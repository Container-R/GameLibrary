# 随机关卡有一条出路，玩家就一定能到出口吗

大厅有一扇随机传送门：一半机会直接到出口，另一半会把玩家送进出不来的地牢。测试工具把两个结果都当作可走的边，报告「大厅能到出口」。它没算错，但回答的是「有没有一个好结果」，不是「玩家有没有办法保证走出去」。若设计承诺要保住这一局，验收不能只问前一个问题。

以下把一次玩家行动（以及该行动引出的结果）算一步。玩家能根据当前状态选行动，但不能指定随机结果；同一局不靠读档或重开。若产品承认失败后重试，要单独定义哪些进度保留，不能悄悄当作走到了出口。

## 一扇门：存在、概率和保底分开写

设计师可以用下面三个版本开评审。三版都存在一步到出口的结果，但测试标准不同。

| 大厅能怎么走 | 存在出路 | 玩家能保证在几步内到达 | 最优选择下，1／2／3 步内到达的概率 |
| --- | --- | --- | --- |
| 抽中出口或死路，各一半 | 是 | 无保底 | 1/2、1/2、1/2 |
| 抽中出口或回大厅，各一半，重新独立抽 | 是 | 无保底 | 1/2、3/4、7/8 |
| 保留独立抽取，再加两步必达的绕路 | 是 | 2 步，走绕路 | 1/2、1、1 |

第二行给无限次机会时，到达概率是 1，因为连续失败 N 次的概率是 (1/2)^N，随 N 增大趋于 0。但无论承诺多少步，都仍可能每次没抽中。概率 1 在这里不等于「每条允许的结果序列都能结束」。第三行也不表示所有玩家都会过关；它只表示有一套选法可保证到达。若规格连玩家随便选也不能把自己卡死，还要枚举允许的选择造成的状态，并检查每个状态是否仍有补救策略。

## 不要把「抽到了什么」记成玩家的下一步

从关卡数据导出三层：**状态 → 玩家动作 → 该动作的所有可能结果**。状态可以是房间、任务旗标、重试次数和已经消耗的道具；动作是「触发传送」或「走绕路」；结果是传送到了哪。把「传到出口」和「传到牢房」拆成玩家的两个独立动作，保底检查就会错误地让玩家只选前者。结果有权重时，另记每个结果的概率；只做最坏情形分析时，仍须列全可能结果，但不需要知道概率。这里假设状态对玩家可见，且包含影响下一步规则的事实。若某个旗标仅服务器知道，不能直接让策略按该旗标选路；需按玩家能观察到的信息另建模型。

若只问是否存在出路，从出口沿结果边反向搜索即可。若要的是保底，从出口开始，按整轮扩张「能保证到达」的集合。用上一轮的集合判本轮，不能一边遍历一边写回，否则同一轮会混进多步，算错保底步数：

```text
W0 = 所有完成状态
每一轮：
    Wi+1 = Wi ∪ {
        存在一项玩家可选动作，且其结果非空、所有可能结果都在 Wi 的状态
    }
    若集合不再变化，结束
```

一条可能的好结果不能让动作合格；没有结果的动作也不能因「没有坏结果」被当成合格。首次进入第 i 轮的状态能在 i 步内保底。为每个新增状态记下让它加入的动作；执行这个动作的每种结果都会落在前面的轮次，剩余步数上界至少减一。在绕路版，出口第零轮、桥第 1 轮、大厅第 2 轮，保底动作是走桥。独立重抽版没有桥；抽到大厅仍回到未入集合的状态，任何轮次都不能把大厅加进去。这是有限步的可达博弈：玩家选动作，另一个决策点选择结果。[1] 在本模型的一步里两次决定都结算，不把选结果再算一回合。

## 概率目标要写清预算和重试条件

若验收口径改为「在 N 步内至少有 99% 的机会到出口」，给第零步的出口 1、其他状态 0。每加一步，在每个状态对每项玩家动作分别计算「结果概率 × 上一轮该结果的成功率」之和，再取可选动作的最大值；已经完成保持 1，没动作又没完成的状态为 0。这个最大值是假定玩家按成功率最优选择，不是对玩家行为的预测。团队可对照 PRISM 的 MDP 查询：`Pmax=? [ F<=N "exit" ]` 计算可选策略中的最大达成概率。前提是模型的每个转移正好代表此处的一步，动作是玩家可控的选择，而概率分支确实是一次机会的结果。[2]

重试版若每次失败真的回到同一个可重新抽样的状态，7 次时成功概率是 127/128，首次达到 99%。但如果进大厅时已把好坏结果固定，一次失败就意味着这一局余下重试都会失败；模型不能继续把失败画成回到同一个重新抽样节点。这时第 7 次之后仍只有 1/2。请在实机记录重试是否推进抽取、是否复用种子或缓存结果，以及失败后实际回到的状态。若有保底计数器，应把次数写入状态：允许连续失败两次、第三次必出，与永远能重抽不是同一条路径规则。

落地时把三项写进验收单：是否至少存在出路；要求哪个状态在几步内保底、保底动作是什么；或在什么抽取规则下、多少步内要达到什么概率。用失败分支复现反例，再按规则确定修复点：加一条不会被随机结果截断的绕路，让最后一次重试必定成功或提供确定的退路，或改验收指标。不能靠演示一条成功路线，替代对坏结果的检查。
