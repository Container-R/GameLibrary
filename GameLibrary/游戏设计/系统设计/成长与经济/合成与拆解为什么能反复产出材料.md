# 合成与拆解为什么能反复产出材料

一条制作配方拿三块废料做出两个零件和一份残渣；另一台机器吃掉一个零件和一份残渣，又返还三块废料。单看任何一张配方，都像是有投入才有产出。连着做，废料和残渣回到开始时的数量，却留下一个零件。如果下一轮还可以原样开始，原本要靠探索获取的零件就有了另一条来源。游戏经济策划要核对的是整条操作链，而不是逐个配方看似收了多少成本。

## 把每一步实际消耗和产出分开

用 `(废料, 零件, 残渣)` 表示库存。先假定物品是整数、配方可立即再次使用，背包不限量，没有额外消耗。两步都是先扣输入，再把产物记入库存。

| 操作 | 要求并消耗 | 产出 | 执行后库存 |
| --- | --- | --- | --- |
| 开始 | | | `(3, 0, 0)` |
| 合成 | 3 废料 | 2 零件、1 残渣 | `(0, 2, 1)` |
| 拆解 | 1 零件、1 残渣 | 3 废料 | `(3, 1, 0)` |

做完后还握有原先的三块废料，新增零件也不会妨碍下一轮：有 `k` 个零件时，这两步总能把 `(3,k,0)` 变成 `(3,k+1,0)`。因此在这一组规则下，重复性来自每轮都能继续的证明，不是因为连续试了四轮刚好成功。完整库存一直在涨，不是回到同一个状态；回到的是**启动下一轮所需的条件**。

要在配方表里筛同类问题，可以先给每条固定配方算出「产出减消耗」列向量。设 `x` 是各配方的使用次数，矩阵 `C` 的各列是这些净变化，那么末库存等于起始库存加上 `C·x`。上例各做一次，净变化为 `(0,+1,0)`。对于希望「挣一个目标材料且不亏其他材料」的检查，先筛目标项为正、其他项不为负的非负整数次数；如果还要求某种催化剂完全复原，就把对应净变化约束为零。筛到组合只说明数量可能对得上。这样的状态方程不含动作顺序，不能用来证明可达。[1]

把库存全设为零就是最直接的反例：同一个组合仍然净赚一个零件，但第一步根本没有任何配方可以执行。还有一种容易被净量隐藏的情况：配方要求先持有一张模具，完成时原样返还。模具在净变化里是零，却仍是启动条件。必须保留输入、产出及非消耗前提，不能拿净变化表直接当可执行规则。

## 账面上回本，还要再试一轮

把背包改为最多装四件，容量在扣除输入后、检查最终库存时计算，且不允许丢弃或转移。第一轮拆解后是三块废料和一个零件，刚好四件。第二次合成后有三个零件、一份残渣，仍是四件。再次拆解虽然只需要两个输入，但结算后会留下两件零件、三块废料，共五件。第一轮合法，第二轮在拆解处失败。于是**启动材料全回来了，不等于能无限累积产物**。如果游戏可以把零件卖掉或存入不受同一容量限制的仓库，这些动作就要一并纳入模型：玩家也许可以每轮腾出空间，再把收益带出去。

再看机器需要耗掉一格不自动恢复的电量。如果第一轮返还了三块废料，但电量从 1 变成 0，便没有归还所有持续开工所需的资源。不应把库存小计的零件增加叫作可重复增产。若机器次日自动补电，等待是另一个可用动作：限制可能把不间断的重复生产变成每天一次稳定产出，改变的是速率，不是单轮结算。每天一次是否超标，应按游戏的成长预算检验。[2]

## 给每条可疑回路留一条能复跑的操作记录

先从实际可达的账户状态开始。只检查空背包会漏掉拿到关键种子之后的组合；只用全解锁、给满材料的测试号，又会把尚未能启动的路线算成前期风险。记录版本、玩家进度、工作台状态、库存和容量。按真实扣给顺序编码每个动作；如果实现是分多步扣给或容许产物溢出，则按实现记录，不套用本文的单步结算。

小规则集可以直接逐步搜索。从真实起始状态出发，对每个状态遍历当前合法的动作，生成下一状态；保留第一次到达该状态的前驱和动作。看到目标增加、所需条件恢复时，沿前驱还原顺序，重放第一轮和第二轮。若先付一次解锁费、拿到模具后才进入循环，就把已解锁的可达状态作为新的比较起点，并另存从账户初态抵达它的步骤。循环不必返还这笔只发生一次的前置投入。如果认为还可以无限重复，要额外给出为什么新增产物不影响动作的理由，比如上面的 `k → k+1`。如果八步内没找到，而且仍有未展开的合法后继，就不能排除更长的序列。只有已访问集合对所有**已建模的**合法后继闭合，也就是从集合内每个状态再走一步都不会产生新状态，才排除了这组规则、起始状态和判据下的遗漏；漏建出售、库存恢复或等待，会直接缩小这个保证。

本库的原创整数模型用两条配方和上述动作顺序，执行了六组对照。初始三废料、无容量及电量限制时，八步内有四轮，每轮多一个零件；去掉启动材料后一步也做不了；拆解返还减为两块废料时，先到 `(2,1,0)`，随后无法再启动。有一格不可恢复电量的对照中材料可回本一次，但电量不归还；容量三件的对照连第一轮都不能完整执行；容量四件的对照只增产一轮。这里的容量按件数计，不模拟真实游戏的叠堆、重量或掉落。复现记录同时标出了搜索仍有未展开后继的情况。

## 修的是异常来源，不只是给它限速

如果拆解是为换装失误提供部分补偿，先尝试降低**造成回路的那一笔**返还，保留正常拆解的价值。例子里从返三块改返两块，相当于每做完一轮少一块废料；没有外部补给就不能不断恢复启动条件。若副产物是别的系统的重要来源，可以改拆解所需材料或用途，而不是全面砍合成产出。若设计本来想让加工机器稳定产零件，就为它设定明确的产出速度及外部成本，再用正常收支检查，不要指望背包上限自动控制可搬运的总量。[2]

修完要重放原见证，还要试邻近的合法操作：额外带一轮种子、换拆解站、把产物入库再开始，以及等补货。记录每轮净得、缺少的材料或次数，以及从哪些进度能启动。这样才能知道是切断了异常来源、把它搬到别处，还是保留了一条数量可控的正常路径。
