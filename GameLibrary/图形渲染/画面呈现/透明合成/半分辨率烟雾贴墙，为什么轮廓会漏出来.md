# 半分辨率烟雾贴墙，为什么轮廓会漏出来

一团烟雾在遮挡物后经过。全分辨率渲染时，烟雾被柱子挡住，柱子旁边仍能看见烟。把粒子颜色改为半宽、半高的离屏目标后，柱子旁空了一条缝，或者烟反倒盖到了柱子上。两种症状可能由同一项优化引起：四个屏幕像素只留下一个深度代表值。只改粒子的软化距离，不能让这一个值重新分辨柱子和背景。

## 从全分辨率看：同一个粒子需要两种判断

软粒子会根据它与该像素场景表面的深度间距改变不透明度。这里用随距离增加的线性眼空间深度，设粒子片元深度为 4 米，淡出从 0 到 2 米。不计粒子贴图调制时，保留的不透明度比例为 `clamp((场景眼深 − 粒子眼深) / 2 米, 0, 1)`。它用的是同一视图射线上的眼深差，不是最近三维表面的欧氏距离。正常的硬遮挡、软交界淡出和最后的透明混合也不是同一件事；这里用零不透明度表达遮挡，不用硬件深度测试。

同一个 2×2 块里，前景柱子眼深是 2 米，背景墙是 10 米。全分辨率下，柱子覆盖的位置得 0，背景处得 1。半分辨率目标若对四个样本共用一个值，前一步已经丢掉了差异：

- 取最近的 2 米：片元处处被挡，背景侧也没烟，形成一条空缝。
- 取最远的 10 米：片元处处可见，烟盖到了前景物体上。
- 简单平均不一定居中修好。本例四个样本近远各半，平均是 6 米，算出的不透明度仍是 1；更根本的问题是 6 米处没有一个被采样的表面。

[NVIDIA GPU Gems 3 第 23 章](https://developer.nvidia.com/gpugems/gpugems3/part-iv-image-effects/chapter-23-high-speed-screen-particles)的图 23-3、23-4 展示了粗深度带来的空缝，也说明用远值压小前景轮廓会让粒子侵入遮挡物。这不是可无损下采样的深度规则。该章示例中的最大值指该示例深度约定下更远；自己写 shader 时先确认数据的含义。设备深度可能是反向 Z，也可能经非线性投影；直接对原始纹理做平均不等于对眼深平均。若要复用米制淡出参数，应让场景和粒子的深度在同一线性域，处理清屏值和无几何样本，并区分普通与反向 Z 的近远比较。Unity URP 的 [Particles Unlit 材质说明](https://docs.unity3d.com/cn/6000.0/Manual/urp/particles-unlit-shader.html)也明确软粒子依赖启用的 `CameraDepthTexture`；有这个材质开关，不等于离屏粒子缓冲一定使用了同样的采样与还原方式。

## 上采样能选对已有的样本，不能找回没画过的烟

给低分辨率不透明度配一个场景深度标签。回到全分辨率时，先读目标像素的场景深度，再从邻近小图像素里挑标签更近的样本，或把深度差过大的邻点从滤波权重里排除，再归一化。这样不会盲目把前景的烟和背景的烟混在一起。阈值用可解释的深度尺度，还要在没有可靠样本时走预定回退，不能让无权重的像素除零。

实际跑了两遍 OpenGL 着色器：一遍把 4×2 的眼深和不透明度折叠到 2×1，另一遍还原到 4×2。每行眼深是 `[10,2,10,10]`，两行相同。下列数是读回的每行不透明度，255 表示比例 1：

| 方法 | 4 个像素 |
| --- | --- |
| 全分辨率对照 | 255, 0, 255, 255 |
| 取近深度后双线性还原 | 0, 64, 191, 255 |
| 取远深度后双线性还原 | 255, 255, 255, 255 |
| 取近深度后按全分辨率深度选择邻点 | 255, 0, 255, 255 |

左边的小图像素实际没画出烟；选择器之所以能还原第一个像素，是因为相邻小图像素有深度 10 的烟可以借。把每行改成 `[10,2,10,2]`，两个小图像素都选了近深度，深度选择器得到 `[0,0,0,0]`，而正确结果是 `[255,0,255,0]`。这次背景没有样本可借。试件用深度不匹配时的全分辨率重算恢复了结果；真实渲染要恢复烟的颜色、叠层和纹理覆盖，通常得重渲染相关粒子，而不是拿深度猜一个 alpha。若邻点与当前像素的粒子分布不同，即便场景深度相同也不保证颜色正确。

## 遇到边缘错误，按三个缓冲逐一查

1. 固定同一帧粒子种子和相机，用全分辨率同一材质渲染一份对照。看源深度里遮挡物有没有写入、线性化后的前后关系对不对；如果全分辨率也错，先查材质透明规则、深度来源或坐标，不急着改低分辨率。
2. 在出错像素记录源深度的 2×2 足迹、缩小后的深度标签、小图里的粒子颜色和不透明度。若小图已经不见烟，换上采样不能凭空恢复；若小图两侧都有可靠样本，管住按深度跨边取样通常比调材质阈值更对症。
3. 对同时含近远深度的块，试预算允许的局部高分辨率重算，或把必须保持遮挡边界的近景烟单独走全分辨率。重画区域应替换小图的对应贡献，不能把两份烟叠加。把结果与纯远值方案并列看：远值可能更适合一闪即逝的爆炸，却会让慢烟长期压住角色剪影。用目标设备的 GPU 计时测降采样、采样重建和重画的总成本，并让镜头横移穿过薄栏杆验证边缘是否跳动。深度跨度只能标出风险区域，不是烟一定画错的证明；窗口内很陡的连续墙面也可能触发。

本文的[复现实验](../../../../管理档案/实验/低分辨率软粒子的深度边缘/README.md)用 Mesa 软件 OpenGL 执行实际渲染目标读回；输入是合成的眼深和恒定粒子深度，没有引擎、角色、真实烟颜色或物理 GPU 计时。若画面不随分辨率变、只在透明层互换顺序时变，另看[加权透明混合与逐层合成](加权透明混合不用排序，为什么仍不等于逐层合成.md)；先诊断是输入样本丢失，还是同一批样本的合成规则不同。
