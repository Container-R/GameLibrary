# 线性混合蒙皮的法线修正：从邻域权重到逐顶点计算

两根骨骼都没有旋转，其中一根只向上移动，表面却可能倾斜。若照明方向仍只随骨骼的旋转部分变化，高光就没有描述相邻点之间不同的位移。给每根骨骼补一个逆转置，或者再次单位化法线，都未必补上这个变化。

本文面向会使用三维向量、矩阵和线性混合蒙皮（LBS）的动画程序员与角色技术美术，给出一条完整但限定的法线计算方法：从静止网格的邻域权重估计梯度，预计算两个方向上的变化量，再在每个姿势中独立计算各顶点的着色法线。方法采用明确的**等权面梯度平均**，便于实现和核对；它不是论文中的余切／Voronoi 预处理复现，也不保证优于所有资产已有的照明方案。

需要先有正确的位置蒙皮。本文的 `Cₛ(p)=Aₛp+tₛ` 是接受同一源空间、输出到同一变形空间的有效骨骼变换，包含必要的绑定校正和层级变换。使用 glTF 时，可先完成[逆绑定、节点层级与输出空间](../../../技术美术/环境管线/模型导入/构造glTF蒙皮矩阵时，怎样对齐绑定空间与节点变换.md)。以下只处理固定源网格的 LBS 法线方向，不接入 morph、双四元数、UV 切线空间法线贴图或各向异性材质。

## 先决定要保留哪一种方向

三角形的**几何面法线**由位置和顶点顺序决定：对依序排列的 A、B、C，采用右手叉积 `(B−A)×(C−A)` 并单位化。照明使用的**着色法线**可能经过平滑或艺术编辑，不必等于任一邻面的面法线。

本文输入的是每个着色样本的单位法线 n。方法传输与 n 垂直的平面，尽量保留这份输入方向的含义，不先用几何平均覆盖它。输出是选定局部变形估计下的着色方向，不是“所有相邻三角形共同的垂线”。这一目标与 Tarini 等人的着色法线处理一致。[2，§2.2、§4.1]

离散网格只给出顶点权重，没有唯一的连续权重函数。因而还必须约定怎样重建它，以及哪些面参与每个样本的估计。本文选择：每个面内线性插值，垂直于该面的方向上保持权重不变，再对声明邻域中的面梯度等权平均。下面将把这个选择写成可执行的步骤。

## 只有平移，也能产生法线变化

取源空间中的三角形：

```text
A=(0,0,0)，B=(1,0,0)，C=(0,1,0)，输入 n=(0,0,1)。
C₀(p)=p，C₁(p)=p+(0,0,1)。
w₁(x,y,z)=x，w₀=1−x。
```

x 是变形前的位置坐标。三角形内两项权重非负、和为1。混合位置为：

```text
F(p)=(1−x)C₀(p)+xC₁(p)=(x,y,z+x)。
A'=(0,0,0)，B'=(1,0,1)，C'=(0,1,0)。
(B'−A')×(C'−A')=(−1,0,1)。
```

几何面法线因此变成 `(−1,0,1)/√2`。两根骨骼的线性部分却都是单位阵 I：逐骨变换 n 后混合、逐骨取逆转置后混合，或者先混合线性块再取逆转置，在本例中都给出 +Z。它与新边 `(1,0,1)` 的点积为1，不垂直。一般情况下，这三种计算路径并不相同；这里只是恰好一起遗漏了权重变化。

遗漏项可以直接求导看见。固定当前姿势，令权重在所考察区域可微，p、tₛ 为三维列向量，Aₛ 为 3×3 矩阵：

```text
F(p) = Σₛ wₛ(p)(Aₛp+tₛ)
J(p) = Σₛ wₛ(p)Aₛ + Σₛ (Aₛp+tₛ)(∇wₛ(p))ᵀ
       └──── L ────┘   └──── 权重变化带来的项 ────┘
```

雅可比 J 描述输入小位移怎样变成输出小位移；后一项是列向量乘行向量产生的 3×3 外积。这个例子中 `∇w₁=(1,0,0)`、`∇w₀=(−1,0,0)`，所以：

```text
J = [1 0 0; 0 1 0; 1 0 1]，J⁻ᵀn=(−1,0,1)。
```

Kavan 的课程 §6、式(16)(17)和图10讨论了这一机制。[1] 本例的 F 恰为仿射映射，微分方向与变形后三点形成的面方向相同；一般的非线性权重混合没有这个保证。连续重建曲面可能弯曲，而渲染网格通常仍用变形顶点之间的直边组成三角形。[2，§3.1]

## 预处理第一步：明确样本、邻域和坏输入

预处理需要源位置、三角形索引、每个角点完整的位置权重、给定法线，以及每个着色样本的面邻域。所有位置和法线处在同一源空间。位置权重非负、和为1；没有列出的骨骼按0处理。本文假定这份输入已按项目的数值规则验收，不能在计算梯度时偷偷重新归一化并继续使用旧位置路径。

最简单的实现以渲染顶点索引为样本，使用真正引用该索引的面。这自然保留复制顶点间的边界。若资产希望 UV 缝两侧共享估计，必须提供明确共享组，并先确认组内位置及完整权重一致；它们可以保留各自的 n 和辅助平面。只凭坐标相同自动焊接，会把本应独立的硬边、重叠表面或不同权重混在一起。

为每个样本固定一个非空邻域，明确硬边是否分开。全流程对该样本的所有骨骼使用**同一组面**。无效索引、非有限数、零长度法线、归一化失败或退化面应带着样本和面编号返回失败，先修复输入。若项目决定剔除某个坏面，应先重新确定整个邻域，而不是只在某根骨骼的求和中跳过它。

## 预处理第二步：由三角形的权重差求面梯度

对每个面取三个角点 `p₀,p₁,p₂`。遍历它们位置影响的骨骼并集，而不是只看待处理顶点的非零权重。对其中一根骨骼，设：

```text
e₁=p₁−p₀，e₂=p₂−p₀
d₁=w₁−w₀，d₂=w₂−w₀
G₁₁=e₁·e₁，G₁₂=e₁·e₂，G₂₂=e₂·e₂
D=G₁₁G₂₂−G₁₂²
```

本节的 w₀、w₁、w₂ 指这根骨骼在三个角点的权重，不是骨骼编号。求 `g=a e₁+b e₂`，要求沿两条边的变化量分别是 d₁、d₂：

```text
[ G₁₁ G₁₂ ] [a] = [d₁]
[ G₁₂ G₂₂ ] [b]   [d₂]

a=(d₁G₂₂−d₂G₁₂)/D
b=(d₂G₁₁−d₁G₁₂)/D
g_face=a e₁+b e₂
```

这使 `g_face·e₁=d₁`、`g_face·e₂=d₂`，且没有离面分量，正好落实面内线性、沿法向不变的选择。[2，§3.1] 在实数下，非退化三角形的 D 大于0。实现中应使用适合资产尺度的长度下限，并检查无量纲比值 `D/(G₁₁G₂₂)` 是否过小；计算它之前先确认两条边长度有效、乘积和 D 有限。该比值等于两边夹角的正弦平方，接近0意味着病态求解。阈值由源精度、单位和允许的方向误差决定，不能随手给 D 加一个常数就当作恢复成功。

对样本 i 的邻域 `Nᵢ`，每根骨骼使用同一个分母：

```text
gᵢ,ₛ = (1/|Nᵢ|) Σ(f∈Nᵢ) g_f,ₛ
```

某根骨骼在一个面上没有影响时，该面的梯度为0，也计入分母。只平均“这根骨骼出现的面”会改变规则，并可能破坏后面需要的梯度和为0。等权平均受三角剖分影响；它是本文选择的简单离散估计。论文 §3.2 使用的 Voronoi／cotangent 汇总属于另一种选择，不能用本文的数字声称复现了它。[2]

## 预处理第三步：把梯度压成两个方向系数

为给定单位法线 n 构造正交单位向量 u、v，并保持 `u×v=n`。可从 X、Y、Z 坐标轴中选择与 n 点积绝对值最小的一根 a，固定相等时的优先顺序，然后：

```text
u=normalize(a×n)，v=n×u
αₛ=gₛ·u，βₛ=gₛ·v
```

u、v 只用来表示着色平面，不是 UV 切线。将它们和系数一起缓存；更换基底却沿用旧系数会改变含义。也可以使用其他满足上述条件的固定基底。

归一化权重在每个面上满足 `Σₛwₛ=1`，所以面梯度之和为0；共同邻域和共同分母把这个性质保留到顶点。因此理论上：

```text
Σₛgₛ=0，Σₛαₛ=0，Σₛβₛ=0。
```

预处理应检查这些关系及面边残差。数值容差要按梯度／系数的量级制定并记录；明显超限时，先查丢项、不同分母、输入权重或病态面。若要统一一个小的舍入残差，可选参考骨骼 r，把其系数显式设为其余系数之和的负数，并记录这项数值一致性处理；不能靠这一操作掩盖大的输入错误。

保留集合由两部分组成：位置计算需要的骨骼，以及 α 或 β 非零的骨骼。后者在当前顶点的位置权重可以为0，但每帧仍需要其变换。选择集合中的一根 r 作为参考，最终可省去 r 的一对系数，保留其索引；参考变换仍然要读取。完整方法不静默截断影响数：若格式容不下这个集合，返回所需容量，扩大格式或另外设计有误差预算的有损策略。删掉“小系数”也是近似，会改变梯度和与结果。

一次预处理的交付至少包括：p、原位置权重和对应索引、n 或其用途说明、固定 u/v、法线所需骨骼并集、参考 r、其余骨骼的 α/β，以及邻域和数值规则的身份。位置、拓扑、权重、法线、共享组或源空间变化后应重新计算；仅姿势变化时更新骨骼变换即可。

## 每帧：先传输平面，再求法线

在同一姿势与输出空间中，计算全部所需骨骼对当前源点的作用，并从原位置权重构成 L：

```text
qₛ=Aₛp+tₛ
L=Σₛ wₛ Aₛ
u'=L u + Σ(s≠r) αₛ(qₛ−qᵣ)
v'=L v + Σ(s≠r) βₛ(qₛ−qᵣ)
h=u'×v'
n'=h/|h|
```

位置权重和位置结果不因法线修正而改变。零位置权重的额外骨骼不进入 L 的有效和，却可能进入两条切向量的修正。这是论文 §4.1–§4.3 的切平面传输与参考骨骼形式，应用在本文明确选择的梯度估计上。[2] 因为系数和为0，将 `Σαₛqₛ` 写成参考差不会改变实数结果；它可减少大共同平移造成的相消规模，但不能保证浮点相减总是精确。

求 n' 前检查所有结果有限、两条向量长度有效、叉积没有坍缩。可同时用与输出尺度对应的长度下限，以及 `|h|/(|u'||v'|)` 的夹角指标检测病态平面；除法前检查分母。失败时不要归一化零向量或输出任意固定轴。返回诊断，交由项目选择保留近似方向、重算几何方向或拒绝该姿势，并明确所选回退已改变方法。

叉积还保留一个方向约定。若 J 表示这里的局部线性估计且 `u×v=n`，则：

```text
(Ju)×(Jv)=cof(J)n
J 可逆时，cof(J)n=det(J)J⁻ᵀn。
```

`cof(J)` 是余子式矩阵。det(J)>0 时，单位化后与逆转置同方向；det(J)<0 时相反，涉及反射或局部翻转。本文保留源平面的定向并随变形叉乘，不自动翻回朝外。双面照明、面剔除和资产的朝向约定应另外保持一致。J 奇异时逆转置没有定义，但某个二维平面仍可能没有坍缩；叉积可检查这个平面，却不能解决全部奇异情况。

## 完整例子：中心不动，为什么仍要第二根骨骼

取 XY 平面上的五个点和四个 +Z 朝向的三角形：

```text
O=(0,0,0)，E=(1,0,0)，N=(0,1,0)，W=(−1,0,0)，S=(0,−1,0)
面：OEN、ONW、OWS、OSE
骨骼1的权重：E为1，其余点为0；骨骼0取补数。
```

中心的邻域就是这四个面，不跨其他接缝。以 OEN 为例，`e₁=(1,0,0)`、`e₂=(0,1,0)`、`d₁=1,d₂=0`，所以 G 为单位阵，得到骨骼1的面梯度 `(1,0,0)`。OSE 中 `e₁=(0,−1,0)`、`e₂=(1,0,0)`，权重差为0、1，同样得到 `(1,0,0)`。其余两面三个角点的该权重都为0。

| 面 | 骨骼1的梯度 | 骨骼0的梯度 |
| --- | --- | --- |
| OEN | (1,0,0) | (−1,0,0) |
| ONW | (0,0,0) | (0,0,0) |
| OWS | (0,0,0) | (0,0,0) |
| OSE | (1,0,0) | (−1,0,0) |

共同除以4，得到 `g₁=(1/2,0,0)`、`g₀=(−1/2,0,0)`。这里不能把 g₁ 称为中心权重的精确导数：分片线性权重场为 `max(x,0)`，中心沿 X 存在折点。可微非负函数若在内部取0，其梯度应为0；本例算的是邻面梯度的平均估计，没有违反这个事实。

给定 n=+Z，本例选合法的固定基底 `u=+X,v=+Y`。得到 `α₁=1/2,α₀=−1/2,β₀=β₁=0`。仍使用 `C₀(p)=p`、`C₁(p)=p+(0,0,1)`，参考 r=0：

```text
O 的位置权重为(1,0)，位置仍是原点。
q₀=(0,0,0)，q₁=(0,0,1)，L=I。
u'=(1,0,0)+(1/2)(0,0,1)=(1,0,1/2)
v'=(0,1,0)
u'×v'=(−1/2,0,1)
n'=(−1,0,2)/√5。
```

因此，只留位置所需的骨骼0会丢失法线修正。额外保存骨骼1的索引、变换访问与系数，才完成这里定义的方法。[2，§3.2、§5] 这不是要求保留所有零权重条目，而是保留当前估计真正需要的项。

实际变形后三角形的方向并不全是 n'：两个东侧面的未单位化法线为 `(−1,0,1)`，两个西侧仍为 +Z。中心结果描述一个汇总后的着色平面，不能要求它同时垂直于折线两侧所有面。给定法线若经过艺术编辑，仍用它自己的 u/v 计算，不能借这个平面算例把全网格法线换成 +Z。

## 接入检查、成本与选择

先用少量确定输入检查数据链，再比较真实资产画面：

1. **常量权重。** 每面权重差为0，修正项应为0；输出是混合线性块传输 u/v 后的叉积。它不自动等于“逐骨逆转置再混合”。
2. **所有骨骼使用同一变换。** 参考差为0，得到该共同变换的定向平面法线。给所有 q 加同一平移也不应改变实数结果。可据此查漏项与空间不一致。
3. **从网格重建梯度。** 使用上面的平移三角形和菱形，不只给着色器手填系数。分别核对面边残差、共同分母、系数和、额外骨骼及最终方向。
4. **失败路径。** 退化源面、空邻域、容量不足和坍缩输出都应得到明确状态；反射输入应按既定定向规则处理。不要只测试方向看起来正常的姿势。
5. **资产比较。** 固定同一位置、姿势、空间和光照，分别看当前着色方向、该估计及按声明平滑规则重算的几何方向。差异先按各自目标解释，再由动态画面、接缝稳定性和预算决定是否采用。

三条路线各有成本。沿用现有近似通常数据少，也可能符合既有资产的调校；从变形几何重算法线更直接对应离散表面，但需要邻接、平滑规则和合适的计算阶段，且可能覆盖艺术方向；本文方法把邻域工作前移到静态预处理，每帧可独立处理顶点，但增加系数、额外索引和变换读取，对网格质量与邻域规则敏感。

按本文的直接表示，u/v 需要6个标量，k根法线所需骨骼需保存 `2(k−1)` 个系数，还要考虑额外索引、对齐和缓存开销。项目若能重建或复用其中的数据，应按自己的实际格式计算成本，不能把论文的某项运算比较当作这份布局的总开销。更多骨骼、病态小三角形和压缩系数都会影响误差与带宽。

论文 §4.4 还讨论限制修正向量长度，以减轻输入折叠引发的法线翻转，并报告了其试验采用的 c=0.9。[2] 本文没有把它作为默认步骤：任意缩放或混合后的基向量长度未必为1，固定0.9不是普遍防翻转保证。若项目选择截断修正或裁剪影响，需另设目标、误差和回退规则，而不能继续称其与上面的完整计算相同。
