# 组队玩法做 A/B 测试：按玩家分组会漏掉什么

新工具能把双人任务的提示发给队友。试玩后，开了工具的玩家和没开的玩家分数差不多。于是团队想说「改动没什么用」。但没开的玩家也可能一直在用队友发来的提示。这里不是统计表算错了，而是**按谁收到功能做比较，和让整支队伍都用上功能，是两个不同的问题**。

本文面向设计与数据分析人员，用双人固定队说明：上线决策要比较哪两种分配方式，队友收益怎样单独测，以及怎样从匹配记录查组间是否真的隔离。

## 队友的分配也会改变我的结果

以一个虚构玩法为例。每队两名玩家，实验前已经成队；实验期间只在原队合作，积分不会通过队外交易、匹配或排行榜反过来影响任务。新功能允许本人发提示，本人使用更清楚的标记也可以得到帮助。我们以预先列入的每名玩家一周内获得的双人任务积分为指标，确认无参与时记零，记录缺损则不当作零。为了只看分配的影响，假设所有玩家在相同配置下的平均积分如下：

| 自己是否有工具 | 队友是否有工具 | 自己的平均积分 |
| --- | --- | ---: |
| 无 | 无 | 30 |
| 无 | 有 | 34 |
| 有 | 无 | 36 |
| 有 | 有 | 45 |

表是事先指定的四种平均结果，不是四次观察，也不是实际游戏数据。它允许队友使用版本改变自己的成绩，这叫**干扰**（interference）。假设干扰可在队内发生，却不会越过队伍边界，称为**部分干扰**（partial interference）。正式研究用这一类假设来区分自身分配、他人分配和整组政策的后果。[1]

表里自己没工具时，队友有工具使预期得分从 30 升到 34。若自己和队友都没有，给自己开工具的差是 36−30=6；若队友已经有，给自己开工具的差是 45−34=11。**自身改动的差值也要说明队友处在什么配置下。** 不能取其中一个当成适用所有组队环境的「功能价值」。

## 都说“开给一半”，其实可能在比较三件事

- **每名玩家各自独立地以 50% 概率开启。** 无论本人开不开，队友都有一半概率开启。在此模型里，处理玩家预期均值是 (36+45)/2=40.5，对照玩家是 (30+34)/2=32，差 8.5 分。这是混合队友环境中的自身分配差，不是全开对全关，也不是任意一次有限样本实际均值的保证。
- **每队恰好选一人开启。** 这次有功能的玩家一定配到没功能的队友；没功能的玩家一定配到有功能的队友。按玩家标签对比只得到 36−34=2 分。一次比较中本人和队友的分配同时反向改变，连「队友配置不变时给自己开功能」也不是它回答的问题。
- **按整队随机：一部分队两人都开，另一部分队两人都关。** 仍可让大约一半玩家开启，但比较变成 45−30=15 分。在本例中，这才是待上线的「给两名队友都开启」对「都不开」的政策差。这个设计不提供只有一人开启的队伍，不能单靠它把 15 分拆成自身影响和队友收益。

所以，换一个分配单位不只是为了让区间更准确，也可能改变你究竟能看到哪些配置。LinkedIn 研究团队曾在其平台并行运行个体级与簇级随机实验，利用分配设计差异检查网络效应；这是一种在线产品的先例，不是本例游戏或这三个分值的来源。[2]

## 上线前决定按谁分配、按什么报告

**问题是“这功能值得给全队吗？”** 若整队确实能隔离，按实验前固定的队伍标识分配。把各队所有已入组玩家的结果保留，按原分配比较；别在事后只留完整打过的队伍，也别拿收到提示次数来重新分组。双人队同样大小时，先求队均值，再比较两组队均值，与这里的入组玩家等权点差相同。真实队伍若大小不同，先明确要衡量典型一支队还是典型一名玩家；用不同权重算出不同问题，方差方法也要配合实际分配设计。几千场重复对局不是几千次独立整队分配；队伍很少时，要如实说明精度可能不足。本文不提供通用的置信区间公式。

**问题是“没开工具的人能从队友那里受益多少？”** 先把队伍随机分到三个策略：零人开、恰好一人开、两人都开；再在单开队内随机选是谁开启。这是把队策略和队员分配分开的两阶段安排。[1] 在这个双人例子，比较单开队里的未开启者和零开队里的玩家，就是 34−30；比较单开队里的开启者和两人都开队里的玩家，可以回答「自己已经有工具时，队友也开」带来的 45−36。不能事后从随意形成的队伍里按实际使用情况挑出这几组，就当作随机化。真实实验中的估计方法要尊重每种配置的抽中概率；把试验里没有分配过的一格藏进平均值，补不出那一格的效果。

**上线开关跟实际组队边界不一致时怎么办？** 先把队伍标识、入组名册、每次合作的实际队友、功能分配与版本、以及指标窗口对在一起。检查一次临时替补、跨队联机或公会共享会不会让对照组用上队外新功能。如果加入或离开队伍受处理影响，不要只删掉换队的人来恢复表面整洁；先报告原分配下的跨队情况，再决定原设计是否还能回答问题。干扰主要越过队伍边界时，应在实验开始前改用能覆盖影响范围的分组（例如独立匹配池），并权衡独立组数变少与单组差异变大。若无法建立隔离，不能把结果直接叫作「全量上线效果」。
