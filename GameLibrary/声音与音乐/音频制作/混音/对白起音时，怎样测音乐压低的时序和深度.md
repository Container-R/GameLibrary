# 对白起音时，怎样测音乐压低的时序和深度

导航员说「左转，穿过闸门」。干声里每个词都在，进游戏后玩家只听清「穿过闸门」。把整句拉响可能让后半句刺耳，却没找出首词被盖住的原因。先保留已经验收的对白增益，查音乐什么时候开始降低、第一词那一段实际降低了多少。下面把主动降低背景音乐简称为压低（ducking）。这里交付的是判断增益时序和深度的方法，不给出哪版更容易听懂的结论。

## 用分轨对齐起音和增益

用同一次播放保存对白干轨、进入检测器的声音、压低前后的音乐轨和最终混音。记录播放实例、预计起音、实际到达混音器的起音，以及增益命令生效时刻。脚本发出「播放对白」不等于声音已经出现：文件留白、解码和音频块都可能推迟可闻起音。用混音器的样本时钟，把第一词、较响的句身和句间停顿与检测输入及音乐增益对齐。总混音的总体响度不能回答第一词发生时音乐降了多少。

对同一乐段做三版：音乐原样、检测到对白后才压低、已知起音前预先压低。对白波形、固定增益、乐段位置和监听设备都不变。不要把三个成品重新归一化到同一个总体响度，归一化会改动对白增益，破坏只改音乐的对照。

## 先问压得了多少，再问压得有多快

FFmpeg 7.1 的侧链压缩器让第二路信号驱动第一路的增益。硬拐点、下行、峰值检测、全湿混合（mix=1）且输入、检测、补偿增益均为 1 时，检测包络 L 不高于阈值 T 就不减益。高于时，压缩比 R 带来的衰减为 `20×(1−1/R)×log10(L/T)` dB。L 是平滑后的线性值，不是整句 LUFS。攻击时间只改变包络多久接近这个值；不会提高同一输入下的稳态衰减上限。[1]

用 FFmpeg 7.1.5 实跑：弱开头持续 35 ms，检测幅度 0.145，随后正文幅度 0.4。阈值 0.125、比例 4:1、释放 180 ms 时，开头即使稳定也只能压低约 0.97 dB；正文可以到约 7.58 dB。合成等能载波用于测增益，不供回听。表中每格按该时间窗内音乐的输出与输入 RMS 计算 `20×log10(RMS输出/RMS输入)`，不是某一采样点的增益。

| 检测设置 | 开头音乐电平变化 | 正文 | 随后停顿 |
| --- | ---: | ---: | ---: |
| 峰值，攻击 120 ms，阈值 0.125 | 0.00 dB | −6.71 dB | −0.76 dB |
| 峰值，攻击 12 ms，阈值 0.125 | −0.71 dB | −7.58 dB | −0.78 dB |
| 峰值，攻击 12 ms，阈值 0.09 | −2.49 dB | −9.72 dB | −2.18 dB |

这组输入缩短攻击以后，弱开头仍远没有压到正文的深度。降阈值对开头更有效，却也使正文和停顿压得更多；停顿里没有检测输入，本例的减益来自上一段尚未释放。真实检测轨若含呼吸、环境声或无关对白，降阈值也可能额外触发。若包络本来就能达到目标深度，只是到得太晚，才优先检查攻击、检测窗口和音频延迟。更换 RMS、软拐点或压缩器时，要重测其曲线和参数含义。

再渲染三版可回放的混音，比较分轨读数。把同一份合成语音「Wait. The gate is open.」与同一段原创音乐叠加，固定对白轨和电平。按实际语音活动定位第一词（500–845 ms）及其后 140 ms 停顿。快攻击版在第一词的音乐均方根电平几乎未变，正文平均只降低 1.105 dB；提前压低版在第一词降低 7.5 dB，也让音乐在那 140 ms 的停顿里保持降低。整词峰值是 0.145，首 35 ms 的峰值却只有约 0.091，低于 0.125 的阈值；整词的峰值也不等于检测器能维持的平滑包络。两组证据说明何时、降低了多少，不证明哪个版本更容易听懂或听起来更自然。三个成品是同一份干声，不是三个配音。

## 提前压低跟随播放实例，不用一个全局开关

固定过场和已知起音的提示，可让音乐在首词之前沿短斜坡下降，在对白结束或允许的停顿回升。起音未知的游戏内对白通常还需要反应式方案，或重做容易遮蔽的音乐/对白。可用中间件快照或音乐总线实现，但 API 存在不等于排程已经与样本对齐。[2][3]

先算停顿有多长，再决定要不要回升。仍以试件的 140 ms 停顿为例：从 −7.5 dB 以 160 ms 线性斜坡回到正常，下句还需提前 60 ms 再下压。两条完整斜坡共需 220 ms，塞不进 140 ms，只剩 80 ms 可用于上升，按原速度最高只能到 −3.75 dB。此时可选择保持、只部分回升，或改斜坡再检查听感；不要让两条独立计时器抢着改同一总线。

每个对白实例独立提交起止样本、请求深度和代号。例：A 先开始，申请压低 5 dB，B 稍晚开始，申请 7.5 dB。可选择取最强请求而非相加：两者同时有效时目标 −7.5 dB，A 结束不能清掉 B。若 B 延迟并重排，旧代号的停止回调不能停掉新代；尚未生效的 C 取消后，迟到的排程不能把它复活。实际总线从当前增益平滑移向新目标，处理已经开始的斜坡和释放；下面的所有权试件只验证目标选择，不模拟线程和实际过渡。

听审不知道版本时，先让其复述第一词，再问停顿是否有突兀的抽吸；分开记词识别和音乐变化，不把能量改善当作听懂。若衰减时序和深度都合理、玩家仍没听清，再查频段遮蔽、空间处理与对白素材。单轨响度验收不能替代这一步。
