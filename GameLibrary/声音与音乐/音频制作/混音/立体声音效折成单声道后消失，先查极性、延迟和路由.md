# 立体声音效折成单声道后消失，先查极性、延迟和路由

某个玩法提示在耳机立体声模式里清楚可闻，切到单声道后却变成很淡的一声，或者根本没有输出。先别把该音效的音量拉高：左、右各自有电平，不代表合在一起还有原来的内容；而有些所谓「单声道」实际上只复制了左路。

本文只讨论两个声道合成一路，以及需要时把结果送到两个输出。目标是判断问题发生在制作、导入、运行时混音还是最终通道映射。环绕声、头部相关传递函数和各平台具体的下混矩阵需另验。

## 用同一段声音做三个对照

把待查的那一声从安静段到结束一起截出，保留两路相同的时间范围，不在截取或导出时分别归一化。先独听左路、独听右路，再用系数已知的单声道折叠听同一段，并一起看波形或能量。要排查一声短提示，不用整分钟混音的平均电平替它作答。

一个明确的对照是 M = 0.5L + 0.5R。两个相同的声道合起来和单路波形一样；如果右路恰好每个样本都是左路的负值，合成就是零。两个声道单独听仍以相同电平播放，并不会暴露这种**反极性**问题。实际两路增益若不同，未必完全归零：例如 R=−0.8L，同一矩阵只剩 0.1L，相对左路降低 20 dB，有非零输出也不能排除相消。若只有一路有提示，正常折叠仍保留它，只是这个对照里振幅减半（相对该路约 −6 dB），并不等于丢失。其他矩阵系数、运行时增益和峰值空间由项目决定，不能从例子的 0.5 反推某台主机的规则。

FFmpeg 的 `pan` 提供一个便于重放的对照：`pan=mono|c0=0.5*c0+0.5*c1`，两路都加入。这里用 `=` 是为了保留所写增益；该滤镜用 `<` 时会另做增益归一化。[1] 用这条明确的参考路径，并不需要先知道项目引擎怎样折叠，也不意味着正式项目要运行 FFmpeg。

## 同一个音晚到，常常只消失一部分频率

延迟一个相同波形并不是给整个波形乘 −1。若右路相对左路延迟时间 τ，在某频率 f 上，右路相位相对落后 2πfτ；两路等权平均后的振幅比为 |cos(πfτ)|。当这个频率的半个周期落在延迟里，两路正好抵消；到整周期，仍接近原幅度。许多相消点依次排开，便是梳状滤波。短促的复合提示可能还剩下尖锐的某一段，真正用于辨识的成分却变弱了，听上去就像换了素材。

在实际执行的 FFmpeg 试件中，用 48 kHz PCM，右路延迟 32 个样本，约 0.667 毫秒。750 Hz 每周期 64 样本，32 正好半周期；1500 Hz 每周期 32 样本，32 正好一整周期。下表读稳态，不把延迟起头那 32 个仅有左声道的样本算进去：

| 输入 | 明确折叠后的峰值 |
| --- | ---: |
| 750 Hz，左右同波形 | 4096 |
| 750 Hz，右声道反极性 | 0 |
| 750 Hz，右声道延迟 32 样本 | 0 |
| 1500 Hz，右声道延迟同样的 32 样本 | 4096 |

数值是 16 位 PCM 样本单位，不是声压、响度或任何通用可听阈值。[复现实验](../../../../管理档案/实验/立体声单声道折叠/README.md)用合成波形和实际滤镜输出作对照；没有运行 Unity、Wwise 或某台设备的单声道开关。真实素材可用短段相关与频谱当线索，尤其对照原本构成提示的瞬态和中频；把完整素材压成一个相关系数，会掩盖只在某一瞬间或频段消失的问题。

## 分清做了折叠，还是丢掉一个声道

排查时另做两条短试件，一条只在左有提示，另一条只在右有提示。只查两边本来就相同的一段，无法分辨真正折叠和只选左路。试件中只有右路有信号，把左路复制到两边，两边都读到零；先按上述矩阵合成再复制，两个输出各读到同一个峰值 2048。注意这回答的是每路有没有该提示，不预言两只音箱合起来的响度。

如果游戏提供无障碍单声道，可按同样方法检查模式的目标是否是「把两边的内容送到左和右」。微软的 Xbox 无障碍音频指南给出这种建议，它并没有指定必须使用本文的矩阵。[2] 实际验收还要分别检查左、右设备输出，以及操作系统的单声道开关或者游戏自己做的转换；二者在哪一层执行、是否仍有后级空间化，决定测什么。后级又做声像或只接一侧输出，都会让前面正确的折叠显得没生效。对依赖方向的重要提示，单声道没有原来的左右定位，仍可用其他不依赖方向的提示方式保留玩法信息。

## 逐层抓同一声提示，再决定修哪里

按项目实际的信号链挑观察点，不需要每一级都有工具。用同一次播放的事件标记对齐截取范围，记录各级处理延迟，避免晚到的声音落在分析窗外：

1. **素材或导入后已坏。** 比较原始左右轨、参考折叠和实际打包后素材。Unity 6000.0 的 Audio Clip 手册把 Force To Mono 及 Normalize 列为导入选项；此处属于素材进入播放系统之前。[3] 不推断 Unity 的内部系数。若扩宽或延迟只用于装饰，优先保留同相干声作为音效主体，让两侧差异承载装饰，而不是把唯一可识别成分放进两路相消的部分。
2. **素材正确，事件或总线后坏。** 暂时关闭疑似扩宽、反极性、不同侧延迟、立体声混响等其中一环，保留其余路径不变，并记下旁路前后的增益差；只变响不能证明消掉了相消。若出现等间距频谱缺口，就对照是否由延迟复制引起。不要对所有素材自动延迟校正或翻转一路：有些立体声内容本来就包含自然时差，调整应针对导致提示丢失的加工链。此时可修改效果设计、对重要音另做单声道版本，或在单声道模式调用保留干声的路由。
3. **前级相同，只有最终输出少一侧。** 检查映射、空间化后再做折叠的位置、设备通道以及是否只是「左到两边」。只有在明确知道两个声道承载的是冗余内容时，才把选单路当成可设计的做法。若一侧还有独有信息，应保留它。再用峰值和短时电平查余量，避免平均改成直接相加时把同相的内容压坏。
4. **样本仍有，但那声还是辨识不出。** 比较同级的干声与全混音，检查遮蔽、动态处理和小扬声器频响。调增益可解决电平不足，但不能填回完全被抵消的频段；调完仍要在立体声、单声道、单侧可听和实际目标设备上确认同一提示能传达原意。重要信息的语义验收应由相应玩家测试或目标设备检查完成，而不是从一列 PCM 峰值判断。

最终让回归用例同时涵盖双路同相、两侧各自独占提示，以及曾出问题的真实事件。保留同一事件在不同观察点的波形与路由说明。这样即使声音真的不见了，也能说清是在哪一层丢掉了样本，还是样本仍在但被混音掩盖。
