# GameLibrary · 游戏开发知识图书馆

这里整理游戏开发中值得讲清楚的问题：一项技术为什么这样做，制作时怎样使用，出了问题从哪里排查。内容面向程序、美术、策划、音频、测试与制作团队，也适合正在学习这些工作的读者。

文章按实际工作领域放在文件夹里。你可以像逛图书馆一样，先找学科，再找专业区域和主题，最后打开需要的文章；不必先判断它属于“案例研究”还是“解决方案”。

## 从哪里开始

- **[进入图书馆，按学科找书](GameLibrary/README.md)**：查看全部楼层和各层已有内容。
- **[技术美术：环境管线](GameLibrary/技术美术/环境管线/README.md)**：资产导入、纹理、模型数据与场景光照。
- **[角色动画](GameLibrary/角色动画/README.md)**：角色移动、脚滑、动画过渡和动作选择。
- **[游戏设计](GameLibrary/游戏设计/README.md)**：关卡、战斗操作与成长经济。
- **[网络与在线服务](GameLibrary/网络与在线服务/README.md)**：移动预测、对局服务器与在线运维。
- **[声音与音乐](GameLibrary/声音与音乐/README.md)**：游戏音效、交互音乐、混音和循环素材。

例如，你想知道为什么同一张贴图换台电脑导入就变了，可以沿着 **技术美术 → 环境管线 → 资产导入**，找到[《换一台电脑后如何保持资产导入结果一致》](GameLibrary/技术美术/环境管线/资产导入/换一台电脑后如何保持资产导入结果一致.md)。如果只记得关键词，也可以使用 GitHub 的仓库搜索。

## 这里的文章怎样阅读

正文从具体问题讲起，解释做法、例子和适用范围，文末列出来源。来自开发团队的案例、根据文献推导的解释和实际运行过的测试会明确区分。

通用方法不等于所有引擎行为相同。涉及 Godot、Unity、Unreal 或特定工具时，文章会说明版本与限制；使用某个引擎做验证，不代表整个图书馆只服务这个引擎。

本库仍在整理历史资料与维护目录。书架提供当前正文；部分文章会链接到旧文中的特定技术补充，这些链接不表示旧目录是另一套推荐阅读路线。想查证某篇文章，可先看文末参考来源；想参与维护，请看[维护说明](管理档案/README.md)。
