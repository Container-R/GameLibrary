# 单机金币账本演示

本库原创、标准库 Python 模型，2026-10-31 在 Python 3.12.14 执行。

- `python3 -m unittest -v`：14 项测试通过，原始结果 `test-output.txt`。
- `python3 model.py`：生成六种确定性参数场景，结果 `scenario-output.json`。

币种为整数 coin，时间窗口为 session；每次遭遇先入奖励、后扣服务费，session 末检查一次性购买。全部数字为演示假设。升级不改变产出，未建模随机性、离线收入、交易市场、真实货币、玩家行为。

测试覆盖纯内存账本与参数模型，不代表生产数据库事务、存档、防作弊或多线程正确。`eventId` 仅在当前内存对象去重；重启/回档不持久，绝不可直接当作生产发奖实现。

账本构造时余额、条目与已见 ID 均为空，禁止构造参数注入；期初库存必须通过 `post` 入账。`event_id` 必须是非空白字符串。`kind` 仅为描述标签，不强制标签与金额符号对应。字段仍可由调用方直接修改，因此演示要求所有余额变动经 `post`，不提供封装或防篡改保证。新增测试覆盖期初入账、禁止构造注入、无效 ID 无副作用拒绝、布尔/非整数/负参数与布尔币值拒绝。
