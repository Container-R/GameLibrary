# 独立模型对抗审查（2026-10-31）

运行：仓库根目录 `python3 research/experiments/deep-model-qa/stress_models.py`。Python 3.12.14，纯标准库；两次完整运行 JSON 字节一致。`output.json` 记录 seeds 0–199、被检模型 SHA-256、数量和变异检测结果。此文件不修改被检目录。默认模型目录为父级 experiments；可用 `--model-root` 显式覆盖。脚本拒绝 `python -O`，防止断言被剥除后误报通过。

## 问题、独立判据与结果

### 客户端预测

200 个固定种子，每个预先生成96条合法命令。客户端测试历史容量显式设128，故可超出服务器32条接收窗口；这不是默认客户端容量。每个场景先执行180个有损/重复/乱序提交步，快照从历史中随机选择，因此含过期重投。50,712次发送尝试处于服务器接收窗口之外。抽象权威位置偏移直接注入服务端状态，用于验证较旧权威结果加未确认输入的关系，不模拟击退或物理。

独立判据：服务端位置等于已确认原始输入前缀之和加累计注入偏移；确认数不超过实际服务端步数；pending不超过窗口；每次有效客户端快照后位置等于该快照位置加原始输入后缀之和；旧快照不修改任何被观察状态；每次原始输入只发射一次效果。

**收敛前提显式限制**：随机阶段后进入可靠后缀，每步重发全部尚未确认命令，并最终交付最新快照。最多96个后缀步。该构造是确定的最终交付保障，不是随机网络在任意丢包下必然恢复的证明。所有200场景达到ack=96、pending为空且客户端与服务器最终位置相等。

### 固定步长

200个种子，每个100个随机时间分段（1/600秒量子，允许0），每帧预算1–8。随后以零新增时间排空积压。总计39,772模拟tick。每帧独立检查：`tick+accumulator == total_elapsed*60`，执行步数不超过预算，状态和事件精确等于原始tick输入前缀；显示alpha在[0,1]且显示值在前后状态区间内。

变形判据：把同一总时间改为全部1/600秒细分、预算固定1，最终tick、余数、位置和事件必须完全一致。两种分段使用同一规范化tick输入，不涉及真实采样时间归属。

## 变异检验

只在内存副本故意引入错误，不落盘修改源模型。seed0即检测到全部四个变异：
- 预测越过缺口消费最大seq：服务端前缀判据失败。
- 预测重放重新发射效果：原始效果日志判据失败。
- 固定步预算耗尽后丢弃整数积压：时间守恒失败。
- 固定步重复发射每个非零输入事件：事件前缀判据失败。

这些变异说明具体判据能发现这四类错误，不是通用覆盖率、完备证明或真实系统安全认证。

## 限制与下一步

本轮未发现被检实现违反上述判据。没有socket、并发、真实计时、引擎、碰撞、资源加载、浮点物理或报文字节解码。未声称覆盖所有种子、输入域或所有API误用。预测合法输入的迟到交付和窗口恢复是本轮重点；不重新覆盖既有单测已检查的畸形消息字段。固定步只使用有限非负Fraction时间和合法整数预算。

下一步集成优先验证真实输入tick映射与引擎回退依赖，而非用扩大种子数替代这些边界。若模型代码改变，应重跑并核对输出中的模型哈希。
