# 中断动画转场的标量惯性化：保留输出值与速度，而不是重用旧片段

## 问题与算法选择

动画目标已经切换，输出却不应在切换瞬间跳位置或跳速度。若上一轮转场还没结束，此时屏幕对应的输出通常不等于旧片段原始值。用旧片段重新计算偏移，会把尚未衰减的修正突然丢掉。

本文研究一个严格缩小的版本：一维连续信号，每段目标的位置与导数均已知，转场发生时刻显式给定。它不是角色动画系统、姿态空间或足底约束求解器。

Daniel Holden 的 *Spring-It-On* 在“Inertialization”节用位置与速度偏移连接新动画，再以弹簧衰减偏移；其示例在再次转场时包含已有偏移。作者明确将此弹簧形式与原始有限时间多项式形式区分，并指出其没有固定完成时间，可能越过目标。本文实现使用标准指数函数，不复制示例的快速近似；也不复现其性能或视觉演示。[S1]

## 从初值问题推导，而不是猜混合权重

令新目标为 p(t)，输出为 z(t)=p(t)+r(s)，其中 s 是本次转场后的时间。目标和导数必须在同一时刻采样。假设左侧实际输出为 z−、速度为 w−，初始化：

    r0 = z− - p(t0)
    u0 = w− - p′(t0)

于是刚切换后的输出和速度分别为 p+r0=z−、p′+u0=w−。这只需要两条初值，不需要在后续区间持续求值旧片段；但旧输出必须包括尚未消失的残差。

选择正速率 λ，保持本段恒定，令残差满足：

    r″ + 2λr′ + λ²r = 0
    b = u0 + λr0
    r(s) = (r0 + bs) exp(−λs)
    u(s) = (u0 − λbs) exp(−λs)

对第一式解求导得到 u；再求导代入微分方程，各项抵消。s=0 时恢复 r0、u0；s 趋于无穷时，多项式乘负指数趋于零。这是实数代数结论，不能替代浮点实现检查。

本协议用 λ（单位每秒）而非模糊的“混合时长”。坐标单位记作 L，速度为 L/s。来源的直观半衰期约定不保证任意初速度下位移恰好减半；本文不把它包装为完成时限。

## 一次更新与再次转场

普通区间按实际 dt 推进残差，然后在区间终点取目标值及导数，最后相加。不要把区间起点的目标与终点残差拼在一起。

若区间中间有转场，应先切开区间：推进到事件时刻，用旧段求出实际输出及速度；减去同一时刻的新目标与导数，得到新残差；记录零时长的新侧状态，再推进剩余区间。不同采样网格只有共享这些事件时刻与顺序，才是在比较同一问题。

再次转场时，直接使用旧片段 p_old、p′_old 而不是实际 z、w，丢失量恰是旧残差 r、u。只保存位置偏移也不够：新侧速度仍可能与左侧不同。

## 连续不等于正确姿态

上述构造要求每段目标为C1，并在切换点具有有限的单侧值与单侧导数极限；使用正确的对应极限后，输出在转场处保持C1连续。它不保证C2。在两侧二阶导数存在时，新侧加速度为 p″−2λu−λ²r，通常不等于旧侧加速度。不要把数值平滑解释为加速度、接触或碰撞都正确。

临界阻尼也不保证任意初值单调靠近零。初速度可能让偏移先增大，也可能让位置穿零时速度仍非零。完整收敛指两个状态都收敛；位置第一次为零不是转场完成。浮点下溢得到零又是另一件事，不构成实数解有限时刻完全收敛的证明。

零残差时，输出直接等于连续变化的目标，不是每帧把整个目标再送入一个追踪滤波器。但转场期间残差本来就使输出偏离目标，反复转场还会持续建立残差；不能据此宣称一般意义上的零延迟。

脚部位置即使连续，也可以连续地离开地面。[根运动与足底接触](turn-in-place-foot-sliding.md)研究的是另一组约束，不能借用本条标量数学结果宣布脚滑已解决。

## 数值证据状态

[有限夹具](../../research/experiments/scalar-inertialization/README.md)在实现前冻结协议 `b39a921e…`：七组初值、采样时刻0、1/8、1/2、1、2秒，独立于闭式函数的两状态 RK4 步长为1/128与1/256秒。每个分量的细网格绝对误差须不超过1e-7；粗误差足够大时还需满足预定精化条件，接近舍入量级则不宣称观测到收敛阶。

作者表中细网格差异如下；L与L/s分别列出，不把不同量纲混成一个物理误差：

| 初值 (r0,u0,λ) | 最大位置差 / L | 最大速度差 / (L/s) |
|---|---:|---:|
| (0,0,2) | 0 | 0 |
| (1,0,2) | 3.46e-11 | 9.21e-11 |
| (0,1,2) | 2.30e-11 | 5.76e-11 |
| (1,2,2) | 8.06e-11 | 2.07e-10 |
| (1,−4,2) | 5.75e-11 | 1.38e-10 |
| (−0.75,1.25,0.5) | 3.47e-13 | 2.12e-13 |
| (0.25,−0.5,8) | 1.52e-9 | 1.66e-8 |

五组非舍入主导初值通过预定精化条件；零组与慢速N组不据误差比宣称阶数。两级 RK4 结果不是全域误差上界或阶数定理。

**实际有辨别力的反例：**目标从0.4t切到正弦段，再于1.125秒切到另一线性段。第一切换只补位置而把残差速度置零，会跳变约0.32926 L/s。第二切换忽略上一轮残差，则位置和速度分别跳变约0.93261 L与0.88826 L/s。完整重定位保持两侧输出及速度一致；但首切换加速度仍跳变约1.48295 L/s²，明确不能升级为C2。

另外，(1,2,2)的偏移在1/8秒增至约1.16820；(1,−4,2)在1/2秒位置为零而速度约−0.73576。采用来源理想化h=0.5秒映射后，该时刻单位初始偏移剩余约0.59657而非0.5。这些是预期反例，不是被隐藏的失败。

残差分区用30/60/144等分与不规则步长，事件比较统一切开0.75和1.125秒。观测到的微小分区差在冻结阈值内；不把它表述为位级确定性或不同输入采样下仍等价。

作者 normal/`-O`各执行8个测试方法；独立复核复制相同源码再次各执行8个，覆盖仍是同一套八方法。139项守卫输入/输出子检查属于其中一个方法，不另算139个场景。复核者在查看作者实现与结果之前，先写并运行自己的ODE积分器；其后对四份结果检查35组双状态采样及转场。独立细积分与最终输出的差约为8.57e-12 L、2.29e-11 L/s。四次测试套件运行、一次独立参考积分、随后静态读取应分别记账，不混成更多测试情境。初次运行无失败，冻结阈值未修改。

这里的独立性指分别编写、未调用闭式函数；两个积分器都采用经典RK4，不是两个不同数值方法家族。源代码审查、代数推导、误差表与反例共同支持这个有限实现，而非仅信任一个PASS字段。

## 适用限制与来源

需要显式转场与可信目标导数。任意采样片段的速度估计、旋转四元数、关节限制、实际骨骼、根运动、碰撞与引擎时序不在本单位内。接口只接收精确内建int/float（不含bool），坐标与速度绝对值不超过100、λ在[0.125,16]、dt在[0,8]；非有限、越界输入或越界输出会拒绝，不夹紧。输入范围不是输出不变集，极端组合可能合理地被拒绝。参数域与数值拒绝规则见有限协议；不把有限样本当作全域浮点稳定性证明。

归档测试需要新的输出路径，并同时检查本次退出状态与当前报告；旧JSON不能证明新的调用成功。该小型夹具不是执行认证或通用故障安全运行器。
