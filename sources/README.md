## 更新规则

1. 新增结论必须能定位到实际读取的来源或已执行实验；搜索结果摘要不代替正文。
2. 版本化 URL 仍可能变动。维护时检查正文版本；可变分支不能伪装固定修订。
3. 资料受限或读取失败时记录缺口，换合法可读来源，不绕过访问控制。
4. 原创契约、建议实验和实际执行结果分别标明；无法观察的状态保持未知。
