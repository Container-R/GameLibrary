# 着色器变体的观察点与证据边界

- Unity 6.0 [构建回调](https://docs.unity.com/en-us/engine/6000.0/manual/building-and-publishing/build-customize-build-pipeline/build-callbacks) 按同类回调顺序值由小到大；[OnProcessShader](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityeditor/build/ipreprocessshaders/onprocessshader) 提供构建前图形着色器候选，不等同包内数据。
- 固定 Unity Graphics 提交 [ShaderPreprocessor.cs](https://github.com/Unity-Technologies/Graphics/blob/52dcb5726277b769559de8bf0155f7b021bea913/Packages/com.unity.render-pipelines.core/Editor/ShaderStripping/ShaderPreprocessor.cs#L96-L170) 可定位候选计数、移除、报告调用与顺序 0；[ShaderStrippingReport.cs](https://github.com/Unity-Technologies/Graphics/blob/52dcb5726277b769559de8bf0155f7b021bea913/Packages/com.unity.render-pipelines.core/Editor/ShaderStripping/ShaderStrippingReport.cs#L187-L330) 显示逐片段输入、输出计数，报告名称来自 Pass、SubShader、ShaderType，不枚举关键字组合。运行包不由此文件证明。
- Unity 6.0 [变体数量](https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/shaders/shader-troubleshooting/shader-reducing/shader-variants/shader-how-many-variants) 和 [URP 剥离报告](https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/built-in/shaders-in-universalrp/shader-stripping) 给出阶段计数与报告入口。[变体剥离文档](https://docs.unity.com/en-us/engine/6000.0/manual/materials-and-shaders/shaders/shader-troubleshooting/shader-reducing/shader-variants/shader-variant-stripping) 指出 OpenGL、OpenGL ES、Vulkan 不按阶段后缀限制。
- [Strict Shader Variant Matching](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityeditor/playersettings/strictshadervariantmatching) 区分精确查找失败与默认相近匹配；[Frame Debugger 详细字段](https://docs.unity.com/en-us/engine/6000.0/manual/analysis/graphics-performance-profiling/profiling/frame-debugger-window-event-information) 区分实际使用、原始着色器及 Pass。日志没有每次绘制的完整身份；需要结合单一诊断场景与抓帧，不能由日志静默推断成功。
- [模型与限制](../实验/shader-variant-runtime-evidence/README.md)：验证的是证据规则，不是 Unity 的运行、包上传或 GPU 绘制。
