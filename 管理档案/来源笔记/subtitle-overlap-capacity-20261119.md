# 字幕交叠与屏幕容量：来源说明

核读时间：2026-11-19（北京时间）。邻近《怎样让关键声音信息不只依赖听觉》聚焦重要非语音事件的可达性与时效，不提供两段对白的多时段排版可行性判定。

1. W3C [WebVTT](https://www.w3.org/TR/webvtt1/)，引言的交叠时间示例与 cue timings。格式允许 cue 时间部分重叠，不等同于指定游戏渲染，也不由此断言正文模型为 WebVTT 的合规实现。
2. Microsoft [XAG 104](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/104)，Implementation guidelines：说话者身份、可调整字号、呈现行数通常不超过两行而特别情形允许三行、最大字号不能遮挡关键目标。正文两行为教学安排，并不将 Microsoft 建议转为跨设备的唯一规则；没有搬用某语言的阅读速度或复现指南内游戏截图。
3. 原创固定时间候选的容量检查见 [试件](../实验/交叠对白的字幕容量/README.md)。只核预定的可显示时间与行数，未实测手机/主机布局、引擎、配音、玩家理解和视觉负担。
