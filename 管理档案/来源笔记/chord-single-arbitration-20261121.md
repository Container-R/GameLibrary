# 单键与组合键仲裁：原始资料及证据

- Unity，[Input System 1.17: Action Bindings](https://docs.unity3d.com/Packages/com.unity.inputsystem@1.17/manual/ActionBindings.html#one-modifier)，One Modifier 使用按住的附加控件门控另一控件。这里只用作文中前置修饰的参照；项目演示的 A 先按、80 ms、输入代次和批次封口均不是 Unity 默认行为。
- Microsoft，[Xbox Accessibility Guideline 107](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/107)，同时按等复合要求无法避免时，提供体力要求更低的替代或绕过方式；无 80 ms 建议。
- [合成输入回放](../实验/单键与组合键仲裁/README.md)核查互斥、边沿、截止、取消和设备作用域。设备复位方案与额外网络或输入等待是工程取舍；没有实测引擎或设备。
