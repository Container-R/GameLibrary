# 不依赖颜色的状态：来源与证据

- W3C WAI，[Understanding SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum)：Contrast ratio、Relative luminance 的 sRGB 解码与计算。未把网页阈值应用为游戏的统一指标通过条件。
- W3C WAI，[Understanding SC 1.4.1](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color)：仅颜色传达含义的限制、某些情况下的明暗差，以及必须辨认特定颜色时另有可见表示的边界。不是对屏幕朗读的替代。
- Microsoft Game Dev，[Xbox Accessibility Guideline 103](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/103)，Symbols and shapes、Color、视觉及非视觉提示。已实际看 [Grounded 制作菜单的配图](https://learn.microsoft.com/en-us/xbox/images/gaming-accessibility/grounded-craft-menu.png)：同一个缺材料场景的数量文字、警告三角和红色强调。截图只作引用定位，不随本实验包复制，不作用户研究证据。

[复现实验](../实验/非颜色状态标记/README.md)只包含原创色值和符号、尺度模型、SVG；未运行游戏或进行真实玩家试用。
