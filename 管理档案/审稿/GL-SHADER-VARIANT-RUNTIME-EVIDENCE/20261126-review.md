技术、读者、导航均为独立模型审查，不是实际 Unity 开发者或项目验证。技术审稿独立跑八组结果和 1/1 同数不同成员的对照，核对 Unity 6.0 文档、固定 Graphics 源码的报告字段及采样时点，指出 Vulkan 等后端不能按阶段后缀作裁剪假设，已修订并复核终稿。

读者用同一诊断 Player 的 Vulkan 冰霜缺失场景。初稿没有让读者核实具体绘制与严格错误的对应；补充最小场景、Pass/原始与实际着色器、编译器平台和关键字成员，以及无法关联时保留未知。复核后读者按正文完成检查，能区分请求与阶段消失、下游和证据不足。

导航从根盲走按学科浏览、引擎与工具、构建发布、着色器构建到唯一正本。新实验材料随逻辑变更交付，旧旁链以实际基线核对。对源代码和模型的审查不代表运行过 Unity、GPU 捕捉或玩家测试。
