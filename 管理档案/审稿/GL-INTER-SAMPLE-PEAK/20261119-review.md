## 技术审稿：通过

通读正文后核对 ITU-R BS.1770-5 附件 2 与 FFmpeg 官方滤波器文档。重跑复现脚本，原始 JSON、图与记录逐字一致，目检中文图示。改正 ITU 附件中处理步骤与小节编号的混淆；技术审查者核对终版只有该项修正，结论不变。

另用原 12 kHz 输入走 48→48 kHz s16，样本峰约 0.8、无整数端值；48→16 kHz 时该频率被滤掉，浮点峰约 0.00000551343、整数端值数为零。输入真峰越过标称满量程不等于每条整数路径都会削顶，必须在实际路径核实。末尾 −66.4/+0.5 dBTP 是该构建与试件的实测边界，不宣称所有表头都漏尾。

## 读者与导航审读：通过

从项目根按学科进入声音与音乐 → 音频制作 → 混音；也实走声音与音乐 → 游戏音效 → 音频渲染的交叉入口，两条路到同一正文。目检幅度线和采样标记，图文一致。按正文自行设计三条武器音效同帧、总线 +1.4 dBTP、设备输出 44.1 kHz 整数的变例，能指出在哪里采集、如何控制变量并判断首次夹紧；设验收上限 −2 dBTP 时算出静态衰减名义值 3.4 dB，再留余量并实际重测。能区分修正前置增益与单纯调小已损坏的录音。终版复核绑定实际正文。
