## 独立任务：分出一致与不一致的整个区间

### 输入

同一同步组内的两个循环片段，左右脚落地事件已经确认语义一致；本次只讨论相邻左脚落地至右脚落地之间，不跨循环边界。

- 走路 A：片长 1.2 秒；左脚落地 0.20 秒，下一右脚落地 0.80 秒。左脚接触保持至 0.95 秒。上一段右脚接触到 0.32 秒结束。
- 跑步 B：片长 0.90 秒；左脚落地 0.10 秒，下一右脚落地 0.60 秒。左脚接触到 0.30 秒结束。上一段右脚接触已在 0.08 秒结束。
- 本次制作要求：在对应事件区间的进度 25%–65% 内，混合素材都应保留左脚单支撑，不能把腾空混入这一段设计好的支撑过渡。
- 接触记录以触地时刻包含、离地时刻不包含解释；下文比较区间进度 `0 ≤ u < 1`，不把下一右脚触地端点混入前一段。

### 1. 先完成事件区间映射，而不替它附加接触结论

由正文第 20–24 行，可写出这对事件之间的对应时刻：

- `tA = 0.20 + 0.60u`
- `tB = 0.10 + 0.50u`

例如 A 在 0.62 秒时，`u = (0.62 − 0.20) / (0.80 − 0.20) = 0.70`，B 应对应 `0.10 + 0.50 × 0.70 = 0.45` 秒。

若误用整段进度，A 的整体进度是 `0.62 / 1.20 ≈ 0.5167`，B 会到 0.465 秒，其事件区间进度为 `(0.465 − 0.10) / 0.50 = 0.73`。因此区间同步改正的是 0.70 与 0.73 的事件相位差，并未从数字本身推出脚是否接地。

这一步所需方法与条件在原有第 9–26 行，修订后仍完整且未被新增说明否定。

### 2. 按正文要求并排比较接触事件，找出所有变化点

正文第 38 行说明端点没有离地信息，第 40 行明确要求对照左右脚接触区间或触地、离地事件。依据这一步，我把输入中的离地时刻转换到同一事件区间进度：

- A 上一右脚离地的进度：`(0.32 − 0.20) / 0.60 = 0.20`。
- B 左脚离地的进度：`(0.30 − 0.10) / 0.50 = 0.40`。
- A 左脚在整个当前区间都接触，因为它到 0.95 秒才离地，晚于当前区间的终点 0.80 秒。
- B 上一右脚已在当前区间之前离地，下一右脚直到当前区间末端才落地。

所以整个区间分为三段：

1. `0 ≤ u < 0.20`：A 双脚支撑，B 左脚单支撑。事件区间进度一致，支撑状态不同。
2. `0.20 ≤ u < 0.40`：A、B 都是左脚单支撑。两项检查均通过，但仍没有世界位置的保证。
3. `0.40 ≤ u < 1`：A 左脚单支撑，B 双脚腾空。事件区间进度一致，支撑状态不同。

单点交叉检查：`u = 0.30` 时，A 为 0.38 秒、B 为 0.25 秒，两者确实都在左脚接触区间；`u = 0.70` 时，A 为 0.62 秒、B 为 0.45 秒，A 仍左支撑，B 已腾空。

这一结果不靠猜“同名落脚是不是同一支撑状态”，也不需要全文之外的同步理论。我只用正文给出的时间对应方法、接触区间比较要求及输入提供的观察值完成运算。

### 3. 根据制作意图作决定，而不是统一要求走跑接触完全相同

本次要求在 `0.25 ≤ u ≤ 0.65` 保持左脚单支撑。两段素材只有 `0.25 ≤ u < 0.40` 满足这个要求，`0.40 ≤ u ≤ 0.65` 不满足。因此不能把当前两个落脚标记对齐当成整段目标已完成。

依据第 40 行，应重新选择能表达所需支撑的事件对应或参与片段，再复核所要求的时段。不能只来回调整总播放速度，也不能凭已有两个落脚事件就直接批准这段过渡。

改变结论的条件：若制作意图允许走跑转换在后半段进入腾空，则上述状态差异不再自动构成失败。第 40 行明确不要求走跑天然拥有完全相同的接触状态。即使允许该差异，仍需观察最终接触点与动作质量，而不是因此宣布脚滑问题已经解决。

正文没有给出能够满足任何制作目标的自动重映射算法；本任务也没有据此凭空指定一个必定成功的新片段或强行添加同名离地标记。对于文章承诺的检查与采用判断，已能给出具体拒绝区间及下一步方向。

### 4. 保留空间误差这一独立关卡

即使限制在两段都为左脚单支撑的 `0.20 ≤ u < 0.40`，也不能认定脚已锁住。第 42–44 行明确将步幅、骨架比例、脚轨迹与实际角色运动列为另外的检查对象，要求观察接触点。
