## 独立代表任务及完成结果

下列输入由审读者新设，不是原文数值或真实运行记录。

**输入前提：** 制作人员确认循环 A、B 的“左脚落地”均为同一类接触事件，“右脚落地”亦然。A 长 1.2 秒，相邻左/右标记为 0.15/0.75 秒；B 长 0.9 秒，相邻左/右标记为 0.18/0.63 秒。当前 A 为 0.45 秒。这两个区间都非零、不跨循环边界，当前时间位于指定区间中。另有拟加入的片段 C，其左标记实际标的是全脚掌压稳，而 A/B 左标记是脚尖刚碰地，且 C 没有右标记。

任务：判断整体百分比是否对齐阶段，求一个有限的区间对应结果；决定加入 C 前后应检查什么，并说明结果能否作为脚接触验收。

1. **整体同步结果。** A 的总进度为 0.45/1.2=37.5%，故 B 整体同步时间为 0.3375 秒。A 在标记区间的位置为 (0.45−0.15)/(0.75−0.15)=0.5；B 为 (0.3375−0.18)/(0.63−0.18)=0.35。两段整体进度相同，却不处于同一相邻事件区间进度。依据：“整段进度相同……”节给出的定义和计算过程。
2. **区间映射结果。** 用 A 的 0.5 映射到 B，得到 0.18+0.5×(0.63−0.18)=0.405 秒。这只保证在已确认对应的区间内均处于中点；B 此时整段进度为45%，无须仍是37.5%。依据：“先对应这一段步态……”节的映射式。这不是对 UE 内部选段行为的预测。
3. **C 的语义问题先处理。** 同名左标记并非同义，不能直接声称可以对应。应让制作人员统一事件定义并重新检查时间，再谈同步。依据：“加了标记……”节直接对比脚尖碰地与全脚掌压稳，不需要从专业常识另补规则。
4. **C 的共同标记问题。** 若 C 确实作为同组参与资产加入，要重新核对实际参与片段及共同标记。C 缺右标记时，不能把原来的左右区间公式直接当当前运行算法；同时也不能只凭缺右标记便宣称完全回退长度同步，因为左标记仍可能共有。只有没有匹配标记时，文章才支持长度同步的回退判断。实际如何选区间和运行状态须在工程里核对。依据：第三节对“少一个标记不等于一定完全回退”的明确限制。
5. **不能验收脚接触。** 即使把 B 调到0.405秒，或处理完 C 的事件语义，也只完成时间关系检查。步幅、骨架比例、脚轨迹及控制器实际运动仍可能不同，须观察各自接触时段内的接触点。依据：最后一节。本文没有给接触误差阈值、锁脚求解或碰撞处理，故我不能仅凭这些时间计算报告脚不滑或修复通过。
6. **何时停用手算。** 跨循环边界、区间长度为零、标记重复导致配对不明、事件语义未确认、参与资产改变后共同区间已不明确时，当前算例的输入条件不成立，不能悄悄沿用上述公式作引擎结果。正文明确限制前几项输入，并明确不复现跨界、重复匹配和内部选段；未给其解决算法，因此这里的操作结论是先核对工程与对应关系，而不是自行发明规则。
