# 动画标记区间对应：来源与读者审查

2026-11-05。脚滑排查正文增加循环步态选读入口，不新增书目或引擎实验。新支持全文 SHA-256：`0cc283e1127e1e9c49ff898ba60d3dc5db555e7bd2a3a0a2339a7b372b41648f`。

完整阅读现有动画师、脚滑正文及 Notify 执行资格说明后，检索支持、来源和历史资料。已有说明涉及支撑阶段、几何混合与事件资格，没有给出整段进度和相邻标记区间进度的区别。新说明不重复事件权威或锁脚实现。

主编与独立来源审者读取 Epic 明示 Unreal Engine 5.6 的 Animation Sync Groups 文本，重点为 Overview 与 Marker-Based Syncing。来源审者另比对5.7相关文字，但正文只引用5.6。版本选择网址不是不可变实现；未看动图、读引擎源码或运行角色。

原创例子限定两对含义对应、非零长度、相邻且不跨循环的事件区间。A长1秒、左右标记0.2与0.7秒，B长0.8秒、对应标记0.1与0.5秒。整段45%令A区间进度50%、B区间65%；以区间50%对应则B取0.3秒。数值独立重算通过，不冒称引擎轨迹。只缺一种公共标记并不据此断言完全回退；未推断最少数量、重复名称匹配或动态成员实现。时间位置正确不约束世界脚点。

初稿标题使用“一半”而算例为45%，已改“播放进度相同”；初稿接入建议涉及起步/停止，已限为另一循环步态，避免未说明非循环配置要求。独立全文读者审查确认计算与边界，并指出节标题把时长和进度混淆、同步组归属措辞不准；已分别改为整段进度和动画归属，最终载荷另行复核。
