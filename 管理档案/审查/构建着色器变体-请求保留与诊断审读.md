其余关键事实与独立核对的官方条款一致：`_local` 不由同名全局 API 替代；`multi_compile` 并非不可被构建回调移除；Strict 匹配实际启用与覆盖后的组合，而不补回变体或判断美术意图。相近匹配只是条件性的缺项处理，候选没有预测具体画面、把无粉色当成功，或把 SubShader 回退混作同一机制。

保留更多组合的构建负担只是一般取舍说明，没有量化性能或特定平台承诺。末段普通／强化状态的接收建议明确未执行；平台、渲染管线、材质与 pass 均已限定。有效请求错误、缺项及未触发状态的边界没有遗漏。
