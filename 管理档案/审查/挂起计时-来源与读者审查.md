# 挂起计时：来源与读者审查

为[固定时间步正文](../../GameLibrary/玩法程序/玩法系统/时间与模拟/用固定时间步组织战斗模拟.md)补充[设备挂起与本地倒计时](../支持资料/设备挂起的时间，应该算进倒计时吗.md)的可选解释。不增加书目，不改原累加器算法、输入分配或历史实验。

作者之外的独立代理重新读取 Linux man-pages 的 CLOCK_MONOTONIC、CLOCK_BOOTTIME 说明与版本页脚，并审阅整篇支持、原正文及两处修改。单调性与是否计入系统挂起应分开；同一计时域内2秒工作、30秒挂起、1秒工作的理想推演分别为3秒与33秒，10秒本地期限余7秒或已到。系统工作不等于线程占用CPU。游戏暂停政策、既有模拟欠账、服务器状态和唤醒执行没有混为一谈。

旧正文的每轮更新基准以主循环仍执行为条件；新增文字只补充系统挂起后的首次更新前提，不声称原实验检测了挂起。没有调用计时接口、调整系统配置、执行挂起、运行引擎或真人测试。来源为可更新的man-pages页面，记录文档版本，不认证安装环境。
