### NIST SP 800-142, Practical Combinatorial Testing

官方来源：https://nvlpubs.nist.gov/nistpubs/legacy/sp/nistspecialpublication800-142.pdf 。本轮成功打开官方 PDF（82页），并提取同题原始 PDF 的正文阅读以下段落；不是用搜索摘要代替原文。

- 印刷第9–10页 §2.2：输入产生后仍需判定期望输出，讨论崩溃检查、嵌入断言和模型判据。支持正文把配置覆盖与实际正确性分开。
- 印刷第16–17页 §3.3.1：删掉不可测试配置会连带删除其他必要搭配，原例指出 Linux/IPv6；可手工补齐，也可生成时引入约束。支持文章的删行警告，不能简化成“过滤就完成”。
- 印刷第19–20页 §4.1：分区需有规格依据，任意取范围中点可能错过条件，边界及相邻值可揭示比较符错误。支持文章的断点遗漏说明。
- 印刷第21页 §4.3：强度上升影响测试数，选择须考虑资源及收益。原文也讨论逐阶增测启发式；正文没有把启发式升级成保证，没有挪用缺陷检出率。
- 印刷第23–24页第5章：事件的相对顺序不要求相邻，正式定义允许中间插入其他事件。支持正文区分顺序与相邻，不把静态配置当操作序列。
- 印刷第29–31页 §6.2.1–6.2.3：完整覆盖的参数组比例与值组合覆盖比例是不同度量。正文报告45个有组身份的合法对子，没有把10组与45个值组合混成同一分母。

### NIST User Guide for ACTS, Basic 1.0 / Advanced 3.3

官方来源：https://csrc.nist.gov/csrc/media/Projects/automated-combinatorial-testing-for-software/documents/acts_user_guide_for_basic1.0_and_advanced3.3_versions_nov23.pdf 。本轮直接打开并读取官方21页 PDF 的以下段落。

- 第1页 §1.1：IPOG-D 与 IPOG-F2 不支持混合强度、约束或负向测试。
- 第2页 §1.2–1.3：参数关系组可以重叠或包含，混合强度及约束支持限定 IPOG、IPOG-F；无效行若是某合法组合的唯一承载者，会损害覆盖。
- 第3页 §1.5 与 CLI：可以验证外部或自产测试表；`doi=-1` 用于混合强度。
- 第4页 CLI：`chandler=no` 忽略约束；`check=on` 开启生成后覆盖验证，默认 off。
- 第13–15页 §3.2：固定数字强度只使用该数字，Mixed 使用模型内关系；Ignore Constraints 会忽略约束。支持文章要求核对实际运行选项。
- 另读第20页 §3.6：GUI Operations → Verify 可验证外部表，验证时仍需正确的 Mixed 和 Ignore Constraints 设置。

来源与正文主张一致。文章对 ACTS 的定位是采用工具时的契约，不是声称完成导入或测得工具行为，符合其真实证据范围。
