# 旧入口兼容与生成器保护

2026-11-01。根 DISCOVERY.md 与 CATALOG.md 不再提供旧的平铺分类和维护状态清单；它们作为已有书签的兼容入口，转向 GameLibrary 导览及根首页。旧版本仍在 Git 历史里，没有搬运执行记录或复制成第二套现行目录。

旧路线生成器现在仅能写入“管理档案/草稿”下的 Markdown，按输出目录生成正确相对链接。写入及检查模式均拒绝根 README、DISCOVERY、CATALOG，也拒绝覆盖规范图书清单。固定清单不由这个旧元数据工具重建。它仍可供维护者分析历史关联，不是读者目录生成器。

作者在正常与优化模式下各执行16个测试方法；主集成在最终脚本位置执行同一16方法通过。这里包含原11方法和新增5方法，不能算成三组互不重复的新测试。保护路径、嵌套草稿链接、缺失与陈旧输出，以及静态符号链接误指向均在有限测试中覆盖；不声称抵御恶意并发文件替换。

历史审查脚本中指向旧 DISCOVERY 的生成/检查命令会被新保护拒绝。旧记录描述的是当时版本，不再代表新读者入口的当前检查结果；本次未修改历史归档。真正的书架覆盖与定向读者导航另作检查，脚本通过不能证明全库文字达标。
