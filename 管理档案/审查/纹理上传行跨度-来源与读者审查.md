# 纹理上传行跨度：来源与独立读者审读摘要

2026-11-02。接受现有纹理预算正文的一条可选入口与渲染侧支持，不新增书。门槛作者与独立审者分别读取固定 Microsoft DirectX-Headers v1.614.1 提交 `48a762973271c5a75869946bf1fdbc489a628a5c` 的逐行复制及 UpdateSubresources 相关路径；独立审者另外重开 Microsoft GetCopyableFootprints、D3D12_SUBRESOURCE_DATA 与 DDS File Layout 原文。

独立机制审读和全文读者视角审读接受：来源与目标各用自己的行跨度，每次只复制有效行字节。两行128/256例是条件算术，不是设备返回或上传结果。一次复制256字节会错放第二行；照目标跨度乘行数读512字节则超过只有256字节的来源。有效写入末端 O+384 不等于整个分配量。来源已经匹配目标布局时可能整块复制的例外保留。

支持明确正行跨度、二维单切片、不重叠且足够范围；BC使用块行。多切片、其他子资源、容量与溢出、资源状态、同步和上传缓冲区寿命另需处理，helper不被称为安全解析器。没有把256/512推广到所有特性或平台，没有编译、API/GPU执行、图像或性能结果，也没有继承旧CPU预算检查作为上传验证。

全文读者审读绑定支持 SHA-256 `6921aa9e3df8d483326982eb7c007b0a88afb191d145b78760ce477e16b92dee`。原预算正文 SHA-256 `3a70434fd5edb60ed6ed30468eb5d90b50c04e283ea9e7de7422648fecad7f95` 的全部内容保持，仅在row pitch段之后增加选读入口；移除该入口可恢复原字节。60×40算术、历史CPU范围及既有梯度支持保留。

这是一份独立代理审读的公开摘要，不是原内部报告逐字副本、真人可用性测试或全库审查。实际本批入口整合与载荷仍需分别核验；本记录与支持在同一修订中归档，不用本地接受宣称已完成远端发布。
