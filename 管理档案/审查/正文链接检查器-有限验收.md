# 正文链接检查器：有限验收范围

本次新增的工具位于[维护工具目录](../工具/library/README.md)，用于减少正文相对路径写错后漏检的风险，不是通用 Markdown 解析器。

早期候选虽通过其自带测试，独立审查仍构造出假通过：空白正文、段落或列表后的缩进链接、跨行标签、非法代码围栏和跨行 HTML。两轮拒绝促使实现明确报告不能解释的语法，而不是吞掉内容后返回成功。后来又把未闭合或跨行的行内代码、含 HTML 实体的目标限定为不支持，避免误报为已确认的坏链接。

最终代码以版本库中的字节为准；35 个测试方法在普通 Python 和 `-O` 两种模式下运行，是同一有限测试集的两种执行，不是 70 个独立案例。独立审查额外重放早期反例并检查 CLI 非零退出。以上不证明所有潜在 Markdown 写法都已正确识别。

真实图书目录扫描仍为 **incomplete**：58 篇正文中识别到 133 个本地链接、22 次片段检查，未报告可判定的目标或片段错误，另有 31 项不支持。不能把这些不支持项改称通过，不能用结果证明外部来源有效、渲染后锚点完全相同、正文易读或全库全部链接正确。后续发布仍需要检查变更正文的实际路径及最终提交树。

本记录仅保留合成输入的失效类别与验收范围，不附运行环境信息。没有执行游戏、构建资产或开展真人检索测试。
