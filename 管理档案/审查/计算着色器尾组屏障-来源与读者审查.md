# 计算着色器尾组屏障：来源与读者审查

2026-11-03。接受有限来源分析，不是 GPU 验证。

## 阅读与范围

定向完整读取 Khronos GLSL 4.60.8 的 §2.6、§3.8.2、§4.3.8、§7.1.6、§8.16–8.17，以及 Microsoft GroupMemoryBarrierWithGroupSync 的技术正文。核对了封面版次、组内调用身份、共享变量初始状态、控制流会合及两类屏障的不同职责。没有通读整份 GLSL 规范、检查驱动、编译或派发着色器。

独立来源审查复核十项整数分成两组的推导：组尺寸 (8,1,1)，派发尺寸 (2,1,1)，第二组仍有八次调用；无有效输入的六次各写零并参与同一屏障。结果仅是 36 和 19 两份小计。容量、非重叠输出、只读输入是示意前提，不是经过运行验证的资源状态。

独立读者审查完整阅读支持及宿主入口，能区分输入访问条件、共享槽初始化和同步参与条件。一次措辞修订把无效槽写入责任说得更直接，最终稿重新核读。未把语义违规包装成某块 GPU 的实际死锁，也未把零贡献推广到最大值等任意操作。
