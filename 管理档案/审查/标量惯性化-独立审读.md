## 独立代数核查

以 `E=exp(−λs)`、`b=u₀+λr₀` 简写，直接求导：

```text
r′ = [b − λ(r₀+bs)]E = (u₀−λbs)E = u
u′ = (−λb−λu₀+λ²bs)E
2λu + λ²r = (2λu₀+λ²r₀−λ²bs)E
u′ + 2λu + λ²r = (−λb+λu₀+λ²r₀)E = 0
```

`s=0` 恢复两个初值。λ>0且段内固定时，线性多项式乘负指数在无限时间趋零；这不是有限时清零保证。`b` 的量纲为位置/时间，`bs` 为位置，`λbs` 为速度；ODE各项都是位置/时间²。新文秒与每秒单位说明正确。

- 开篇：旧原值2加残差1得输出3；速度1加残差速度1得2。新目标1、速度−1，初始化得到r₀=2、u₀=3，新输出仍3/2。若只用旧片段，得到r₀=1、u₀=2，输出2/1，恰好丢掉前次残差。此处是同刻手算，不是角色观测。
- 区间：1.125−1.0=0.125秒，1.2−1.125=0.075秒，合计0.2秒。切分和终点配对正确，不把整段时间错误施加给新目标。
- 过零：r₀=1、u₀=−4、λ=2，则b=−2，半秒时r=0、u=(−4+2)/e=−2/e，约−0.736。只按位置归零结束会切掉非零速度。临界阻尼不保证任意初值单调逼近，新文未作此错误推论。
- C¹需每段目标的一阶连续性及切换点对应有限单侧值/导数；以这些值重定位才匹配左右位置和速度。新稿已给这些条件，不是声称任意噪声采样都自动C¹。若二阶导数存在，新侧加速度确为p″−2λu−λ²r，不保证与旧侧相同；因此不能推C²。
- 零残差时不额外追踪滤波目标，但非零残差仍带来偏离；半衰期也不能忽略含初速的多项式因子。有限精度、下溢、非有限值及反复重建的限制均保留，未宣传普遍零延迟或全域稳定性。

以上未使用数值积分、引擎或模型执行验证。
