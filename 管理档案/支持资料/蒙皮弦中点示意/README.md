## 重画与实际检查

[generate.py](generate.py)只用Python标准库生成SVG与[geometry.json](geometry.json)。两轴使用同一每单位260像素比例，屏幕Y取反；图中的小数是理想几何坐标的数值绘制，不是蒙皮运行输出。SVG保留文本和字体名称，不附字体文件；不同阅读器或可用字体可能改变字形排版，不承诺跨环境像素一致。

为重画，可在自己的工作副本中用已有Python3和Inkscape执行：

```sh
python3 render_isolated.py --run-name reproduction-1
```

[外层](render_isolated.py)与[冻结协议](RENDER-PROTOCOL.md)先按[输入manifest](render-manifest.json)核对原件，复制到全新独占目录并再次核对，再准备HOME/XDG/TMP可写位置。生成限10秒、渲染限30秒；仅适用于这里的有限POSIX流程，不是安全沙箱，也没有实际触发超时测试。不存在所需软件时应失败，不自动安装。协议中“尚未第二轮执行”是冻结前状态，实际结果另由回执记录，不事后改写输入。

2026-11-03的新隔离执行[回执](render-result.json)记录两个命令均返回0，输入复制核验和环境准备完成。随后实际查看最终PNG、核对几何与文字，没有只凭命令成功接受图片。最终SVG摘要为`122267e9a0b0c1f2f1ff4eb581e53b4aeb2455a1b46481a78eb1ab2f132f074d`。

渲染stderr并非空：出现PangoFT2FontMap与GtkRecentManager对象封装警告。保留了原始日志，没有消警重跑；本文仅接受实际看过的这个有限图示，不据此断言渲染器或其它字体/功能无缺陷。PNG是本地视觉检查产物，不随包发布；其文字元数据实际仅含公开软件网址标记，没有把该检查冒充所有文件格式的隐私保证。发布的SVG、坐标JSON、输入与回执保持该轮原字节。

首次绘图没有满足环境准备规范的事实见[初次限制](INITIAL-EXECUTION-LIMIT.md)。新执行不覆盖初轮，也不把绘图两轮包装为独立蒙皮复现。
