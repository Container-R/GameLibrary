# 按玩家汇总后，怎样估计场次完成率的近似方差

把每名玩家的完成场次数与合格场次数各汇总成一列，能够保留“全部合格场次中有多少完成”的指标。下一步若想估计它的不确定性，还必须说明数据怎样产生。**本篇从一开始就改用另一个模型：只看一个实验组，假设不同玩家的两列汇总量是独立同分布的随机向量。** 下面的推导研究玩家数逐渐增多时的近似，不接着计算“四名固定玩家、六种分配”的有限随机化例子。

这个区别决定公式能回答什么。玩家内的场次可以相关，完成数也可以与场次数相关；但玩家之间是否独立，仍须另有依据。分组发生在玩家身上，并不会自动证明这里的抽样模型成立。

本篇面向需要理解统计交接材料的开发者，说明怎样从两列玩家汇总量得到一个保留原指标的近似方差。它不提供置信区间、显著性检验或上线标准。

## 先确定要保留哪一个比例

设这一组纳入了 K 名玩家。对第 i 名玩家，记：

- Sᵢ：预定观察窗口内完成的合格场次数；
- Nᵢ：同一窗口内的合格场次数。

两者必须使用一致的纳入规则。完成计数满足 0 ≤ Sᵢ ≤ Nᵢ。用上横线表示按玩家求平均，例如 S̄ = ΣᵢSᵢ/K、N̄ = ΣᵢNᵢ/K。整组的场次完成率为

R̂ = ΣᵢSᵢ / ΣᵢNᵢ = S̄ / N̄。

这里每场仍占相同权重，玩得多的玩家会贡献更多场次。若改成先求每个人的完成率，再把这些完成率平均，就把问题换成了玩家等权的平均表现。两种问题都可能有用，但不能互相替代。

在本篇的抽样模型里，用 E 表示总体期望，定义 μS = E[Sᵢ]、μN = E[Nᵢ]。估计目标是

r = μS / μN。

它是“平均每名玩家的完成数”与“平均每名玩家的合格场次数”之比，不是个人完成率的总体平均。还要注意，**即使只在总场次数大于零的样本上讨论 R̂ 的平均值，它也不必恰好等于 r**。这项近似方差计算没有消除有限样本偏差，更不会把无定义的比例自动补成0。

## 把比例的波动写成玩家残差的波动

Delta 方法的做法，是把一个平滑函数在总体均值附近作一阶展开，再利用均值的抽样性质。Deng 等人的方法论文在群组指标中使用了这一思路。[1] 对本篇的比例，可以先从一个精确恒等式出发：

R̂ − r = (S̄ − rN̄) / N̄。

注意分子。把 rNᵢ 作为按总体比例换算的比较基准，Sᵢ − rNᵢ 就是实际完成数与该基准之差。这不是断言不同活跃度的玩家都有相同完成机会，也没有假设给定 Nᵢ 后的预期完成数一定等于 rNᵢ。这里减去的是与场次数有关的量，而不是给所有玩家减去同一个常数。

为了让接下来的近似成立，采用以下充分条件：

- 不同玩家的整对数据 (Sᵢ,Nᵢ) 独立同分布；Sᵢ 与 Nᵢ 之间无需独立。
- μN > 0，且 Sᵢ、Nᵢ 的二阶矩有限，即平方的总体平均有限。在完成计数场景中，要求 E[Nᵢ²] 有限便同时约束了 Sᵢ。
- 考察的是同一总体下 K 不断增大的情况，而不是让固定的几名玩家不断增加场次。

在这些条件下，N̄ 会趋近 μN；分子是均值为零的独立同分布玩家量的平均。将分母在一阶项中换成 μN，得到

R̂ − r ≈ (1/K) Σᵢ(Sᵢ − rNᵢ) / μN。

因此，一阶近似的方差规模为

Var(R̂) ≈ Var(Sᵢ − rNᵢ) / (KμN²)。

Var 表示方差，衡量随机量围绕其均值的波动。严格地说，这一步给出的是大样本极限中的方差参数及其 1/K 缩放，并非任何有限 K 下的精确方差等式。若残差总体方差大于零，中心极限定理给出相应的非退化正态极限；这仍不能说明某一份小样本已足够接近该极限。

这个表达式保留了两种信息：玩家之间的完成数怎样变化，以及这些变化中有多少与场次数一起变化。只计算完成数的方差，会遗漏后一部分。

## 用样本中的量代替未知总体量

总体比例 r 和总体均值 μN 通常未知。将它们分别替换为 R̂ 和 N̄，并为每名玩家计算

Uᵢ = Sᵢ − R̂Nᵢ。

令 Ū = ΣᵢUᵢ/K。使用通常的样本方差约定：

sU² = Σᵢ(Uᵢ − Ū)² / (K−1)。

只要 K > 1 且总场次数大于零，就能计算以下代入估计：

V̂ = sU² / (K N̄²)。

V̂ 是近似方差的估计，标准误则是它的平方根。**K 是玩家数，不是场次行数；K−1 是这里样本方差采用的分母。** Uᵢ 使用了由整份样本估计的 R̂，不能把这些拟合残差当成已知总体比例下的独立观测。因此，采用 K−1 并不意味着 V̂ 对有限样本的真实方差无偏。

精确算术下，ΣᵢUᵢ = ΣᵢSᵢ − R̂ΣᵢNᵢ = 0。由此还能得到方便核对的等价式：

V̂ = [K/(K−1)] × ΣᵢUᵢ² / (ΣᵢNᵢ)²。

也可以从两列数据的协方差展开。记 sS²、sN² 为 S、N 两列的样本方差，sSN 为它们的样本协方差，三者统一采用 K−1 作分母；例如

sSN = Σᵢ(Sᵢ−S̄)(Nᵢ−N̄)/(K−1)。

那么有精确的代数关系

sU² = sS² − 2R̂sSN + R̂²sN²。

将右侧代入 V̂，就得到常见的展开形式。这与论文§3.2式(6)的结构一致。[1] 中间的协方差项不能因为“已经按玩家汇总”就删掉：完成数与场次数本来就可能共同变化。

## 三对数字只用来检查算术

取三对原创合成数据：(S,N) 分别为 (1,1)、(1,2)、(0,3)。这里只核对公式是否保留指标、分母与协方差项，**不把三名玩家当作大样本，也不据此作任何统计判断**。

总完成数是2，总场次数是6，所以 R̂ = 1/3。若改成个人完成率的简单平均，则得到 (1+1/2+0)/3 = 1/2，已经变成另一项指标。

三名玩家的残差为

U = (2/3，1/3，−1)。

残差和为0，平方和为14/9；除以 K−1 = 2，得到 sU² = 7/9。由于 N̄ = 2，代入计算为

V̂ = (7/9)/(3×2²) = 7/108。

再独立核对展开形式：sS² = 1/3、sN² = 1、sSN = −1/2。因此

sS² − 2R̂sSN + R̂²sN²
= 1/3 − 2×(1/3)×(−1/2) + 1/9
= 7/9。

两条计算路径得到相同结果。该例使用精确分数计算核对过，验证的是代数等式与算术，不是方差估计的准确程度、区间覆盖率或对真实玩家数据的适用性。 可查看[原创精确分数检查脚本](玩家完成率近似方差/check_algebra.py)：它只对固定数字执行断言，使用 Python 标准库，不读取玩家数据，也不是生产统计接口。

## 哪些时候，算出一个数仍然不够

首先检查是否存在可定义的比例。若总场次数为零，R̂ 与 V̂ 都没有定义，不能在分母补一个很小的数或把结果填成0。K ≤ 1 时，即使比例可以计算，这里的样本方差仍不可用。

单个玩家 Nᵢ = 0 是另一回事。如果预定纳入规则包含这名玩家，(Sᵢ,Nᵢ) = (0,0) 可以作为一对汇总量保留，无需求出不存在的个人完成率。是否纳入必须由目标人群与观察规则决定，不能为了让公式好算而悄悄删掉零场玩家。删去他们会改变抽样人群和 K；即使观测到的总量比不变，也不能认为分析方案完全没变。

其次，总场次数为正只是“能够计算”，不代表分母已经稳定。大量零场玩家、极不均衡的活动量，或少数玩家占据大部分场次，都可能使有限样本中的一阶近似不可靠。更多场次不能替代更多独立玩家，本文也没有据此给出一个通用的最低玩家数。

样本残差全为零，也不能单凭这一点认定总体没有波动；这可能只是当前样本没有显现总体差异。

玩家之间的关系同样重要。同一对局中的队友和对手、共享环境或共同时间冲击，都可能破坏独立性；配对、分层或从固定有限人群中抽样，也需要结合实际设计处理。玩家汇总解决了记录归属，不会自动消除这些关系。

若改版会改变玩家是否参与或玩多少场，比例本身仍可计算，但比较它时还要解释分母和场次构成的变化。这里的一组方差推导没有解决这种因果解释问题，也没有提供通用的两组比较方法。

最后，回到[按玩家分组的实验，为什么不能把每场当成独立样本](按玩家分组的实验，为什么不能把每场当成独立样本.md)的四人例子。如果恰好把两名全完成的玩家分在一组、两名全未完成的玩家分在另一组，各组拟合残差都会是0，本篇公式也会机械地给出0。**这不等于原来六种分配下的不确定性为零。** 那个例子固定玩家及结果，变化的是分组；本篇则对每名玩家的 (Sᵢ,Nᵢ) 汇总量采用独立同分布抽样模型。不能把后者的代入结果拿去替换前者的精确分配分析。

数值实现还应避免把几个很大的方差、协方差项相减，优先用残差及稳定的中心化平方和计算，并检查总量溢出与非有限结果。浮点算术下残差和未必严格为零；这些计算细节需要处理，但数值稳定也不能弥补统计模型不成立。

这项推导的用途，是让统计交接不止于“每人一行”：保留完成数与场次数的比值，明确玩家层面的抽样假设，并把两列数据共同变化的信息带入近似方差。是否能据此开展推断，仍须回到实际人群、分配设计和样本表现判断。
