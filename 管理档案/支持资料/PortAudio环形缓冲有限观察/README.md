# PortAudio环形缓冲：有限功能观察

这里保存《取得环形缓冲区的区域，为什么还不算交出消息》的复现材料。测试直接编译 PortAudio v19.7.0 的三个原始工具文件，调用实际区域与索引接口；驱动不是重写的队列。它只在一个线程中按顺序操作，不启动音频设备，也不检验实时性或并发内存顺序。

2026-11-02，主运行和另一位操作者的独立重复都完成同一组六项、每次十三阶段。独立重复在同一环境、同一编译器下重新编译，不复用主运行的二进制，不是跨平台验证。两次输出逐字相同，不把它们累计为十二种测试。

## 怎样重复

需要 Python3、可用的 C 编译器以及支持此原源码屏障分支的环境。在本目录执行：

```sh
python3 run_probe.py new-result
```

`new-result` 必须不存在。脚本先核对输入清单，再在新临时目录复制并复核源码，设置隔离的 HOME、XDG 与临时目录，重新编译并执行一次。编译上限20秒，功能运行上限5秒。缺少依赖或构建失败就停止，不安装、不修改原实现，也不定义 `ALLOW_SMP_DANGERS` 绕过分支。这里只提供复现命令，不保证其他平台的编译结果。

结果须同时检查完整输出、退出码和固定预期，不能只看一行 PASS。失败不会覆盖已有结果；尚未运行的阶段与已运行失败分别记录。原始诊断会留在结果目录的 `.local` 文件中，本次公开包不包含这些文件；未来诊断可能带有私人路径，应先审查再分享。

本次编译器自报 `cc (Debian 14.2.0-19) 14.2.0`。这是技术版本信息，不是对本机编译器二进制身份的认证。清单绑定公共源码、协议、驱动、预期与运行脚本；输出摘要用于认出记录，不是签名或供应链信任证明。
