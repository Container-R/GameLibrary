# ENet 发送队列原生实验：可复现材料与未完成边界

**状态：没有完成原生队列验证。** 本目录是有限实验的原创代码及固定预期，不是已经通过的 ENet 行为证据。当前结果见 [失败与范围说明](FAILURE-SUMMARY.md)。没有原生 PASS 文件，也没有把空跟踪解释为零网络调用。

目标是直接链接 ENet v1.3.18 固定上游，观察 `enet_peer_send` 在16个长度/单独标志/序号组合及1个拒绝通道输入下的队列。它不建立网络连接，不测传输、接收、延迟、玩家体验或实际游戏；人工设置 CONNECTED 仅是队列调用的内部前提。全部17个输入仍是待原生验证的预期。

## 目录包含什么

- `fixture.c`：原创观察程序；真实发送、packet、链表与reset来自未修改上游库，不由模拟函数替代。
- `run.py`、`consumer.py`：受限运行与作者侧消费检查器；失败停止，原始记录及派生记录按严格类型绑定。
- `test_queue.py`：纯合成测试，可在正常 Python 与 `-O` 下运行；不启动编译器、跟踪器或原生 fixture。
- `independent/oracle.json`：独立审者在原生结果之前冻结的17行预期。作者侧检查器不是独立 oracle。
- `PROTOCOL.md`：实施前冻结的原协议；其中“尚未构建”等描述记录那个时点，不代表本目录的当前状态。后续精确诊断例外见 `WARNING-POLICY.md`；该说明也保留执行前的审批时点，实际两次停止结果以本目录失败说明为准。
- `reviewed-build.stderr`：只有固定上游相对文件名的已审编译诊断，作为逐字节允许集合；不是允许忽略其他警告。
- 两份源码清单：固定原创输入身份，以及指定上游文件的提交、Git blob 和 SHA-256。

本目录不包含完整上游源、编译产物或任何原始执行收据。保留的源文件哈希用于辨识公开代码，不是本机工具或二进制指纹。独立审查的源代码、协议与纯测试验收不能替代尚未完成的原生行为验收。
