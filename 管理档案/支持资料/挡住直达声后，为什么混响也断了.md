# 挡住直达声后，为什么混响也断了

切割器还在运转，玩家走到一面墙后。这个虚构项目希望直达声减弱，同时保留一点间接声，让空间仍然连贯。但接入者调了直达声的遮挡控制，混响也一起消失了；混响自己的控制值明明没有改变。

先别急着提高混响音量。需要确认的是：**送进混响的信号，是否已经经过那道直达声衰减？** 如果输入在上游就被切掉，保持发送系数不变，并不能把它找回来。

这里讨论声音设计师与接入程序员怎样检查这种关系。墙后保留什么声音应由项目决定；并非所有墙体、空间或玩法都应该保留同样的间接声。

## 两个控制值，不一定对应两条独立输入

先分开三件事：**直达输出**是本例不经过混响效果的那一路；**混响发送**是送给混响效果器的输入；**混响返回**则是效果器处理后送回混音的结果。发送不是返回，混响效果也不是全部真实声学传播的同义词。

用一个原创纸面模型看清取样位置。设某一时刻的输入样本为 x，直达路的幅度系数为 d，混响发送系数为 s。先只考虑这两个标量系数，不加入距离、滤波、其他声音或后续总线。

若发送取自已经衰减的信号：

```text
x → 乘 d → 分路 → 直达输出
              └→ 乘 s → 混响输入

直达输出 = d × x
混响输入 = s × (d × x)
```

若先分路，再只对直达一路衰减：

```text
x → 分路 → 乘 d → 直达输出
       └→ 乘 s → 混响输入

直达输出 = d × x
混响输入 = s × x
```

取 x=0.5、d=0、s=0.4。第一种连接的直达输出与混响输入都为0；第二种连接的直达输出为0，混响输入却是0.2。**s 在两种连接里完全一样，差别在它乘到什么信号。** 0.2只是送进效果器的样本值，不是混响返回的幅度，更不是玩家感到的响度。

这不是 FMOD 算法，也不是参数换算表。尤其不能直接把 d 写成“1减去中间件的 occlusion 值”：实际控制可能使用曲线或频率过滤，而不是这里的简单乘法。

## 一个历史 FMOD 问题，正好暴露了这一区别

FMOD 官方论坛2022年的一段讨论中，开发者希望遮住直达声、保留混响。Leah_FMOD 在12月8日第5帖解释，当时的处理链把混响发送放在直达衰减或过滤之后；上游信号被切掉时，发送也就没有新输入。12月12日第7帖进一步把这种顺序描述为设计行为。[1]

这提供了一个具体反例：参数分别叫 direct 和 reverb，不足以证明它们拿到互相独立的信号。该讨论没有明确精确 SDK 构建号，不能把当时的内部顺序直接写成今天所有 FMOD 工程的行为。

本次读取的 FMOD Core 2.03.15 手册仍分别列出 directocclusion 与 reverbocclusion，范围都是0到1；但它也说明，某些初始化选项会让 direct 控制作用为频率过滤。这个参数说明本身，不是“设置一边不会影响另一边输入”的并联路由保证。[2]

术语也要连着语境看。2023年官方论坛回答一个 I3DL2 参数映射问题时，把 obstruction 的目标描述为在混响发送之后只处理直达路，而 occlusion 涉及直达与混响两路。[3] 这能帮助双方说清要控制的对象，却不是所有中间件共用的命名或等效配置规则。

## 把发送提前，也可能把别的处理绕过去

第二张图很容易让人得出“把发送移到前面就好了”。但实际信号图里不只有 d 和 s。

上述2022年回复特别提醒：在其讨论的链路中，把发送移到衰减之前，还会让这一路不再接受原来的距离衰减。[1] 因此，“保住混响”可能同时改变远处声源进入混响的量。这个副作用不能靠另一个固定发送值自动解决。

接入时应先核对本工程的取样点：它位于哪些处理之前、哪些处理之后？希望保留的距离关系、音量关系和过滤是否仍然成立？这些是需要检查的项目问题，不是本文替当前 SDK 画出的完整信号图。不要直接照搬旧论坛中的节点索引或重接代码。

如果设计就是要把墙后整个声音压低，连间接声也一起减弱，那么两路联动可以是有意的选择。反之，若要求只削弱直达输出，就需要确认采用的控制确实作用于所选支路，而不是仅凭参数名称认定已经做到。

## 没有新输入，不等于尾声已经归零

回到第一张图：d变成0，能由这个纸面模型推出的是**此刻送入混响的新样本为0**。它没有描述效果器内部已经积累的历史，也没有描述返回路是否另外被静音，因此不能推出“混响返回在同一时刻归零”。

排查时，持续声音的混响输入被截断、已有尾声继续衰减、返回总线被整体压低，是不同问题。若多个声源共用混响，返回里还可能有其他输入的贡献；看到返回仍有电平，也不能证明这台切割器仍在向它发送。

可以按以下顺序设计一次检查，但本文没有执行：

1. 先写清墙前、墙后希望直达声与间接声分别怎样变化，固定素材和当前版本。
2. 观察实际信号图，找到直达处理、混响发送取样点与返回路，不只读两个参数值。
3. 在可分辨该声源贡献的条件下，分别看直达输出、发送输入和返回的变化。将进入遮挡后的持续输入与已有尾声分开观察。
4. 再检查距离变化及正常混音，确认所选连接没有意外绕过其他需要保留的处理，并按项目要求试听。

最后交接的应是“希望影响什么、控制实际落在哪里、哪些输出已经检查”，而不是一句“遮挡开了”。本例的数字、连接图与检查步骤都是说明和待执行建议；没有运行中间件、播放声音或取得听感与性能结论。
