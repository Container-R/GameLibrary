## 实际留下了什么

2026-11-02，主编按冻结清单执行一次runner，只有 `run-01`，没有重试或关闭沙箱重跑。

- [observation.json](run-01/observation.json)：`FAIL`、`TargetClosedError`、`rows=[]`。没有获得行矩形，也没有截图，因此没有四行排版观察，更没有成功的浏览器排版验证。
- [receipt.json](run-01/receipt.json)：worker返回1；请求启用Chromium沙箱；输入前后绑定一致；leader已回收、所拥有进程组检查为不存在，拥有的环境目录记录为已移除。这些是该有限收尾记录，不证明脱离组的后代或所有系统写入均已处理。

错误类型不足以判定确切原因，不能把它写成“已证实沙箱不支持”。子过程原始诊断按预定规则没有公开记录，因而也不能从简短错误反推完整启动过程。`page_request_count=0` 是未取得页面观察时保留下来的初始化值，**不是无联网测量**。协议所写浏览器版本是准备阶段的技术自报信息，本次输出并未取得浏览器版本，不将其当作这次成功运行的版本证明。
