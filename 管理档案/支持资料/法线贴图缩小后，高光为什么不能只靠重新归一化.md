# 法线贴图缩小后，高光为什么不能只靠重新归一化

[返回纹理与Mip预算文章](../../GameLibrary/技术美术/环境管线/纹理与材质/计算BC压缩纹理和Mip链的数据量.md)

一块有细小凹凸的金属板，近看正常，远看却有刺眼的亮点。贴图尺寸、mip 级数和采样层级都核对过了，取出的法线也重新归一化成单位长度，问题仍可能存在：**一个平均方向，不一定能代表这一片细节的平均高光响应。**

这是假设的排查场景，不是某张实际素材的诊断。本说明面向处理纹理导入与材质的技术美术、渲染程序，采用 Toksvig 的历史简报解释信息在哪里丢失，再用原创小算例说明界限。不提供现代材质的通用抗闪烁开关，也没有运行着色器。[1]

## 方向平均得对，不等于光照平均得对

法线描述表面朝向。这里先排除颜色空间和切线基的问题：所有方向已正确解码到**同一个坐标系**，长度均为1；一个采样区域里只有两个方向，权重各为一半。

设它们分别向左、向右倾斜30度：

```text
n₁ = ( 1/2, 0, √3/2)
n₂ = (−1/2, 0, √3/2)
平均向量 m = (n₁+n₂)/2 = (0, 0, √3/2)
```

平均方向朝上没有错，但长度变成 `√3/2`，约0.866。归一化就是除以这个长度，于是得到 `(0,0,1)`。如果原来的两个方向本就都朝上，归一化后的结果也是 `(0,0,1)`：这一步把“附近方向不同”与“附近完全平坦”的区别压掉了。

为了看见它怎样影响高光，只考虑一个简化的 Blinn–Phong 高光幂项：

```text
q(n) = max(n·H, 0)⁴
```

`·` 是点积，`H` 是光照方向与观察方向之间的单位半程向量；指数4是本例选择的固定数。我们只比较这一项，不包含完整材质的颜色、遮挡、菲涅耳或其他项，也不把它当作完整反射模型。

先令 `H=(0,0,1)`。两个原始方向各自的响应都是 `(√3/2)⁴=9/16`，等权平均后仍是 **9/16**。若先把平均向量归一化再计算，得到的却是 **1**。

这不是浮点误差，而是计算次序不同：先对不同方向求非线性的高光响应，再平均，通常不等于先把方向合成一个单位向量，再求响应。仅把向量长度“修回1”，并没有完成前一种过滤。[1，印刷第2–3页]

## 留住长度有帮助，但它不是完整的方向分布

Toksvig 利用平均法线的缩短程度估计区域内的方向变化，同时明确指出：同一个长度可以对应不同分布。[1，印刷第1–2页] 一个数字不能告诉材质，细纹主要朝左右倾斜，还是主要朝前后倾斜。

沿用上面的两个方向，再构造另一组 `n₃=(0,1/2,√3/2)`、`n₄=(0,−1/2,√3/2)`，同样各占一半。两组的平均向量和长度**完全相同**。现在把半程向量改为 `H=(1/2,0,√3/2)`，指数仍为4：

| 区域内的两个方向 | 两次点积 | 先求幂项、再等权平均 |
|---|---|---|
| 左右倾斜的 n₁、n₂ | 1、1/2 | `(1⁴+(1/2)⁴)/2 = 17/32` |
| 前后倾斜的 n₃、n₄ | 3/4、3/4 | `(3/4)⁴ = 81/256` |

这两个结果不同，然而只接收平均向量的处理无法区分它们。它说明保留平均长度也不是精确恢复任意高光的充分信息；不是说 Toksvig 方法毫无作用，更不是一次方法精度或画质测试。两组都是本文原创纸面例子，所有点积非负，没有借负数幂项制造差异。

## 历史方法调整的是高光响应，不是把长度直接当粗糙度

简报在近似的方向分布假设下，把缩短后的长度与 Blinn–Phong 指数联系起来。若记平均长度为 `L`、原指数为 `s`，其中的调整因子是：

```text
f = L / (L + s(1−L))
新指数 = f × s
```

原式还调整高光强度，而不只是降低指数。对于这里讨论的 `0<L≤1、s>0`，`L=1` 时因子为1；长度降低时，高光变宽、峰值降低。这是简报中的近似处理，不是从任意纹理恢复全部细节的恒等式。[1，印刷第3–4页]

不要把这个指数公式直接赋给采用其他反射模型的“roughness”参数。项目需要核对实际材质如何表示粗糙程度、如何过滤，以及是否已经做了类似补偿。平均向量为零时也不能照抄这里的方向归一化，需要实现另行处理；本文不是包含全部异常分支的着色器。

## 接入时，追查信息在哪一步还存在

检查法线 mip 管线时，可以沿着数据走，而不是反复重烘焙模型：

1. **平均的是什么？** 确认是正确解码、同空间的方向及约定的权重。若一开始误把法线当颜色做 sRGB 解码，先处理[法线分量的解释问题](法线贴图也是RGB，为什么不能照着颜色图做sRGB解码.md)，不能用高光补偿掩盖它。
2. **什么时候归一化？** 若每级生成后只保存单位方向，之前缩小区域的长度信息已经不在那一份结果中。后来再插值可能产生新的长度变化，但不表示此前丢失的细节已经恢复。若格式或接入步骤总是重建单位向量，也不能假设最终仍携带原长度。
3. **材质需要怎样的过滤信息？** 导入端保存或预计算的量，必须与运行时的反射模型配合。只改法线导入，或只在着色器里再归一化，都不自动完成这种配合。
4. **精度够不够？** 简报提醒，高指数情形对平均长度误差敏感。[1，印刷第5页] 应在目标素材和镜头下检查量化、压缩与最终采样的影响，而不是把很小的长度差全部解释成真实表面变化。

这些是未执行的项目检查。本文没有生成法线 mip、测量闪烁或证明某个引擎的补偿有效；阴影、采样不足、材质参数变化等仍可能造成亮点异常。预算正确、方向正确和高光过滤合适，是三个需要分别接收的结果。
