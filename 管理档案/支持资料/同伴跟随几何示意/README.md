# 同伴跟随几何示意：来源与适用边界

图件：`管理档案/支持资料/同伴跟随几何示意/follow-checks.svg`。

本图为本文独立绘制的原创二维点平面反例，未复制、描摹或改编来源原图，不是《最后生还者》来源图 35.1。图中设领队点 L = (0, 0)、候选点 C = (2, 0)、选定的前方端点 F = (2, 2)，唯一禁区为闭矩形 [0.8, 1.2] × [0.8, 1.2]，边界也属于禁区。

L→C 的纵坐标恒为 0，C→F 的横坐标恒为 2，因此两段都避开禁区。但 L→F = (2t, 2t)，0≤t≤1，恰在 t∈[2/5, 3/5] 时进入或接触禁区。这个反例只说明“两段分别畅通”不能推出“第三段畅通”，不证明某个游戏或 AI 实现实际出现过这一结果。

图件由 Matplotlib 矢量绘制，坐标轴等比例；实线与虚线分别表示避开禁区和与禁区相交的线段，禁区另用斜线填充，不依赖颜色单独传达区别。示意范围仅限静态二维点与线段，不代表实际游戏几何、导航网格执行、有限体积净空、扫掠碰撞或观测到的 AI 运行结果。
