# 流动贴图为什么要定期复位，又怎样藏住跳变

假设一条水沟已经能显示流动纹样：不同位置的流向不同，图案开始时像是在顺着水沟移动，过一会儿却越拉越斜。直接把动画时间清零，形状恢复了，画面又突然跳回起点。材质作者需要解决的，正是这两个连在一起的问题：怎样限制形变，又不让复位显得突兀？

本文面向制作流动材质的美术与 TA。我们用一个剪切场和两层交替显示的纸面例子，分清流向速度、每轮时长和混合权重。以下公式与数字都是原创教学构造，不是 Valve 的着色器代码，也没有进行渲染验证。

## 不同位置的偏移差，为什么会越积越大

**UV** 是到纹理里取样的二维坐标，分别写作 `u` 和 `v`。为了只讨论形变，本例让表面位置与纹理坐标共用同一尺度：横、竖各一个坐标单位，对应一份纹样的宽、高。实际材质若有不同平铺倍率或坐标转换，需要另外处理。

设某个表面位置为 `x=(u,v)`，该处的二维流向向量为 `F(x)`。本例的流向图不随时间改变。向量的两个分量分别表示横、竖方向每秒改变多少纹理坐标；方向决定往哪边偏移，长度表示这个坐标空间中的速度。流向图就是提供这类局部向量的数据纹理。

暂时只在固定表面位置取一次流向，再按经过的时间 `t` 计算取样位置 `q`：

```text
q(x,t) = x - t × F(x)
```

负号是本例选择的反向取样约定：为了让纹样看起来向一侧移动，到纹理的相反一侧取值。它不是所有流向图通用的符号规定。

先看一个重要反例：**如果所有位置的流向向量完全相同，整张纹样只会平移，不会因时间变长而产生这种形变。** 问题出在各处偏移不同。令本例流向为 `F(u,v)=(0.25v,0)`，也就是竖向坐标越大，水平偏移速度越大；系数 `0.25` 的单位为每秒。

在表面上取两个不动的位置：`A=(0,0)`、`B=(0,0.1)`。A 的流向为零，B 的流向为 `(0.025,0)`。它们到纹理里取样的位置会这样变化：

| 经过时间 | A 的取样位置 | B 的取样位置 |
|---|---|---|
| 0 秒 | `(0,0)` | `(0,0.1)` |
| 4 秒 | `(0,0)` | `(-0.1,0.1)` |
| 8 秒 | `(0,0)` | `(-0.2,0.1)` |

表面上的 A、B 没有移动，取样位置却越来越错开。把这种差异放到整张图上，圆形纹样就会被剪切成斜椭圆，一个方向拉长，另一个方向压缩。一直增加时间，便会一直增加本例的剪切量。单纯换一张更清晰的纹理，并没有改变这个坐标关系。

## 每层只播放一小段，在看不见时复位

Alex Vlachos 在2010年的 Valve 水流课件中，先讨论《Left 4 Dead 2》的法线流动，再扩展到《Portal 2》的颜色纹样。它给出的一个关键办法是：只使用短段形变，让两层错开半个周期，并交替改变各层的贡献，隐藏每层的重新开始。[1]

沿用刚才的剪切场，设每层一轮持续 `P=4 秒`。**相位**表示这一层走到本轮的哪个位置：0 是开始，0.5 是中点，接近 1 是即将结束。取小数部分的函数 `fract` 让它每轮回到 0：

```text
p0 = fract(t/P)
p1 = fract(t/P + 0.5)
```

`p0`、`p1` 分别是两层的相位；第二层比第一层错开半轮。接下来为每层指定**权重**，也就是它在合成结果里占多少贡献：

```text
w(p) = 1 - abs(2p - 1)
```

`abs` 表示绝对值。这条三角形权重在相位 0 时为 0，到 0.5 时升至 1，再降到接近 1 时的接近 0。两层错开半轮后，权重之和始终为 1。

每层的有效偏移时间记为 `τi=P×pi`，其中 `i` 为 0 或 1。它只在本轮的 0 到不足 4 秒之间变化，不会继续累积到 8 秒、12 秒。各层取样位置为 `qi=x-τi×F(x)`。

为了只解释贡献，不暗含颜色空间或法线组合规则，令 `T(q)` 是一个理想的连续数值纹样：在位置 `q` 取到一个介于 0 和 1 之间的标量。这里的数值只是纸面上的图样强弱，不是 RGB 颜色或法线向量。合成结果写作：

```text
C = w(p0) × T(q0) + w(p1) × T(q1)
```

到 `t=4 秒` 时，第一层的相位从接近 1 跳回 0，取样位置也跟着复位。但它的权重在跳变前后都趋向 0，因此这次位置跳变没有突然带入一个有分量的新值。此时第二层恰好处于相位 0.5，权重为 1，它的取样位置仍连续变化，由它承接画面。

再过两秒，轮到第二层复位，第一层来到相位 0.5。**每层都在自己的贡献归零时重新开始，而不是两层同时清零。** 在这个有界、连续纹样的假设下，合成数值不会因为复位产生跳变。

这仍不保证画面处处自然。三角形权重有转折，数值连续不代表变化速度也连续；两份形状在中途叠加，还可能显出重影、重复或脉动。原课件也另列了重复和脉动问题，不能把“两层”理解为已经解决全部流动伪影。[1]

## 让权重最高时，图案恰好没有形变

刚才每层的有效时间从 0 增至不足 4 秒。权重最高的相位是 0.5，对应 `τ=2 秒`，所以最清楚显示出来的，仍是一幅已有剪切的纹样。

课件在比较法线流动与颜色碎屑流动时，把单侧形变区间改为围绕零展开的区间，让颜色层的最高权重对应无形变位置。[1] 用本例的符号表达这个思路，只需将有效时间改为：

```text
τi = P × (pi - 0.5)
```

仍取 `P=4 秒`，每层便从 `-2 秒` 对应的偏移开始，经过 0，走到接近 `+2 秒` 后复位。相位 0.5、权重 1 时，`τi=0`，正好取回未形变的纹样；较大的正负形变主要出现在权重较低的时候。

相位仍一直向前增加，只是偏移区间的起点变了，并没有每半轮把流向倒转。这也不是“颜色必须这样、法线必须那样”的通用规定，而是理解历史案例为何偏爱较少可见形变的一种参数化。真正接入颜色或法线纹理时，还要分别确认颜色表示、向量解码和组合方式，不能把上面的标量混合直接当完整着色器。

## 交接参数时，分别说清三件事

当作者觉得流动效果不合适，可以先分开看：

- **局部流向与速度**：本例由 `F(x)` 决定。改它，会改变不同位置的偏移方向或每秒偏移量。
- **每轮持续时间**：本例由 `P` 决定。速度不变时，缩短周期会限制一层能累积的偏移，也会让交替与复位发生得更频繁。
- **哪一段更明显**：由相位错开方式和权重决定。它们安排两层何时接替，不会把局部向量自动变成更准确的流体运动。

要检查接入是否符合这些约定，可以先关闭一层，看它何时复位；再恢复两层，检查复位层此时是否确实归零、另一层是否承接结果。这是建议的检查方法，不是本文已经运行的测试。

最后要分清材质外观与物体运动：本例始终在固定表面位置取得流向，再乘一个有限时间偏移纹理，没有沿着弯曲路径不断更新方向。它适合解释如何循环表现表面流动，不能据此得到真实漂浮物的轨迹或物理水体。某个纹样还会淡出、复位、重新出现，因此也不承诺一片可辨认的碎屑始终保持同一个身份。
