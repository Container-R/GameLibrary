# 骨骼没有旋转，为什么变形后的法线仍可能需要改变

两根骨骼都没有旋转，其中一根只向上平移。模型上的点移动了，表面也倾斜了，但逐骨变换后混合得到的法线仍然朝上。这不必归因于矩阵上传或权重归一化错误。即使这些输入都正确，不同位置使用不同权重，也能产生单根骨骼的线性部分没有描述的表面倾斜。

下面用一个三角形说明这个问题，面向正在核对蒙皮与照明结果的动画程序员和技术美术。它是理想实数下的手算，不是某个引擎或资产的故障记录。目标是学会选择比较对象，而不是要求所有模型都重算法线。

## 先说明我们要比较哪一种法线

**几何面法线**由三角形的位置和顶点顺序决定。本文约定右手叉积：顶点依序为 A、B、C 时，方向取 `(B−A)×(C−A)`，再除以长度。非退化三角形的这个方向垂直于两条边。

照明使用的**着色法线**则可能是平滑后的顶点属性、艺术编辑的方向，或者进一步受法线贴图影响的结果。它不必等于每个相邻三角形的面法线。不能因为两者不同，就宣布模型或着色器错误。

为了单独考察蒙皮变形，这个例子明确把三角形原始的 +Z 面法线作为给定输入，并以**变形后同一三角形的几何面法线**作为比较目标。这个目标只属于本例。真实资产应先说明想保留什么方向，再决定怎样检查。

## 同一根骨骼的平移，怎样把三角形变斜

取输入空间中的三个点，按 A、B、C 排列：

```text
A = (0,0,0)
B = (1,0,0)
C = (0,1,0)
N = (0,0,1)
```

两条边原来沿 +X、+Y，叉积就是 +Z。这里使用列向量；下面的 C₀、C₁ 已经是接受同一输入空间、输出到同一变形空间的**有效骨骼变换**，不是未经绑定校正的局部关节矩阵：

```text
C₀(p) = p
C₁(p) = p + (0,0,1)
```

若尚未确认有效变换包含什么，应先核对[逆绑定、关节层级及输出空间](关节已经移动了，为什么蒙皮还需要逆绑定矩阵.md)，而不要直接套这个例子。

设输入点为 `p=(x,y,z)`，第二项的权重是 `w₁=x`，第一项是 `w₀=1−x`。**这里的 x 来自变形前的输入位置，不是在变形后重新读取坐标计算权重。** 原三角形内有 `0≤x≤1`，因此两项权重均非负，且和为1。

按线性混合蒙皮，位置是两个变换结果的加权和：

```text
F(p) = (1−x) C₀(p) + x C₁(p)
     = (x,y,z+x)
```

A 和 C 的第二项权重为0，不移动；B 的第二项权重为1，向 +Z 移动1。于是：

```text
A' = (0,0,0)
B' = (1,0,1)
C' = (0,1,0)

B'−A' = (1,0,1)
C'−A' = (0,1,0)
(B'−A') × (C'−A') = (−1,0,1)
```

变形后的单位面法线是 `(−1,0,1)/√2`。它与两条新边的点积均为0。平移本身没有旋转一根骨骼，但不同点获得了不同平移量，三角形因此倾斜。

## 为什么换成逆转置也没有修复这个例子

先看一种方向近似：把给定 N 分别交给每根骨骼的线性部分处理，再按该点的权重混合。C₀ 和 C₁ 的 3×3 线性部分都为单位矩阵 I，区别只在平移。于是无论该点的权重是多少：

```text
(1−x) I N + x I N = N = (0,0,1)
```

对每根骨骼的线性部分改用逆转置，结果仍然不变，因为 `I⁻ᵀ=I`。这个 +Z 方向与新边 `(1,0,1)` 的点积为1，并不垂直；它已经是单位向量，再次单位化也没有帮助。

还有另一种做法：先把骨骼的线性矩阵按权重混合，再对所得矩阵整体取逆转置。**它在一般情况下不等于上一种逐骨逆转置后混合。** 但本例中，混合后的线性块仍然是：

```text
L(p) = (1−x) I + x I = I
L(p)⁻ᵀ N = N
```

因此，两条不同的计算路径在这个构造中碰巧给出同一个不符合目标的方向。不是逆转置的数学规则失效，而是 L(p) 没有描述邻近点之间平移量的变化。

Kavan 的原始课程在 §6、图10中直接讨论了这类仅平移骨骼、线性部分为单位阵的情况。其式(16)针对混合矩阵取逆转置；随后指出空间变化的权重会影响所需法线，并在式(17)加入权重梯度。[1] 本文三角形和数字是独立手算，不是对课程图形的重画或测量。

## 要描述表面变化，还需要看邻近点怎样移动

只知道某个顶点的权重，还不能知道它旁边的权重怎样变化。为解释这个例子，我们显式把 `w₁=x、w₀=1−x` 定义为输入位置的函数；仅在所需局部范围内使用它，不要求整个三维空间的权重都满足非负约束。

**雅可比矩阵 J**记录输入位置沿各轴发生微小变化时，输出位置怎样变化。由 `F(x,y,z)=(x,y,z+x)` 直接得到：

```text
J = [ 1  0  0 ]
    [ 0  1  0 ]
    [ 1  0  1 ]
```

它的第一列 `(1,0,1)` 表示：输入沿 X 增加一小段，输出既向 X 移动，也向 Z 移动。恰是后一个变化让表面倾斜。J 可逆，行列式为1；对这个完整局部变形求逆转置：

```text
J⁻ᵀ = [ 1  0 −1 ]
       [ 0  1  0 ]
       [ 0  0  1 ]

J⁻ᵀ N = (−1,0,1)
```

单位化以后，它与前面的几何面法线一致。这个一致有特定原因：本例选出的 F 本身是仿射映射，整个三角形都受到同一个 J 描述的变形。对于一般非线性变形，连续曲面的微分切平面，不必等于只变换三个顶点后用直边连接成的有限三角形平面。

如果想看遗漏项从哪里来，可以把一般线性混合蒙皮写成以下明确维数的形式：

```text
F(p) = Σⱼ wⱼ(p) (Aⱼp + tⱼ)

J(p) = Σⱼ wⱼ(p) Aⱼ
     + Σⱼ (Aⱼp + tⱼ) (∇wⱼ(p))ᵀ
```

其中 p 和 tⱼ 是三维列向量，Aⱼ 是固定姿势下的 3×3 线性部分，wⱼ 是可微的标量权重函数。`∇wⱼ` 是权重对输入位置三个坐标的导数组成的列向量；一列乘一行产生 3×3 矩阵。第一项考虑骨骼怎样移动点，第二项来自乘积求导，考虑权重随位置怎样变化。这是用明确符号展开的数学解释，与课程强调的梯度项对应。[1]

在本例中，两个权重的梯度分别为 `(−1,0,0)` 和 `(1,0,0)`。第二项合计为 `(0,0,1)(1,0,0)`，也就是只在第3行、第1列填入1，补上了 L=I 缺少的变化。

不过，任意一组存储在顶点上的权重，并不会自动指定唯一的连续权重函数或梯度。本例为了能够手算，主动定义了该函数；它不是一个从任意游戏网格读取正确 J 的完整算法。

## 权重为0的骨骼，为什么还可能留在法线数据里

实际网格往往只存每个顶点的骨骼索引和权重，没有现成的权重函数。若选择梯度修正法线，还要规定如何从相邻顶点重建变化，再把这些变化汇总到顶点。Tarini、Panozzo 和 Sorkine-Hornung 的论文讨论了这条路线，以及邻居的骨骼影响为何可能需要加入当前顶点的数据。[2] 下面独立构造一个小例子，展示这个数据需求；**我们明确采用四个面梯度等权平均，不声称复现论文的余切权重预处理。**

在原来的 XY 平面上，取中心和四个邻点：

```text
O=(0,0,0)
E=(1,0,0), N=(0,1,0), W=(−1,0,0), S=(0,−1,0)

四个三角形依次为 OEN、ONW、OWS、OSE。
```

它们都按 +Z 朝向排列，面积均为 1/2。第二根骨骼的权重 w₁ 在 E 为1，在其余四点为0；第一根骨骼取补数 w₀=1−w₁。在每个三角形内部，用三个角点的值作线性插值，并约定权重沿 Z 不变。这样，整个菱形内的权重都非负，且两项之和为1。

面内的梯度可以直接由边上的权重差确定。例如在 OEN 中，沿 OE 走1，w₁ 增加1；沿 ON 走1，w₁ 不变，所以梯度是 `(1,0,0)`。按同样的方法，四个面的 w₁ 梯度依次为：

```text
OEN：(1,0,0)    ONW：(0,0,0)
OWS：(0,0,0)    OSE：(1,0,0)
```

现在按事先选定的等权平均规则，给 O 分配一个梯度估计：

```text
g₁=(1/2,0,0)，g₀=(−1/2,0,0)。
```

这里有一个不能省略的区别：**O 的权重确实为0，但 g₁ 不是该点的精确导数。** 这个分片线性权重场实际是 `w₁(x,y)=max(x,0)`，在 O 沿 X 的左导数为0、右导数为1，存在折点。一个可微、非负的权重函数若在内部取0，该处是局部最小值，梯度必须为0；本例没有违反这个事实。我们得到的是相邻面变化的平均估计，换一种重建或平均约定，可能得到不同结果。

接着只计算中心 O。沿用前面的有效骨骼变换 C₀、C₁，即第一项不动、第二项向 +Z 平移1。O 的位置权重为 `(1,0)`，所以它本身不移动。给定原始着色法线 `n=(0,0,1)`，并取与它垂直、满足 `u×v=n` 的两条切向量：

```text
u=(1,0,0)，v=(0,1,0)。
```

我们不必把完整梯度放进最终的法线数据，只需保留它沿这两条切向量的变化量。记 `αⱼ=gⱼ·u、βⱼ=gⱼ·v`，本例得到：

```text
骨骼0：α₀=−1/2，β₀=0
骨骼1：α₁= 1/2，β₁=0
```

用骨骼0作参考。两根骨骼分别作用于 O 后的位置是 `q₀=C₀(O)=(0,0,0)`、`q₁=C₁(O)=(0,0,1)`。由于本例的两个线性部分都是 I，未修正的切向量仍是 u、v；梯度修正则给出：

```text
u' = u + α₁(q₁−q₀) = (1,0,1/2)
v' = v + β₁(q₁−q₀) = (0,1,0)

u'×v' = (−1/2,0,1)
单位化后为 (−1,0,2)/√5。
```

这里能只存骨骼1的一对系数，是因为两项梯度之和为0，骨骼0的贡献可以合并进位置差。论文 §4.1–§4.3 讨论了变换两条切向量再叉乘，以及利用参考骨骼的位置差组织修正的做法；本例只是用明确选定的梯度估计展开这段代数。[2]

这就解释了额外骨骼索引的用途：若 O 的数据只服务于位置计算，留下骨骼0就够了；若还要计算这里的法线修正，就必须能够取得骨骼1的变换，尽管它在 O 的位置权重仍为0。采用逐顶点骨骼索引表时，可以保留这个零权重条目及对应系数。若影响数上限容不下它，直接删掉便会丢失这项修正，不能仍称结果完全相同。论文 §3.2 和 §5 也明确处理了这类邻域带来的额外影响项。[2]

最后仍要检查比较对象。这个姿势中只有 E 移动：两个东侧三角形的未单位化面法线为 `(−1,0,1)`，两个西侧三角形仍为 `(0,0,1)`。中心估计得到的 `(−1/2,0,1)` **不等于其中任一面的法线方向**。它描述的是本例选定的顶点平均和给定切平面的修正，不能要求同时垂直于折线两侧的所有面。

因此，“零权重骨骼仍可能占用法线数据”是一项由重建方法带来的表示需求，不是说所有零权重条目都该保留。本例也刻意让给定着色法线等于原始面法线；艺术编辑过的方向、硬边和接缝需要另行明确约定，不能用这套小例子的结果替换全网格的着色法线。

## 实际排查时，先把比较对象固定下来

如果怀疑动画中的高光没有跟随表面，可以先做一个范围很小的诊断，而不是立即重写蒙皮：

1. 固定同一姿势、有效骨骼变换、输入网格、影响集合及权重，确认位置与待检查法线处在同一比较空间。
2. 写清目标。是想检查变形后三角形的面方向，还是保留平滑、编辑后的着色方向？后者不能直接用每片面的叉积判错。
3. 若选择一个非退化三角形作几何对照，从它实际变形后的三点计算边和叉积，再检查候选方向与两条边的点积。这个基准只回答该三角形的垂直关系。
4. 沿法线路径确认究竟是逐骨混合、对混合矩阵取逆转置，还是另一种处理。若出现本例机制，继续单位化或只给每骨补逆转置，不能补回权重的空间变化。

这些是由算例提出的排查步骤，不是已在项目中执行过的测试。发现差异后，仍应根据真实画面目标决定是否需要改变算法。从变形几何重算法线需要相邻几何的数据；估计权重梯度则需要定义及估计方式，不能只在公式中添一个符号。[1] 本文不提供任意网格的平滑、硬边、接缝或梯度计算配方。

## 这个反例证明了什么，又没有证明什么

它证明：权重合法、骨骼只有平移、逐骨线性部分没有旋转，仍可能出现“逐骨方向近似没有跟随变形面”的情况。[静态统一变换的法线规则](../来源笔记/tangent-handedness-normal-transform.md)，不能不加检查地替代完整空间变形的分析。

它没有证明所有空间变化权重都会产生偏差，也没有证明差异必然在最终画面中可见。相同骨骼变换、特定方向或其他抵消条件可能使结果一致。常量权重提供一个简单情形，不应被写成正确结果的唯一必要条件。

本文不评估双四元数、morph、切线空间或法线贴图的具体实现；不处理退化三角形、奇异或近奇异 J、有限精度和性能预算。即使采用几何重算法线，也还需遵守资产想保留的平滑和艺术约定。

回到开头，最有用的检查不是“骨骼旋转了没有”，而是“相邻点受到了怎样不同的位移，以及照明方向应该跟随哪个表面”。先回答这两个问题，再选择计算方法。
