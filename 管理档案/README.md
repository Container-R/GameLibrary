# 维护说明

读者请从[图书馆入口](../README.md)或[学科导览](../GameLibrary/README.md)找书。这里记录目录重建与文章编辑，不代替正文。

- [研究与发表规范](规范/研究与发表规范.md)：导航、自然技术写作、文末引用和通用性要求。
- [目录与编辑清单](图书目录.json)：记录每篇原文、计划位置和当前编辑状态。
- [来源与技术支持笔记](来源笔记/README.md)：已整理的有限支持材料，不计为新增书籍。
- [原始来源卡片](来源卡片/README.md)：保留来源版本、访问范围与历史证据边界。
- [来源归类清单](来源笔记归类.json)：追踪其他笔记的已整理与待整理状态。

55篇改写正文已上架。根目录与支持资料正在逐组归并；历史记录只在审查后去除环境信息，保留技术事实与失败，不重写Git历史。未迁移的原稿暂时原位保留，不能把它们当成另一套当前书库。

- [稳定ID路线维护工具](工具/navigation/README.md)：显式读取现行55篇清单或旧元数据，只生成管理草稿。

- [写作模板](写作模板/README.md)：辅助组织论证，不要求正文套用固定句式。

## 怎样理解整改进度

[图书目录](图书目录.json)分别记录新正文是否上架，以及原文的全部内容是否已有去向。新正文通过审读，并不表示原复合文章的所有章节已经整理完成。[复合旧文待整理](复合旧文待整理.json)逐项列出保留的拆分章节及处理状态；只有章节已有通过审读的新位置，或有经过核对的合并、排除理由，才结束该项。目录中的正文数量不作为全库质量通过证明。

- [分类兼容说明](分类/README.md)及[分类检查器](工具/taxonomy/README.md)：显式清单检查，不证明全行业覆盖。
- [任务队列检查器](工具/queue/README.md)：显式输入与非空迁移计数门槛。
