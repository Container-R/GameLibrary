# 当前区域实体集合：原创复现材料

[返回完整方法](../../../../GameLibrary/玩法程序/玩法系统/物理检测/Box2D当前区域查询与实体命中集合.md)。正文包含必要过程，本目录只提供应用集合模型及有限算术，不能替代 Box2D 接入测试。

需要 Python 3.10 或更新版本，仅用标准库。在本目录运行：

```sh
python3 -B check_application_model.py
```

输出与 results.json 对照。脚本预先规定哪些 shape 回调被引擎返回，再检查720种排列下的成功集合和720种容量失败排列、角色筛选顺序、双向过滤、坐标算术与实体世代键。缺失绑定和新键容量失败整批拒绝；同一实体重复键不占新容量。

没有 Box2D 绑定或原生引擎执行，不求 GJK、宽阶段遍历、近边界浮点行为、物理模拟、性能或并发正确性。脚本不是完整消费系统实现；效果连锁销毁与命令准备的政策见正文。
