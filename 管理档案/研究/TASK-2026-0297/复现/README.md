# 有限窗口流程度量的复现材料

这些材料对应[正式方法](../../../../GameLibrary/项目管理与测试/制作管理/流程度量/有限观察窗口中的在途数量与完成时间.md)中的原创教学记录。工单、候选版本、时间、状态和人工投入全部为设定，没有导出真实团队或任务工具的数据。

## 文件与输入

- [case.json](case.json)：原始教学输入。`flows` 一行表示一次连续流转，`ticket` 保留工单身份，`id` 区分取消后重新进入的经历；`start`、`end` 以共同原点后的自然小时表示。空的 `end` 必须配有 `open_confirmed_at`，表示已经确认截至何时仍在途。初末快照取该时刻全部事件之后的状态。
- [reproduce.py](reproduce.py)：Python 3 标准库程序。事件途径从期初快照逐次处理进入和退出；逐项途径计算各区间与窗口的重叠。随后核对数量守恒及可计算时的年龄关系。内部状态记录只检查发生于该流转内部，不产生额外进出。
- [flow-timeline.svg](../../../../GameLibrary/项目管理与测试/制作管理/流程度量/examples/flow-timeline.svg)、[flow-residence.svg](../../../../GameLibrary/项目管理与测试/制作管理/流程度量/examples/flow-residence.svg)：由同一主例生成的原创图。正文已经包含图中各数值的定义和计算。
- [actual-output.json](actual-output.json)：一次实际执行的完整输出。分数保存为精确字符串，例如 `11/4`；`null` 表示该平均无样本或所需历史信息缺失，具体由该案例输入区分。它不是0。

`internal_events` 保存等待与内部退回的教学事实；`labor` 是独立的人时区间，不从流转停留时间反算。程序检查本例人工区间没有超出对应流转和观察窗口，也没有让同一人的两段投入重叠。它不计算人员利用率。

## 运行与副作用

需要 Python 3，无第三方包，无网络请求、安装或远端写入。在仓库根目录运行：

```bash
python3 管理档案/研究/TASK-2026-0297/复现/reproduce.py
```

默认只读取与程序同目录的 `case.json`，将 JSON 写到标准输出，不修改任何文件。也可以先进入本目录，再运行 `python3 reproduce.py`。这些命令只复算随文教学输入；它不是任意工单系统的导入器，内置分支明确依赖主例的身份和48小时窗口。程序拒绝退出时刻不晚于进入时刻的记录；若真实导出出现同一时间戳的进入和退出，应先核实时间分辨率与事件顺序，不能直接当作本脚本支持的输入。

若要另存输出，可显式重定向，例如 `python3 reproduce.py > flow-result.json`。文件会由命令行覆盖，因此不要把重定向目标指向正文或原始输入。

若要重新生成图，另选输出目录：

```bash
python3 reproduce.py --svg-dir flow-figures
```

这会在指定目录写入 `flow-timeline.svg` 和 `flow-residence.svg`，同时仍向标准输出打印复算结果。任一同名 SVG 已存在时，程序拒绝覆盖；显式加 `--overwrite` 才会替换这两个 SVG。它不会修改正文、目录、输入文件或其他图。

## 分支各自在区分什么

程序的 `variants` 是作者对本文教学计算的复核，不是独立读者考题或审稿答案。

| 分支 | 要区分的解释 |
|---|---|
| `older_A_same_window_events` | 只改变期初项的历史年龄，窗口内面积不变，完成率乘完整耗时却可能高于平均在途 |
| `unknown_initial_entry_times` | 丢失期初真实进入时刻，不等于丢失本窗口面积；不能补造全年龄与完整耗时 |
| `zero_exits`、`empty` | 零退出时仍可算面积，完整退出平均没有样本；空窗不代表观察到了一次零耗时 |
| `split_left_0_30`、`split_right_30_48` | 相邻窗口的面积和进出数量可相加，同一边界的一进一出不重复计算 |
| `start_and_end_events_0_12`、`adjacent_events_12_24` | 恰在起点退出的项已不在初始快照；恰在终点进出的事件只分配给前一窗口 |
| `wrong_merged_C` | 故意把取消后重入错并成连续流转，仍可算术闭合；必须用真实状态边界识别错误 |
| `same_sparse_snapshots_history_A/B` | 相同起止快照可以有不同期间面积，快照无法唯一补出缺失事件 |
| `later_observed_exits_extend_to_60` | 只有假定已经取得新的实际观察记录后才重算更长窗口；不改写原48小时结果 |
| `rejected_inputs` | 重复流转编号被拒绝；漏掉已发生退出的记录与独立期末快照冲突 |

边界分支只核对本文明确采用的 `(a,b]` 事件分配和 `[s,e)` 占据规则，不声称核查某任务软件的实际时间戳行为。两个算法使用同一组教学输入，即使相等也不认证身份、状态或出口条件在真实工作中正确。另需由使用者核实真实记录。
