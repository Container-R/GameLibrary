# 背包拖放应用模型演算

本文配套材料只检验原创应用状态转移。没有 DOM、CSS 引擎、浏览器分派、实际捕获或设备输入；`hit` 和 `capture-result` 是注入事实，不能反过来证明网页这样工作。

## 运行

需要已安装的 Node.js，无第三方包。在本目录执行：

```sh
node run.mjs ./my-run
```

副作用只有在 `./my-run` 下创建或覆盖 `output.json` 与 `summary.txt`，不联网、不安装、不读用户数据、不操作浏览器、不更改其他文件。使用新的输出目录可保留旧记录。`model.mjs` 只定义内存模型；`run.mjs` 读取同目录 `model-inputs.json`，再执行断言并输出。

本包实际运行使用 Node.js v24.22.1；正文采用 [run-02/summary.txt](run-02/summary.txt) 与 [完整输出](run-02/output.json)。首次运行的run-01作为历史研究记录保留，不在本公开包中；run-02增加对“捕获设置期间不得直接完成”的入口防御及断言，14组原输入输出保持相同。14组作者断言通过，断言只约束作者提出的算法，不是独立技术审查或浏览器符合性报告。

## 输入与算法

- [model-inputs.json](model-inputs.json)：R01–R10为同一组原创代表输入的应用层转写；M01–M04增加捕获失败、额外按钮与清理重入。不含浏览器采样数据。
- [model.mjs](model.mjs)：有限状态模型。节点标签通过固定映射得到格子，专用于承接题设，不能复制为真实DOM命中算法。正文另给当前命中、祖先解析与节点登记方法。
- [run.mjs](run.mjs)：逐条运行并保留状态轨迹；末尾有两种刻意错误策略，统计错误入口调用次数，不模拟正式规则接受这些调用。
- [图示SVG](../../../../GameLibrary/界面与体验/交互设计/指针交互/examples/capture-hit-rule.svg)：原创空间示意，已离线渲染查看，不是浏览器截图。

R07的模型变化显式禁用B并刷新预览。R08直接注入重新命中根背景，模型没有计算布局。R09显式施加另一规则操作：剑移到C、版本变6、A显示新剑，随后刷新使旧尝试失效。这项外部操作不受本拖放的“C只接受药水”限制，拖放模型不负责许可或撤销它。R10在关闭后创建世代21的新模型实例，旧101回调不改变102。

M01与M02把不同捕获适配失败归一为`ok=false`，不模拟API抛错过程。M04在清理期间主动重入旧完成和新开始，随后在通知阶段开始102并重复旧清理。它检验终结资格与预览所有者，不测浏览器释放捕获的同步性。所有模型状态为普通对象，不包含getter、Proxy或中途外部监听器；这也是正文同步发布假设的一部分。

R01的click被模型忽略是专用把手与捕获根没有使用业务的合同，不是浏览器没有发click的证据。got同样只保留为输入，不创建第二份会话。本文没有通过合成事件补造原生取消观察。
