# 明暗分组二维示意图的复现

[正文与已发表SVG](../../../../GameLibrary/美术设计/环境设计/概念设计/环境场景细化中的明暗分组与视觉层级检查.md)说明输入、局部改动和用途。这里的程序只绘制原创二维色块，不读取场景或模拟材质、照明、碰撞、mip、LOD和玩家视觉。

## 输入与比较

每个场景坐标为600×320，墙面从(40,35)到(560,280)，门框从(210,30)到(390,260)，门内从(235,30)到(365,235)。B/C横缝中心为70、110、150、190、230、270；竖缝按行交错、间距70，填充矩形笔画厚度4.8。所有图形取消固定磅数描边，使缩小面板保持相对粗细。

A无接缝。B/C的墙面、门洞、台沿、缝位、数量与宽度不变，仅线色从#4a5057改为#9da3aa。D继承C，并加入同一颜色#343c46、同一位置和轮廓的剪影；两个等尺度场景只将门内底色从#29323d改成#7f8b97。RGB是绘图编码，不是材料反射率、线性亮度或灯光强度。小图是相同二维图形缩放后重新栅格化，不是远镜头试验。

## 运行和输出

需要Python 3、Matplotlib和脚本指定的Noto Sans CJK字体。字体位置不同可调整FontProperties中的文件名；不要把缺失字体后的输出当作原版排版。

将[draw_comparison.py](draw_comparison.py)放到一个空的输出目录，执行 `python3 draw_comparison.py`。程序在自身所在目录写出value-group-comparison.svg及value-group-comparison.png；**同名文件会被覆盖**，因此不要直接在保存正式原图的目录运行。程序不下载来源图片，也不安装依赖。

公开版本与作者绘图逻辑、颜色和坐标相同，只去掉两项固定临时缓存目录的默认值和无用导入。编辑复跑使用隔离输出；得到PNG摘要ffcfec0a83b9c59123c4071983d9bbec84b3ad88f98ad0bc8b45ae56ba33938b，与所审原图逐字节一致。SVG中的日期元数据和生成标识可变化，不承诺重新生成SVG的字节摘要相同。已发表SVG保留独立审稿查看过的版本。
