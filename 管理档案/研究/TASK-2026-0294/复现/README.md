# 模块化环境：原创坐标复现

[返回完整方法](../../../../GameLibrary/美术设计/环境设计/模块化环境/模块化环境套件的接口设计与组合验证.md)。必要接口、装配、不变量和制作分流均在正文；这里仅保存原创精确算术，不读取实际资产。

在本目录用 Python 3 标准库运行：

```sh
python3 -B verify_geometry.py
```

脚本只输出 JSON，不写文件。将标准输出与 verification.json 对照。它核对正文五件路线的端口、法线、上向和矩形边界，有限占位、0.2 米故障和楼板数值；无解结论依赖正文的任意链不变量证明，不由有限计算认证。

没有 DCC、引擎、碰撞、导航、光照或真人测试。源工作室的资产和流程没有被本脚本复现。
