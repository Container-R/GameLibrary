# 两骨位置方法：原创参考与有限检查

这是[两骨IK的位置构造与弯曲方向控制](../../../../GameLibrary/角色动画/动画运行时/逆向运动学/两骨IK的位置构造与弯曲方向控制.md)的可选复现附件。方法、公式、状态及接入条件均在正文，本目录不另设一份技术教程。

## 文件与运行

- [reference.py](reference.py)：原创建立三点位置的无状态参考；接口只针对正文约定的binary64数值范围，不是ozz移植或通用输入解析器。
- [check_reference.py](check_reference.py)：41个命名用例与256个种子291的有界内部目标；命名输入及实际输出见[results.json](results.json)。
- [axis-obliquity-check.py](axis-obliquity-check.py)：用独立旋转公式核对斜轴反例、垂直轴对照，以及旋转/正均匀尺度下的9组距离检查；结果见[axis-obliquity-results.json](axis-obliquity-results.json)。

把同目录三个Python文件保存到一个工作目录，使用支持binary64 float的Python 3及标准库运行，不需要引擎、第三方依赖或构建ozz：

```sh
python3 check_reference.py
python3 axis-obliquity-check.py
```

脚本将检查结果写到标准输出，断言失败时停止。参考参数中的p是方向；zero_dir对应正文零距离分支的w。非有限测试输入在JSON中以字符串记录，便于严格JSON解析；脚本中的实际输入仍为相应的浮点特殊值。

## 结果应怎样解释

位置检查的随机输入只覆盖两骨长度[0.1,2]及可达距离内部2%–98%的有限样本，不证明全域稳定。当前结果最大该批残差约1.582e−15；不同运算实现可能出现细微舍入差异，不应把结果文件当作所有设备必须逐位相同的标准。

最初曾把十进制0.4/0.6/0.2当成精确浮点内边界，位置断言失败。修订测试没有放宽位置门槛，而是保留该输入的微小侧向高度，并另用可精确表示的二进制数检查精确边界分支。正文说明了这一区别。

轴反例只代入固定源码所用的角度关系，采用普通旋转公式检查距离不变量，没有执行ozz、SIMD近似或上游测试。所有输出都不是骨架、蒙皮、动作观感、性能或真人验证。结果只记录计算输入、输出与检查范围。
