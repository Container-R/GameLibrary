# 本轮已解决的问题与证据

TASK-2026-0309，researching。下述不是正式方法文章，也不声称原始资料作者使用了本包算法。

## 一、先定义保留谁，否则奖励可以完全失效

本轮重要结论：当想减少的是同一种行为在两个目标之间改选时，把当前行为类型的奖励同时给两个目标，不会形成目标保留。

设当前候选为 `(采矿,矿点A)`，竞争候选为 `(采矿,矿点B)`；两者基础分分别为 `U_A` 和 `U_B`。如果因为当前在采矿，就给所有采矿候选加 `h`，比较是 `U_A+h` 与 `U_B+h`，分差仍为 `U_B-U_A`。这不是 h 太小，而是奖励加在错误的比较层。把 h 调得更大也不能改变此二选一结果。

如果只有具体当前候选 A 得到奖励，规则变成：B 严格大于 `U_A+h` 才替换 A；相等时保留 A。在候选都有效、分数仍在同一尺度且选择器是确定性最大值的前提下，这才产生一段保留区间。

`results.json` 的同类型两目标回放提供直接区分：基础分在 600/610 与 610/600 间交替，h=50。类型奖励六次都换目标；具体候选奖励六次都留在 A。这里只比较选择结果，没有模拟角色走路或采矿产出。

接入含义：若架构先决定“采矿”，再由另一个选择器决定去哪座矿，奖励高层“采矿”并不能稳定低层目标。应在真正拥有目标选择权的层记录和比较目标身份，或者明确定义组合候选。不是所有项目都应把整个行为栈压成一个大键。目标身份所含参数应以“改变后是否需要接管/重启当前行为”为准。

## 二、迟滞不是最低持续时间

两候选的固定加法奖励 h 会产生方向不同的切换门槛。令 `D=U_B-U_A`：当前为 A 时，只有 `D>h` 才选 B；当前为 B 时，只有 `D<-h` 才选 A。边界相等时保留当前。

线性扫描回放使用 -60 到 +60 再返回的 D；h=50 时，第一次在 D=60 换到 B，返回时到 D=-60 才换回 A。D=50 与 -50 都没有替换。该结果由规则直接推出，回放检查了实现与推导一致。

但若 D 每一步都在 +60 与 -60 间跳动，仍然六步六次切换。因此不能把 h 宣称为“保证至少执行多久”。

可以进一步推导一个有条件的界限：只有两个始终有效的候选、固定 h、没有其他抢占机制，且分差随时间的变化幅度满足 `|D(t2)-D(t1)| <= L*|t2-t1|` 时，从 A→B 再反向 B→A，需要分差跨越大于 2h，因此两次相反切换的时间大于 `2h/L`。这是原创条件推导，不是本轮测得的游戏性质。真实目标失效、候选集合变化、感知突变、随机选择或分数不连续都不满足这项前提，不适合拿它设通用持续时间。

还应区分三候选问题：A→B 后，C 可能立即更优，前述两候选反向界限不能保证所有切换间隔。因此本轮不将该推导作为正文必须教授的公式，留给下一轮判断是否有实际读者价值。

## 三、门槛的单位是评分尺度，不是毫秒

原始分为 A=500、B=530，h=50 时保留 A。分数整体乘 10、h 不变时选 B；连 h 一起乘 10 才恢复原选择。结果见 `scale_dependence`。

所以阈值必须跟评分尺度一起调。值域都写成 0 到 1 也不自动保证不同动机的分差含义一致；需要设计者定义曲线和代表情境。本文不能用一次回放推荐 h=0.05，也不能把 h 转成普遍的反应时长。

## 四、评分频率与有效性检查可以分开，但不能夸大时延结果

模型的普通评分时刻是 0ms、100ms，目标 A 在 40ms 从资格集合删除。只在普通评分时检查资格的分支到 100ms 才改选；每 10ms 检查当前资格、发现失效立即重新选择的分支在 40ms 改选。

这证明两种调度规则不是一回事，不能证明某引擎能在 40ms 停止真实行为。模型中目标失效恰好与 tick 对齐，资格真值和候选分数已经在输入里，停止是同步的，且失效事件会额外触发完整重选。真实接入还会受到感知延迟、更新排队、评分预算和停止过程影响。

当外部世界变化尚未进入感知，增加选择器检查次数也看不见它。若当前资格只在重规划时才更新，单独高频读取同一份陈旧值仍不能解决响应问题。

下一轮需分别记录“发现当前失效”“解除当前选择意图”“新的候选可用”“新行为允许开始”四个意义。可以先清除无效意图并等待下一次普通评分，不必为本例结果而规定失效时一定全量重算。

## 五、保留资格与低评分要分开

本模型让不合格候选不进入比较，合法候选可以有 0 分。已移除的当前候选不能靠奖励回来；候选为空时返回 None。结果中的无候选和重新出现候选仅观察选择输出，没有执行器资源回收。

下一轮必须补开始资格与继续资格的差异。例如扣除一次入场费用后，当前行为可能仍可继续，但已经不满足再次开始的费用条件。若把新行为的开始条件直接重用于当前候选，会人为制造失效。另一方面，目标真实消失不能仅当作低分偏好。具体条件由项目规则规定，本轮没有替游戏决定。

## 本轮范围及停止点

已有明确、可复现的新结果：**类型奖励不能稳定同类型具体目标**，且已经排除“把奖励调大即可”这一错误方向。附带回放澄清了评分迟滞、尺度与调度的边界。

本轮不继续堆算例、不搭 AI 框架，也不把此研究包改名为正式文章。独立窄审查指出，模型只记录选择转移，没有 start/stop 调用或闭环行为成本。现阶段足以接续完整研究，不足以宣称交付可生产使用的完整行动管理器。

下一项有效工作是把候选选择接入一个同步持续行为的最小合同和完整轨迹，再决定是否具备独立文章的任务完整性；见 `scope-and-continuation.md` 与 `assessment.md`。
