# 并行汇合期限风险：复现说明

本目录复算[正式方法](../../../../GameLibrary/项目管理与测试/制作管理/交付计划/并行输入汇合的期限风险判断.md)的原创有限教学模型。所有概率、时长、资源和候选方案均为人为条件，不是游戏团队记录。正文已包含理解和使用方法所需的全部输入、公式与主要结果。

## 文件

- `case-data.json`：主例各变量的取值与精确十进制概率、固定尾段、查询点、两项条件改动、边际配对与旧均值反例。
- `reproduce_case.py`：只使用 Python 标准库的有限枚举程序。
- `results.json`：实际执行的结果，保留精确分数和便于阅读的十进制值。
- [common-event-merge.svg](../../../../GameLibrary/项目管理与测试/制作管理/交付计划/examples/common-event-merge.svg)：共同事件到两路到达、汇合与固定尾段的原创计算关系图。
- [finish-cdf.svg](../../../../GameLibrary/项目管理与测试/制作管理/交付计划/examples/finish-cdf.svg)：依据实际枚举结果绘制的原创阶梯累计分布，实心点包含跳点，空心点不包含。

保存的结果与两图来自同一次修订后的实际运行。数值是精确枚举结果，重复执行不会增加对模型参数的证据。

## 运行与副作用

在本目录下，用 Python 3.12 执行：

```sh
python3 reproduce_case.py --input case-data.json --out-dir fresh-run
```

输出目录必须尚不存在。程序先读取输入并计算，随后创建指定目录，只在其中写入 `results.json` 和两幅 SVG；不覆盖已有输出，不修改输入文件，不访问网络，不运行排程产品，不使用随机数，不安装依赖。再次运行请选择新的目录名。拒绝覆盖的错误不会改变已有结果。

输出在 Python 3.12.14 中生成。SVG 采用常见中文字体名称及通用字体回退；不安装字体的阅读器可能采用不同字形，数值和坐标不受影响。

## 实际核对的内容

- 每个输入概率域非负、时间非负，概率总和为1；8个主情境的权重总和为1。
- 每情境只使用一个 `Z`，同时形成 `T_A=X_A+Z`、`T_B=X_B+Z`，再求 `F=max(T_A,T_B)+1`。
- 终点分布为3、5、6、8工作日，概率分别0.512、0.288、0.128、0.072。
- 截止判断使用 `≤`，分位使用首个累计概率达到目标的时刻：P80为5、P90为6、P95为8。
- 原模型与两项条件改动的均值、期限5与6概率、P90与P95。
- 共同发生率范围两端的结果及达到90%所需的发生率门槛。
- 三种边际相同的配对表，以及1/3天模型中的独立与同步快慢平均。
- 六次全成功在指定独立、恒定成功率0.7模型中的概率。

有理数计算避免把0.8的边界误差变成分位跳错。程序中的检查是输入和算术的一致性检查，不是独立审稿，也不证明真实工作独立、资源可用、风险率已校准或某项改动已经生效。实际项目的多日历、容量冲突、预约与返工需要先进入对应情境，本程序没有实现通用资源排程。
