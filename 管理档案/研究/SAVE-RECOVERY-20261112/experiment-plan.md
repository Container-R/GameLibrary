# 进程中止夹具：执行前冻结

承接 brief.md 的判据，不更换问题。此次是 Python/Linux 教学实现，单串行写者、同一文件系统、完整复制、不可信外部写者不在范围。所有测试数据仅在本目录。

固定 A：角色无钥匙，宝箱未领取，区块 town、old。B：角色有钥匙，宝箱已领取，区块 town、new。C：在 B 的语义上推进修订号。每个对象带 slot、generation、revision、schema。清单绑定角色、元数据和元数据声明的完整区块集合；所有对象的身份和业务约束一起检查。根记录绑定活动/前代清单摘要，用校验和检测意外记录损坏，不提供鉴权。

保存：预期父代检查 → 创建唯一候选目录 → 数据写完并同步 → 清单写完并同步 → 重读全代验证 → 目录同步 → 临时根写完并同步 → 单次 replace CURRENT → 根目录同步 → 成功通知 → 清理孤立残留。只保留前代并不允许删除仍有读者的代；夹具仅清理明确未被引用的独立垃圾目录。恢复读取一次根，完整校验活动代，失败时只尝试根所指前代；根坏则拒绝。恢复先构造独立内存状态，验证后一次替换当前世界引用。

父进程等待子进程的确定性屏障，发 SIGKILL，wait 后启动新的恢复进程。屏障：半写区块、全部数据后、清单后、候选验证后、目录同步后、临时根半写、临时根完成、替换前、替换后、根目录同步后、通知后、清理中。每个阶段独立从 A 开始，重复 3 次。替换前预期只接受 A，替换后只接受 B。屏障不是随机调度，也不覆盖系统调用内部撕裂。

额外输入：完整未发布 B、活动代缺块、跨代完整块、错误槽、未知 schema、截断 CURRENT、业务无效但摘要重算正确、清单漏掉必需区块、所有可信根均损坏。记录实际选代、拒绝原因、内存替换前后、根字节和文件摘要。独立文件替换基线在角色 B/区块 A 时中止，必须出现均可解析但业务非法的结果。重试实验：根已到 C，B 的旧请求不得覆盖 C；B 已发布且仍为活动根的同操作重试返回已完成。

恢复中止：分别在候选解析后和替换内存前中止恢复进程；磁盘树摘要应保持不变，下一次恢复仍可完成。错误注入：数据 write 的 ENOSPC 与发布后目录 fsync 的 EIO，仅是软件错误分支，分别保留 A 和留下 B/结果未知。测试记录错误、返回码及操作日志，不声称真实设备故障。

判据不随结果修改。异常先保留，修正代码要另留版本/重跑记录。进程仍共享正常运行的内核、页缓存和设备，故不推导断电、内核崩溃、网络盘或 Windows 保证。
