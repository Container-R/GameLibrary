# 连续重采样的有限原生观察

这份材料接续[连续分块重采样说明](../../支持资料/同一段音乐分块重采样，为什么不能每块从头开始.md)，用一个很小的合成输入观察连续转换。它不是音乐试听或设备性能报告。

2026-11-04，用同一份执行前冻结的夹具完成两次运行，每次重新构建并启动进程。两次由同一操作者、同一执行环境完成；另有独立结果审读，没有独立原生复跑。库自报 0.2.2，这不能认证它与所引用官方源码提交完全一致。

每次只有八帧单声道输入、倍率2和四种调用安排，共七次处理调用：

- 保留状态的两块结果与整块相同。
- 中途 reset 后，总帧数仍相同，两个边界数值却不同。
- 输出容量5时只消费2帧；按实际计数交回余下6帧，第二次得到11帧。

这些是这组输入的观察，不推广为任意分块、倍率、转换器或音质结论。具体数值和结束边界见正文及协议。
