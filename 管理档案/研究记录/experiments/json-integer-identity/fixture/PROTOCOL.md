# JSON 整数身份：冻结执行协议

**状态：冻结协议，已获准实现与纯测试，Node 执行仍未获准。** 主编与独立来源门槛已接受固定规范范围；独立协议审查及字面表先于实现完成。主编 07:09 仅以 shutil.which 确认 Node 名称可发现，未执行版本命令；实际版本留待正式观察自报，不认证源码。初始草案与初版冻结协议已保留；本次只纠正状态叙述，数据条件与 2+2 Node 预算不变。

## 唯一条件与实际输出

一个原创 `.mjs`，只用运行时内建接口，无导入、文件读写、网络、子进程、随机数或原型修改。两段数字输入文本固定为 `9007199254740992` 与 `9007199254740993`，另有两个对应的 JSON 字符串文本；这些数字来自 ECMA 原例，不称为原创发现。所有运算在一次调用内完成：

1. 分别普通 `JSON.parse`，不使用 reviver，记录输入文本、结果 `typeof`、`String(value)`、`Number.isSafeInteger` 以及两个结果的严格相等比较。
2. 分别解析字符串 ID，记录实际字符串值、类型及严格相等比较。
3. 对第一步的两个已解析 Number 分别调用 `String`、`BigInt`，记录实际转换结果（BigInt 用十进制字符串与 `typeof` 表达）及双方是否相等；与对原始十进制文本直接 `BigInt` 转换作对照，后者实际结果应不同。不得把从原文本恢复的结果冒充从舍入值恢复。
4. 对一个由原始文本构造的 BigInt 调用默认 `JSON.stringify`，不提供 replacer、不定义 `toJSON`。捕获实际异常，记录是否抛出、异常名；不冻结实现特有的错误消息。若意外成功，保留实际返回值，不伪造 TypeError。

同一输出报告 `process.version`，不另开版本探测。预期：数字路径同为 Number，十进制字符串同为 `9007199254740992`、均非安全整数；字符串 ID 不同；解析后两种转换均不能区分；原文本 BigInt 对照可区分；默认裸 BigInt 序列化抛 TypeError。这是待检验的来源推导，程序必须记录 API 实际值，再交独立字面 oracle 比较，不能把预期表直接打印成结果。所有报告字段及类型将在实现前冻结；不输出 BigInt 本体使整个报告无法序列化。

## 最小运行与失败保留

薄 Python parent 每次使用全新自有输出根，拒复用/符号链接；准备 HOME、XDG_CACHE_HOME、XDG_CONFIG_HOME、XDG_DATA_HOME、TMPDIR 五个独立目录，Popen 紧前核路径归属、非符号链接并**另验全部为空**（现有 isolation helper 不验证空）。最小环境不继承 NODE_OPTIONS、NODE_PATH、加载器或动态库覆盖；用已确认 Node 路径直接运行冻结 `.mjs`。不公开实际路径、进程身份、环境全表或本机二进制指纹。

每次新进程组；运行超时 10 秒，超时后仅向本次拥有组发 TERM、最多等待 2 秒，再 KILL、最多等待 2 秒。收尾不确定即失败，保留工作目录与所有已产生内容，不借旧 PASS、不重试。正常 leader 退出后仍须确认所拥有组已无存活任务；无法确认也不报成功。不宣称 Popen 初始创建可中断、可以认证逃逸后代或形成文件系统沙箱。

各次保存独立 stdout/stderr、退出/超时/终态与阶段记录；预期 stdout 为一个完整 JSON 对象、stderr 为空、退出 0。缺失、重复 JSON 键、非有限数字、bool 冒整数、字段/类型/值不符均不能 PASS。公开只用经审技术输出、版本自报及源/输入摘要；失败原始诊断留内部，公开可用精确安全摘要。正常输出也须先检查隐私。

## 预算、独立性与停止点

作者恰 2 次、独立审者恰 2 次同条件调用，共最多 4 个 Node 子进程；版本随每次输出，不另跑 `node --version`。首异常停止该执行方剩余额度，保留失败，请主编判定，不替换输入或改期望重跑。每次调用均为新的根和五目录。没有压力、浏览器、游戏、其他语言解析器或网络服务测试。

独立审者须从固定规范推导字面 oracle，不能只调用作者 checker 宣布独立验证。执行输入的固定哈希、实际调用记录与各次结果分开保留；相同输出字节不证明独立调用。即使全部匹配，也只说明所观察 Node 普通接口的这组行为，不证明所有 JSON 解析器、大整数均不精确、字符串 ID 已获授权或存档身份永远有效。
