# 几何高光滤波：OpenGL 着色器对照

在本目录运行 `python3 contrast.py > observed.json`。依赖 Python 3、Pillow，以及能提供无窗口 OpenGL 上下文的 EGL/Mesa。实跑后端为 OpenGL 4.5 Core / Mesa 25.0.7 的 llvmpipe（软件光栅器），不是独立显卡性能测试。

Shader 在 64×64 浮点目标上使用真实的 GLSL `dFdx/dFdy`，不是在 CPU 上计算导数。它没有加载任何纹理。单位法线来自解析正交球面或平面；单位半程向量是 (0,0,1)，GGX α=0.015。41 个样本相位把正交采样位置等距水平移过一个像素，固定垂直偏差为 0.007。输出只比较 GGX 法线分布函数 D，省略完整 BRDF、几何可见性项、曝光与 TAA。第三通道每个像素直接执行 32×32 的盒内采样，保留原 α，是本例的密集参考。原始 D 值及中心覆盖通道见 `observed.json`。

- 球面内部的像素 (32,32)：中心点采样的 D 为 157.70–954.07；加限幅导数核后为 138.20–236.84；盒积分参考为 231.79–410.30。相对参考的 RMSE 从 284.27 变为 155.39，但近峰值被过度压低。平面中心基线与补偿结果逐样本完全相同。
- 球面边界的像素 (57,32)：中心覆盖在 0 与 1 之间切换；两个点采样方案共享同一覆盖掩码，不会被粗糙度修复。便于看出反例，球外法线解析地延伸到切平面，先求导再乘中心覆盖。边缘附近本例的滤波 D 峰约 0.00641，而盒积分参考峰约 0.0000777；不能把这个数当作真实网格/辅助片元结果。
- [五个相位的实际像素导出](phase-panels.png) 裁出球心附近 16×16 像素，以同一显示变换（灰度 = 255√(D/1000)，夹到 0–255）最近邻放大。只用作定性浏览；指标用浮点读回值计算。

导数补偿采用 Tokuyoshi & Kaplanyan [JCGT 2021 §5 式 13](https://jcgt.org/published/0010/02/02/paper.pdf) 的各向同性近似；此处通过解析形状隔离机制，无实际 G-buffer、材质系统或渲染引擎集成。不验证复杂材质、时间稳定性或性能。
