# 几何高光足迹：复现

- [CPU 算例](ndf_footprint.py)：以 Python 3 运行，核对 [实际输出](ndf_footprint.observed.json)。解析球面和无曲率平面均不含贴图，比较同一像素在 41 个相位的中心 D、邻居差分补偿以及密集盒采样。128×128 附有 64×64 的收敛对照。
- [OpenGL 着色器实跑](native/README.md)：以真正的片元导数重跑平面和球面，并测球面边界的覆盖反例。包含原始着色器、浮点读回和统一映射的五相位图。

两组都只比较 GGX 的 D 项，设置为固定半程向量；不是完整光照、带遮挡场景或 GPU 性能验收。
