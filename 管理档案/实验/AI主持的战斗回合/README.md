# AI 主持回合交棒的顺序模型

Node.js v24.22.1；不依赖第三方包。运行 `node turn.mjs`，断言通过后输出 JSON，可与 `trace.json` 比较。每行依次为处置、回合序号、当前角色、主动作是否尚可用、剩余移动、附赠动作是否可用、累计交棒次数。

同一六事件序列，两种方式都检查当前回合和角色。基线只要匹配就接受结束提议；实验组另行要求控制者确认。序列固定为主动作、模型的结构化结束提议、移动、非控制者的结束、控制者的结束、同一旧序号重试。基线第二项切换且随后全因旧回合拒绝；实验组第三项移动后仍属原角色，剩四格，第五项才切换，第六项拒绝。两者都初始化下一角色的行动资源；旧角色的资源不随交棒转移。

这是人工构造的顺序状态机，不运行 Open Game Master、真实模型、网络、身份验证或多处理者竞争；`source` 和 `actor` 是已经由可信入口标好的输入，不是模型可设置的字段。只用两个固定回合演示交棒，没有实现完整先攻顺序。旧序号拒绝防止此序列再次推进，不证明通用幂等或能重放成功响应。
