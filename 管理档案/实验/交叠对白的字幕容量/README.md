# 交叠对白：枚举时间档后的字幕区占用

Python 3.12.14，运行 `python3 schedule.py`。脚本以 100 ms 为单位枚举所有给定起点；每个字幕按半开区间生效，在区间端点累计行数并判是否超过两行。A 固定 [0,22)，一行；B 每次显示 12 个档。原窗口取 10、11、12，B 为一行有 3 种可行，为两行无解。将 B 的实际对白重排后，输入窗口改为 22、23，B 仍两行而有 2 种可行。本例设定到期样式立即移除；动画淡出等占位若仍存在，要另行计入实际展示。

行数、阅读时间和声画可接受范围都是人工设定，不是界面字体测量、经验证的读速、WebVTT 播放或真实游戏。代码只检查列明的起点与同区的行数，不判断遮挡、区域眼动、话语理解或实际音画对应。
