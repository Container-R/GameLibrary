# 断续心跳的游玩时长：合成事件回放

用 Node.js 24.22.3 执行。目录内不需要外部包、账号凭证或玩家数据：

```sh
set -o pipefail
node probe.js | cmp - observed.json
```

- [试件源码](probe.js)含全部合成事件和断言；[实际输出](observed.json)含输入、每条设备流的区间、账号并集、设备秒、去重及忽略记录。
- 发生时间已在同一合成秒轴上。到达截止筛选能看到的事件，观察截止限定所估区间。同一物理设备有多个代次时，先并集再计设备秒；出现新代次不会自动退休旧代次，本回放以已确认的 `retire` 显式截断。
- 样例事件为 20 秒周期附近、最大衔接 30 秒。按不外推／补尾两档，基础结果是 110／130 账号秒，不是 140／180 设备秒；B250 晚到后为 130／150。同 ID 重发不变；合格标志误报的后台心跳不能复活旧段。
- 长静默后才收到明确离开为 20／40 秒，跨日分别为 20／30 秒。单独的迟到离开案例将 20／40 修订为 25／25，说明两档不一定同方向变化。数据到达截止和观察截止取不同值，以及没有明确退役的同设备代次重叠，都单独测试。
- 不测 Android、Unity、Beam、实际时钟漂移或真实玩家。日窗端点由调用方给定，试件不实现时区日历、分布式水位线或生产数据回补。
