# 任务选项版本对照：有限模型复验

本材料支持[任务选项改了条件，怎样找出被关掉的剧情路线](../../../GameLibrary/叙事设计/运行时叙事/选项与路线验证/任务选项改了条件，怎样找出被关掉的剧情路线.md)。

## 文件与运行

- `check.py`：原创 Python 模型与断言，无第三方依赖。
- `observed.json`：Python 3.12.14 实际输出，包含各状态的选项差异、两版到达前缀、新增与丢失状态及验收结果。

在本目录执行：

```sh
python3 check.py > observed-recheck.json
```

原始执行成功，退出码 0。复验另写文件以保留原记录；Python 版本字段可能随环境变化。

## 结果与边界

旧版共有 9 个可达状态；获准修改候选有 8 个，按约定通过；阈值误改候选有 7 个，拒绝；条件过宽候选有 10 个，拒绝。三种候选都能从每个可达状态到达一个结局。另检查完全保留旧版必须拒绝、2 状态预算返回未判定，以及 `trust=2, badge=true` 不可达。

脚本只建模有限、确定、无环的两动作任务。此模型的每个非终点直接或再走一步就进入终点，因此其后继检查可支持能结束的结论；不能把同一检查用于任意有环故事。`accepted` 仅表示本例明确的作者约定、完整探索及允许的图变化均满足，不是一般剧情验收器。

没有运行 ink、真实 UI、宿主奖励、随机内容或旧存档迁移。固定 ink 来源用于正文的工具语义解释，不是这个 Python 模型已调用解释器的证据。
