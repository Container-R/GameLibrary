# 低分辨率软粒子的深度边缘

正文：[半分辨率烟雾贴墙，为什么轮廓会漏出来](../../../GameLibrary/图形渲染/画面呈现/透明合成/半分辨率烟雾贴墙，为什么轮廓会漏出来.md)。

在带 Mesa EGL、软件 OpenGL 4.5 和 Python 3 的 Linux 上执行 `python3 -B probe.py`。脚本要求 surfaceless EGL；无需安装 Python 库。前两行是渲染器/版本，后续数值与 [GPU 读回](gpu-observed.txt)对应，程序自带断言。可选 `python3 -B model.py` 重跑两个眼深的算术检查，对照 [CPU 输出](observed.txt)。

全分辨率输入是重复两行的 R32F 线性眼深，先用 GLSL 在 2×1 RG32F 帧缓冲写深度标签和不透明度；再在 4×2 表面用双线性、深度选择或阈值失败回退输出，不透明度写红通道。读取两个相同行验证一致，只记录一行 4 个 8 位值。没有硬件深度测试、透明混合、非线性设备深度、引擎或物理 GPU。

第一组全深度 10/2/10/10；第二组 10/2/10/2。深度选择在仅两小图像素时比较两者的标签；若没有接近的标签，试件用已知恒定粒子深度和全分辨率深度重算。此回退只是机制演示，不代表从深度单独重建真实粒子外观。
