# 虚拟背包图标绑定：复现材料

要求 Node.js（本次 v24.22.1），无第三方依赖：

```sh
node fixture.mjs
```

成功返回 0，并输出九组 PASS。断言失败返回非零。`output.json` 为本次保存结果。可用 `node fixture.mjs > rerun.json` 后比较输出。

程序使用手动放行的加载替身，串行执行绑定、完成与解绑；即使请求取消，替身仍允许结果到达。成功结果是带持有计数的字符串，不是真实图片。坏变体是用于展示反例的控制组，其错误输出是断言的预期，不表示它们正确。

覆盖：复用乱序、同 ID 同图标键重绑后的旧失败、加载前占位、解绑后迟到、实时重排、同物品图标版本改变、当前失败后旧成功、同步缓存完成排队、旧控件替换。每组完成后检查本方成功结果持有被恰好归还一次。

不调用 Unity、不创建 ListView、不读取设备、不测试纹理上传、渲染性能或真实截图。列表重排由应用显式重绑可视单元格，故不能以本测试证明 Unity 自动刷新已正确接入。
