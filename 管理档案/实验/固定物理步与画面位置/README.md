# 固定物理步与画面位置：复现

正文：[固定物理步下，角色匀速跑为什么还是一顿一顿](../../../GameLibrary/玩法程序/玩法系统/时间与模拟/固定物理步下，角色匀速跑为什么还是一顿一顿.md)。

在本目录分别运行以下命令。使用 Godot 4.7.2.stable.official.ed1daf0bf；两组都是无窗口模拟，`--fixed-fps` 以指定的人工节拍推进普通更新，关闭实时同步。

```sh
godot --headless --path cadence-control --fixed-fps 60 --script cadence.gd
godot --headless --path pivot-control --fixed-fps 40 --script pivot.gd
```

- **直线**：50 次物理更新/秒，位置每步加 0.12。第 13 到 132 次普通更新各与上一次比较，按 0.01 精度分桶。两类位置取自同一节点、同一次普通更新。循环边界有余量四舍五入读成 1.000000 的样本，应使用返回的实际步号与权重，不用公式重新推定引擎执行了几步。
- **镜头**：用同一组坐标计算无旋转、视幅恒定的横向固定偏移模型，分别取最新快照减 2、插值位置减 2 作为镜头中心。没有运行 Camera3D 或坐标投影 API。
- **传送**：两个额外、初始静止的节点在第 120 步均设置为 100，仅一个在移动后重置插值。记录该步中读取的两个插值坐标并断言符合各自预期。
- **刚性挂点补充对照**：固定局部偏移 (4,0,0)，10 Hz 物理、40 Hz 普通更新；父节点每步绕 Z 轴转 30° 并平移 (0.24,0.10,0)。普通子节点的 Godot 插值全局位置，到插值父节点原点是 4.000000；用相同端点手写世界坐标混合，在中点缩成 3.863703（`4 cos 15°`）。这能区分取样时间和取样空间两种错误；该对照未测独立模拟的乘客、碰撞或缩放。
