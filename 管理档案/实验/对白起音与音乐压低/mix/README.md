# 固定对白和音乐素材：首词压低对照

运行 `python3 render_mix.py > observed.local.json`，用 `diff -u observed.json observed.local.json` 对照本次结果。依赖 Python 3 和启用了 libflite 与 sidechaincompress 的 FFmpeg，本次为 7.1.5-0+deb13u1。无须网络或下载素材。

输出目录 `rendered/` 有五个 WAV：单独的 `voice.wav` 和 `music.wav`，以及 `no-duck.wav`、`fast-reactive.wav`、`pre-duck.wav`。三份混音直接相加，均使用同一条语音，未做混音响度归一、自动增益或限制。可用播放器固定音量切换这些文件；不要把手机自动均衡后的对照当作等设置试听。输出峰值是样本峰值而非真峰值。

对白是本试件原创短句 “Wait. The gate is open.”，用 FFmpeg libflite 的标准 `slt` 合成发音，不是现场演员。脚本不附带任何商用对白、样本或模型文件。伴奏由脚本合成原创和弦及谐波，没有第三方录音素材；再现只需运行脚本，不要求分发本地生成的 WAV。

独立合成第一词和后半句，把峰值分别设为 0.145 和 0.4。按 48 kHz PCM 的 5 ms 块找首末 RMS 不低于 0.002 的块并裁出，第一词从 500 ms 开始，留 140 ms 空档后接后半句；这些都是试件控制，不是自动逐字对齐。预压从首词前 60 ms 做线性 dB 斜坡到 −7.5 dB，维持至后半句结束，再用 160 ms 回到正常。原生反应压缩用峰值检测、12 ms 攻击、180 ms 释放、0.125 阈值、4:1 和硬拐点，检测输入是这条固定语音。

观测值用同窗音乐单轨的输出/输入 RMS 比报告；安静第一词及 140 ms 间歇近 0 dB，后半句 −1.105 dB，计划预压在三窗均 −7.5 dB。没有把峰值恒定的换能试件当真实语音包络。可听文件已解码并核对样本数和峰值，当前没有人工试听、转写或可懂度结果。
