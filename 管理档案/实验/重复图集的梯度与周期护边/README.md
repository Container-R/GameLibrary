# 重复图集接缝：OpenGL 对照复现

Linux 上需要 Mesa libEGL/libGL、Python 3 和 Pillow。运行 `python3 reproduce.py`，将输出与 [observed.txt](observed.txt) 对照，脚本重新生成 [对照图](comparison.png)。试件强制 Mesa 软件渲染；记录为 llvmpipe、OpenGL 4.5、Mesa 25.0.7，片元程序使用 GLSL 330。对照图用最近邻放大实际 RGBA8 pbuffer 读回的颜色。

- **A，选级对照。** 连续重复坐标每像素横向推进 1/32 个周期，图集宽 64、子图宽 32；缩小使用最近 Mip 与级内最近邻，放大用最近邻。每一级上传独立的单色标识，排除整页缩小造成的污染。第 16 和 17 列（从 0 计）位于同一导数组跨越周期的位置。隐式采样在这两列读取 Mip 5，其他列读取 0；由连续坐标求导并乘子图比例的 `textureGrad`，以及独立纹理的 `GL_REPEAT`，都在整个横向读到 Mip 0。不是所有设备、接缝相位或过滤设置都会出现同样两列。
- **B，级内颜色对照。** 固定 Mip 0，双线性过滤。子图首末红通道字节分别为 64、192；左边界混入蓝邻图时读到 (32,0,128)，复制同侧边得到 (64,0,0)，复制对侧边得到 (128,0,0)。对侧边的整个 32×8 读回与独立 `GL_REPEAT` 逐字节一致。本次仅横向重复、纵向一行，并未验证低级 Mip 的边框生成、旋转、各向异性或压缩。

固定选级的试件没有从 A 继承地址之外的 mip 选级结论；两组试件分别排除另一个变量。
