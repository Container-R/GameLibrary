# 移动单向平台：相对扫掠与原生静态对照

## 相对扫掠模型

用 Python 3.12.14 运行 `python3 sweep.py`，结果见 [sweep-observed.txt](sweep-observed.txt)。场景只有一个点足与一个宽度固定、无旋转的水平面片；两者在同一个仿真步内各自做线性平移。坐标向上为正，平台位置取面片左端。用精确分数在相对法向间隙从非负降为非正时求交，再以同一时刻的相对横坐标核对宽度。边界端点视为面片的一部分。演示的宽度漏判发生在 `t=4/5`：足部到面片左端还有 1 个单位，而面片只宽 0.5；步末横向已重叠，不能倒推出此前可落地。

稳态支撑按“前一轮已由求解器确认同一平台、没有主动脱离、相对横向仍在范围且末端间隙小”作教学判定，不假装能独立求解接触或处理间隙中途曾过大等情况。主动下穿用手动忽略标志测试；恢复条件模拟实体薄板，要求角色最上端低于板底再加间隔。真实实现要在适当的碰撞时间点检查几何，从模型选择合适门槛。脚本不处理有限尺寸脚部、倾斜、旋转、连续曲线、CCD、碰撞响应、层选择或多平台求解。

## Godot 静态对照

[Godot 4.7 的 CollisionShape2D 文档](https://docs.godotengine.org/en/4.7/classes/class_collisionshape2d.html#class-collisionshape2d-property-one-way-collision)说明 `one_way_collision` 使此碰撞形状只检测一侧；这里只测静止实体顶部，不把它当成上述相对规则的引擎实现。

Godot 4.7.2 stable official，60 Hz。用三个互不干扰的 `CharacterBody2D`（8×12 矩形）分别对着三个 `StaticBody2D`（50×8 矩形）；角色上下速度绝对值为 120 像素/秒，使用 `move_and_slide()`。Godot 这段对照的 Y 向下为正。重跑：

```sh
godot --headless --path godot_static --script res://control.gd --quit-after 300
```

[记录](godot-static-observed.txt)中的一号角色从下方越过单向平台并在下降后站回顶面；双向对照从下方撞到底面；三号角色从上方直接在另一块单向平台落地。记录的坐标是碰撞体中心。末端位置小差异不是需要校准的目标，布尔对照才是。脚本末尾有一组通过/失败退出码；若工具因限步退出而没有打印四条观测，则未完成试验。此原生对照不运行移动平台、主动下穿或无限薄面。
