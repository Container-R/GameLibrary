# 新手提示的共同资格

[返回正文](../../../GameLibrary/项目管理与测试/玩家测试/关卡引导/帮助卡只给卡住的人看，为什么不能按“看过”比较通关率.md)。

```sh
python3 -B probe.py | cmp - observed.json
```

[计算脚本](probe.py)只依赖 Python 3 标准库：[第一组](observed.json)是早期资格按相同规则、真实展示不对称；第二组是被变体改变的晚事件，两组虽然恰好各选中同样多人，但选中者完成率迥异。脚本结果均为人数、完成数和百分点，使用有理数计算。数据是刻意构造的有限反例，不含任何真实用户记录或不确定性估计。
