# 玩法模拟与表现交接：模型复算

需要 Node.js，无其他依赖。在本目录执行 `node verify.js`。保存的原始 JSON 见 `observed.json`。四组使用相同模拟初值和命令。A 每步都有表现帧，B 到末步集中消费，C 集中消费但按步号去重，D 集中消费并错误地让接收器再次扣血。脚本退出正常才表示断言通过。

`ticks` 取样在规则完成后、表现帧之前；`emitted` 是规则发出的事件，`shown` 是接收器接受的 ID，并未真的播放或绘制。`endHP` 是交接完成后状态。D 的规则步快照和事件全部正确，最后的生命却为 -2；C 的生命正常，却漏了 c2。

这个单线程模型不实现原游戏、网络、实际跨线程或渲染。提前结束、事件过期和不同接收器失败恢复策略不在当前断言内。
