# 遮挡增益的样本过渡：离线复现

对应正文：[音源经过门框时，遮挡音量为什么会啪一声](../../../GameLibrary/声音与音乐/游戏音效/空间音频/音源经过门框时，遮挡音量为什么会啪一声.md)。

运行 `python3 -B probe.py`。[脚本](probe.py)使用 Python 3.12.14 和 FFmpeg 7.1.5 的 `aevalsrc` 计算合成单声道，读回 4800 个 float32 样本。[原始日志](observed.txt)保留了数值和断言通过后的控制序列。没有运行 Web Audio 或游戏中间件。

- 输入固定 1 kHz、48 kHz 采样、峰值 0.5 的余弦；索引 1200 和 1440 分别是 25/30 ms，恰在载波正峰。每行的跳幅是该索引与上一个浮点样本的绝对差，正常波形不为零。此数字既不是频谱指标也不是听感阈值。
- 48 kHz 下 5 ms 是 240 个样本。指数转向在一时间常数后为 0.2＋0.8/e。反向回到 1 时，一个试件延续该值，另一个先写入 0.2，复核 30 ms 前后样本。
- 控制滞回是独立的十个合成输入，初态未遮挡，单阈值和双阈值分别切换 6/2 次；不把这段结果当作音频渲染、路径跟踪或关卡实测。
- 项目验证应重复其他相位和实际音色，并在切换时间旁同时留检测原值、目标值、实际增益或可代表它的探针，以及处理前后的波形。只保留一个连续源和单一衰减节点；低通、混响、限幅和声音启停另做隔离对照。
