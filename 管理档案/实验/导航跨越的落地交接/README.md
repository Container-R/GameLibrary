# 导航跨越的落地交接

对应正文：[导航角色跳过去后，怎样确认落地并继续走](../../../GameLibrary/游戏人工智能/移动导航/特殊跨越/导航角色跳过去后，怎样确认落地并继续走.md)。

运行 `node trial.js`。脚点、导航点和接触身份由试件明确给定；`output.json` 是 2026-11-21 在 V8 实际执行的输出。模型算的是二维欧氏最近点，不是物理接地、角色碰撞扫掠、导航多边形或引擎的采样实现。

- 仅用“接地且邻近导航点”会误收下层、未烘焙凸沿和靠近出口网格的独立薄板。正确支撑单独不能排除未烘焙凸沿；同侧近点单独不能排除独立薄板。组合接受目标桥面，仍须在引擎里验证到候选点的可走支撑和障碍间隙。
- 连接禁用时不提交；空中换目标不改变驱动者；当前回调过早时不完成也不失败；实际落错进入恢复；旧编号和重复回调不会多完成一次。
