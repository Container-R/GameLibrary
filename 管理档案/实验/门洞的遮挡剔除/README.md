# 门洞的遮挡剔除：整数射线试件

在本目录使用 Node.js 运行：

```sh
node probe.js | cmp - observed.json
```

墙位于 x=0，相机在 x=-64，目标在 x=64。坐标以 1/32 世界单位记为整数。每条从相机到目标的视线打在墙面的中点，因此可直接比较两倍坐标，避免舍入。半开门挡住门洞下半，主相机的目标网格有 16/32 条射线可通。侧边低机位被墙挡住。两种门洞准入时序是试件显式编写的对照，不是 Unity 的烘焙数据或内部算法。

在 JavaScript V8 中复跑，输出与记录逐字一致。代码字段 `draw_admissions` 是一个候选物体是否进入下步的模型布尔值（0 或 1），不测真实绘制指令、照片、GPU 或 CPU 毫秒。
