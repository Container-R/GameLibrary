# 探针隔墙漏光：两种相同亮度的成因

运行 `python3 probe_mix.py`；记录用 Python 3.12.14，无第三方依赖。比较 [实际输出](probe-mix-output.txt)。脚本对每次输出都做精确断言，使用标准库有理数，无舍入误差。

## 几何与控制量

单位立方体的 x = 0.5 处放边界，x = 0 的四个点为暗侧，x = 1 的四个点为亮侧，默认测试点为 (1/4, 1/2, 1/2)。每个角先按三线性插值取权重，再用人为指定的集合筛掉探针，将剩余权重归一。两侧的光照量不是渲染结果，由用例指定。法线及接收条件视为固定。无可用权重时报无结果，不等同于补黑。

用例分别单独改变接收者允许的探针集合、探针存值，并有重烘得到原值的无变化用例。同侧常量和不同 y/z 的 x 梯度用来检查归一及三维权重。该试件不运行 Unity，不建模烘焙、APV 编码、可见性规则或无样本回退策略。
