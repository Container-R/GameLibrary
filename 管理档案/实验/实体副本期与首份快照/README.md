# 实体副本期与首份快照

[返回正文](../../../GameLibrary/网络与在线服务/实时同步/实体生命周期/实体重新进入同步范围时的首份快照与旧包隔离.md)

从本目录运行：

```bash
python3 -B check_reentry.py | diff -u observed.json -
python3 -B check_retired_scope.py | diff -u retired-observed.json -
```

第一组固定会话 S 的 7 号第 4 代服务器电梯，比较旧缓存、先到的增量、旧退出和正确基线。第二组比较是否保留退出水位：独立全量能解码也不能创建已退出的期。测试了两条全量重传路径，以及含最终退出的五条消息的全部 120 种到达顺序。

两组均为原创、内存中的确定性规则。没有实际连接、网络序列化、引擎实例、确认与重发、跨会话或多代实体；最终无副本不等于每一步无闪现。
