# 着色器变体证据关联的对照

[对应正文](../../../GameLibrary/引擎与工具/构建发布/着色器构建/构建日志里有着色器变体，为什么成品里还是用不上.md)。

执行 `python3 model.py`，对照 [observed.txt](observed.txt)。脚本不读取 Unity、构建包、着色器或 GPU。它用两份各有一个成员但成员不同的集合说明计数不能回答成员归属，并用一个有明确范围的假想构建验证前后阶段与运行结果的判定。

八组断言覆盖请求不符、完整表间消失、两表均无成员、后表仍有却严格失败、捕获范围不全、不同候选、运行时无日志却未验证及明确覆盖的成功。额外检查另一个 Pass 或 API 不应被推断为完整范围。脚本没有模拟真实素材装载及关键字编译。
