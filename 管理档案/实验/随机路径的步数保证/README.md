# 随机路径的步数保证

正文：[随机关卡有一条出路，玩家就一定能到出口吗](../../../GameLibrary/游戏设计/关卡设计/关卡推进/随机关卡有一条出路，玩家就一定能到出口吗.md)

`python3 -B model.py | cmp - observed.txt`。Python 3 标准库；不要关闭断言。输出比较的是有限状态模型，不运行 PRISM 或游戏引擎。

每个状态记录玩家可选的动作；每个动作的结果以正有理数记录，实验中的权重总和为一。出口停止；死路没有动作。每个动作及其结果合为一步。第一项测试只要能沿某个动作的某个结果到出口即标记；第二项要求能选择一个所有结果都更接近目标轮次的动作；第三项以精确分数逐步递推最优概率。

[实跑输出](observed.txt)依次比较掉入死路、回大厅独立重抽、另有两步确定绕路，以及一局固定抽取结果四种情形。最后一个变体中，第一次失败后已知本局继续抽必败，脚本用单独的已知坏状态，而不是让玩家在第一次抽之前读取隐变量。
