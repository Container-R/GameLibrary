# 格挡后反击窗口与距离

运行 `node model.js | cmp - observed.json`，Node.js 24.22.3。合成的一维盒边距离与移动，不运行任何商品游戏或碰撞引擎。首个可行动帧为 0；原攻击方在第 8 帧可防，并在同一帧先于碰撞获得防御。距离是反击者参考点到受击区近边的间隙。

固定距离的六个对照分别区分够到、打空、迟到被挡、晚相交被挡与较早可防的假定状态分支。后者不模拟任何商业游戏或真实取消路线。

追加对照让受击区只在第 5 帧靠近（间隙 0.90，其他帧 1.40）。反击招是第 4 帧起效、持续 1 帧、可达 0.95；逐帧扫所有仍可能赶在第 8 帧之前接触的起手延迟 0 至 4，只有延迟 2 命中。只看延迟 0 与 1 都打空，不能排除这记反击。
