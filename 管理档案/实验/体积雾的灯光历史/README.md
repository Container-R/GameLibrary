# 动态灯拖尾：固定相机的软件试件

运行 `python3 reproduce.py`（测试环境 Python 3.12.14、Pillow 13.0.0），将标准输出与 [render-observed.txt](render-observed.txt) 对照。脚本生成 [comparison.png](comparison.png)。

- **场景与变量。** 固定正交相机；一个 64×32 的横向/深度栅格，均匀消光系数 0.045（每格深度视作 1）。用每个深度格的透射权重 `exp(-σz) × (1 - exp(-σ))` 对当前光源项积分。光源占据一条有界的倾斜窄带，在第一帧横移 27 格，此后不再移动；历史从旧位置的干净稳态开始。几何地址、视线与消光保持不动；只改照明和积累策略。输出图纵向渐隐仅是展示，全部面板用同一显示曲线和亮度尺度；日志才是线性数值。
- **拖尾与恢复。** 在同一条旧光照射线测量相对旧稳态的线性比例。90% 历史在第 1、5、15、29 帧为 90%、59.049%、20.5891%、4.7101%；70% 历史为 70%、16.807%、0.4748%、0.0032%。不使用历史或用准确变化掩码时，旧位置从第 1 帧起为零；后者对第一次变化时新出现的光也不等待历史爬升。掩码用试件已知的照明区域异或，仅在切换帧拒绝变化格；不是可从低采样渲染直接得到的可靠掩码。
- **稳定光噪声。** 独立跑静止单条代表射线，用相同的随机种子与每步均匀扰动 `[-0.3,+0.3]` 近似噪声。先跑 100 步预热，再用 3996 个样本计算相对干净信号的 RMS。无历史约 17.24%；90% 权重约 4.07%；70% 权重约 7.39%；静止时掩码不触发，90% + 拒绝仍约 4.07%。这个噪声未注入上方的干净位移对照；不能由此断言真实引擎的重采样或变化检测无噪声代价。

这是带深度积分的二维软件代理，未运行 Godot 或 Unreal、未测试移动相机或遮挡，也没有 GPU 成本、真实体积阴影、雾密度历史或重投影验证。
