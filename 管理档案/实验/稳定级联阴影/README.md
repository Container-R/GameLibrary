# 稳定级联阴影：固定世界点上的纹素格

在本目录运行（Python 3.12.14）：

```bash
set -o pipefail
python3 -B grid_probe.py | cmp - observed.json
python3 -B mask_probe.py | cmp - mask-observed.json
```

一维脚本用有理数计算纹素边界和最近采样。固定世界接收点为 1.38，理想边缘为 1.2，沿同轴比较未对齐平移、已对齐平移，以及已对齐但改变尺寸。覆盖式以每轴近邻舍入的半纹素误差和指定连续过滤足迹为前提。

二维 CPU 对照把一个固定光空间遮挡形状采成 16×16 个二值纹素，然后对相同世界区域中的 384×384 个固定探针做最近查找。对第 1 帧，第二/三帧状态变化数分别为不对齐 12672/22272、对齐与固定尺度 0/0、对齐但尺度变化 12912/18135。生成图需要 Pillow，可运行 `python3 -B mask_probe.py /tmp/shadow-contact.png`；生成的缩图只展示分类变化，数字来自全分辨率探针。

两份试件均未运行完整引擎深度比较、投射者裁剪、跨级联混合或滤波，也不测屏幕像素与性能。光空间与遮挡物固定；变尺寸例是主动控制的输入，不是测自某场景的相机旋转。

另有真实 OpenGL 深度附件与接收着色器的两遍对照：`python3 -B native/probe.py | cmp - native/observed.json`。需要 EGL、Mesa 软件 GL 和可用的无窗口平台。在参考环境 OpenGL 4.5 Core / llvmpipe 上，先把静态平面四边形栅格到 16×16 的浮点深度附件，再以另一个帧缓冲读取固定探针坐标的深度、用固定接收深度 0.75 比较。清背景深度为 1，绘制深度为 0.25。逐帧比对适用这一场景与运行环境，结果与 CPU 表的变化计数一致。未测试硬件 GPU、投射者裁剪、过滤、偏置、相机重投影或真实 CSM。观察 JSON SHA-256：`4288a0a635679add497388f527ebeed863a11733c8cd4e5e4e8809fd7c8b30bf`。
