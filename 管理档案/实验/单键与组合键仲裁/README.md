# 单键与组合键仲裁：合成回放

需要 Node.js 24.22.3，无外部包：

```sh
set -o pipefail
node probe.js | cmp - observed.json
```

[源码](probe.js)与[实际输出](observed.json)包含 12 个具名回放、1 次反转事件输入数组校验和 2 次拒绝非法输入。事件边沿先按单调毫秒及同刻序号排列，完整同刻批次先处理事件再结算恰在此时的截止。A 先按、B 同设备新按才可能组合；窗口 80 ms 是示例合同。输出附尝试 ID、命令和逻辑提交时刻。

切换层时取消待决，不把它翻成单键。此试件保持按住基线，后续有效松开已发送到新一代；没有实现设备断流后基线重采或跨批迟到修复。只验证应用规则，不测 Unity、原生设备、可感知耗时或人因。
