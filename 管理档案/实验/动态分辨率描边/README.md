# 动态分辨率描边：Pillow 浮点遮罩复现

依赖 Python 3、Pillow 13.0.0。执行 `python3 reproduce.py` 会输出数值并在脚本目录生成 `comparison.png`。参照数值保存在 [observed.txt](observed.txt)。

- 输出固定为 32×12；输入遮罩宽度为 32、24、16，高度恒定。只测水平变化方向。每一行重复同一个垂直阶跃边界，中心对齐像素边界。沿阶跃左侧生成外描边带，使用与每列相交的面积写入浮点遮罩，再用 Pillow 双线性重建。不是对源色彩、斜线、采样 MSAA 或时域抗锯齿的重建。
- 三种输入半径：固定 3 texels；按水平缩放折算后四舍五入的整 texels；保留折算后的分数 texels。日志中的 geometry 为名义输出宽度，peak 是最大 alpha，coverage 是一行中 alpha 总和，`alpha>.5` 是严格大于 0.5 的像素计数。图为放大后的遮罩对照（橙色按遮罩值编码，蓝绿色只是标出阶跃右半侧），不是颜色或感知测评。
- 在 75% 下分数方案名义宽度 3，但峰值、积分与阈值计数是不同量；积分为 2.9688。50% 的 1px 目标是半覆盖内部像素，最近邻与双线性重建都留下积分 1；峰值分别为 .500 和 .375，所以严格 `alpha>.5` 均为零。改阈值或像素相位会改变这个结论。
- 10 像素附件的有效视口为 `[1,7)`，其最后可用中心为 6.5。向右再偏一纹素采到 7.5，即 UV .75。它仍在附件内，普通附件 clamp 不会管，读取手工标记的 1；限制在当前有效视口中心后读取 0。这是单次中心采样的小试件，不是 GPU API 的滤波边界规范。
