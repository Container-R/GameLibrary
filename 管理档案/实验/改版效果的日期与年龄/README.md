# 改版效果的日期与年龄：合成复现

正文：[改版的提升越来越小，是玩家的新鲜感退了吗](../../../GameLibrary/数据分析/实验分析/统计推断/改版的提升越来越小，是玩家的新鲜感退了吗.md)。

运行 `python3 -B model.py | cmp - observed.txt`，需要 Python 3 标准库，不要关闭断言。比较的是确定输入的有理数，并不运行真实游戏或估计实际玩家因果效应。

- 批内效果不变：日历粗汇总为 20、8、8 个百分点；年龄 0、1 使用同一组批权重后均为 12 点。批内衰减正对照的等权年龄曲线为 12、6 点。
- 两批相隔一天，比较日历效应与年龄效应。两种假设都给出 15、5 点的年龄曲线；共享日按早、晚批拆分别为 10/10 和 5/15。
- 两个独立分配块的灰度比例为 10/90 和 90/10。每块内都是 +10 点，粗合并 35% 对 65%，用共同权重回到 +10 点。

`observed.txt` 中每个分数都按 0–1 的率或率差报告；例如 `3/25` 是 12 个百分点，不等于相对提升 12%。
