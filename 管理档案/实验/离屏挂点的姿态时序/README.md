# 离屏挂点的姿态时序

[回到正文](../../../GameLibrary/角色动画/动画运行时/姿态更新/角色离开镜头后，道具挂点为什么还在用旧姿势.md) · [Python 脚本](pose_trace.py) · [实跑 CSV](pose_trace.csv)

运行 `python3 pose_trace.py`，脚本直接断言每组（消费的姿态编号、组件空间 X、生产者结束后的编号、返回的世界 X）。`python3 pose_trace.py | diff - pose_trace.csv` 应无输出。比较同一个移动根下的正常、跳过发布、早读、无效名字和新采样同坐标。没有旋转、混合、真实渲染或多个线程；这不是实机复现，也不测实时性能。

重点对照第 2–3 帧：`stale` 和 `fresh_same_value` 位置完全一样，但骨骼编号分别保持 1 或推进到 2、3；`early` 的第 2 帧也返回 210 厘米，但最终生产者编号为 2。无效名字没有姿态消费编号，它的返回值模拟 UE 文档中的世界空间回退。
