# 纹理视图、采样器与 Mip 的对照

[对应正文](../../../GameLibrary/技术美术/环境管线/纹理与材质/高分辨率%20Mip%20已加载，为什么这次绘制还是发糊.md)。

在有 Mesa EGL/OpenGL 4.5、支持 surfaceless 平台和 Python 3 的环境运行：

```sh
python3 egl_mip.py
```

程序强制软件渲染。它为同一张不可变 RGBA8 纹理分配九层，每层填一种颜色，创建共享底层存储的 2–8 子视图。无各向异性，启用最近纹素和最近 Mip，关闭抖色、MSAA、混合、深度和帧缓冲 sRGB。全屏三角形的有效采样坐标随屏幕 x 以每像素 1/64 变化；对 256×256 完整视图，纹素足迹对应 Mip 2。对固定 LOD 0 的试验，分别保留原采样器和换中性采样器，而不更换视图。

每类分别读取隐式采样、原采样器显式 0、中性采样器显式 0，并将结果颜色解码为原资产层。另一次绘制把 `textureSize(src,0)` 的宽度和 `textureQueryLevels(src)` 编入像素读回。中心像素和输出见 [egl-observed.txt](egl-observed.txt)。这不是对硬件内存分配、UE 流送、实际帧耗时或纹理视觉品质的测量。
