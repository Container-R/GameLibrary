# 法线 Mip 斜率统计试件

这是两组斜率分布的精确分数试件，不读取纹理，也不运行渲染器。每组有两个等权纹素，第一组斜率沿 +45°，第二组沿 −45°。各纹素的局部协方差是零；同一个线性合并中，先平均五个矩再恢复协方差，会保留均值间的变化。

`python3 check_moments.py` 输出 [observed.json](observed.json)。试件在 Python 3.12.14 下运行；检查同一平均单位法线长度、对角线变化相反，以及直接平均子协方差的退化结果。该模型未生成 mip、量化纹理或预测材质高光。
