# 偶发存档回退：复现缩减试件

用 Python 3.12.14 执行 `python3 reproduce.py`，对照 [disk-observed.txt](disk-observed.txt)。脚本只在一次性的临时目录操作合成 JSON，未读取玩家存档或调用游戏。每次候选从同样的版本 0 字节起跑，生成两份候选，按显式事件顺序把文件替换为生效版本；读回重新打开正式文件而非引用现有对象。没有断电测试、fsync、真实线程竞态或引擎测试。

- 主对照：原轨迹及删掉配乐、转镜头后的轨迹都以版本 2 被版本 1 覆盖并重新读到 1；交换发布顺序后读到 2。
- 未决：缺请求、候选没有到达终态或未执行读回。单项删除结果针对脚本当前判据；不能说全局最短。
- 修复对照：串行发布路径检查当前版本后拒绝旧候选，读取版本 2。这不是并行提交协议。
