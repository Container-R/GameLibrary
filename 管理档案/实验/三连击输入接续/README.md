# 三连击输入接续：实验附属材料

[正文](../../../GameLibrary/玩法程序/玩法系统/战斗状态/三连击的输入缓冲、接续窗口与打断清理.md)是唯一技术解释入口。本目录只保存原创测试输入、执行方法和结果，不另设技术长文。

## 应用模型

在本目录执行 `python3 combo_model.py`，将 JSON 与 `observed.json` 比较。模型无引擎调用；输入、政策及显式失败检查写在脚本中。已有正常与优化模式运行输出一致。本次发表整合未重复运行。

## 方法轨探针

在本目录执行下面两条命令，`godot` 应替换为读者自行选用的 Godot 4.6 系列可执行命令，不要求使用记录者的程序：

```sh
godot --headless --path probe --script main.gd
godot --headless --path probe --script deferred_seek.gd
```

这两份脚本及 target.gd、project.godot 是已有观察实际使用的输入，迁移时未改内容。逐行 JSON 分别与 observed-isolated.txt、observed-deferred-seek.txt 比较，忽略启动横幅和 JSON 键顺序。输出公开副本仅删除启动环境横幅及空行；各 JSON 结果行原样保留。

每例独立创建播放器；手动更新、立即方法回调、非循环1秒动画、无混合。首个探针的键为0.1/0.2秒，先 play与advance(0)初始化，再比较推进至0.3与三种seek；第二个键为0.2/0.4/0.6秒，速度1，seek至0.5后advance(0.15)。所有setup数组为空。`application_window_accept`只是一项按字面范围算出的布尔值，不是引擎接受输入的证据。

历史程序自报4.6.3；没有完成官方发行字节来源认证，也没有建立它与正文固定源码提交的构建对应。这里保留有限观察而非认证发行行为。读者用不同程序出现差异，应记录差异，不把本输出当作所有安装必须满足的契约。未测试可见渲染、真实输入设备、完整三连击、混合、根运动或命中。
