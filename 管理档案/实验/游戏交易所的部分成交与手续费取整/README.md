# 复现：游戏交易所的部分成交与手续费取整

在本目录中运行：

```sh
node fee-replay.js | diff -u fee-replay.observed.json -
```

Node v24.22.3。模拟一个已预备 100 金币的买家、一张总价 100 的卖单，以及按卖单累计、3% 向下取整的手续费。验证固定六笔拆分、重复投递、成交 34 后撤单、撤单后拒绝新成交、相同 ID 载荷冲突，以及 4,851 种将 100 拆成三个有序正整数的结果。每步核对累计手续费、剩余金额和金币总量。

此试件顺序执行，只验证金额、状态过渡及重发不重复扣款；不含 PostgreSQL、并发、真实撮合、物品冻结与发放，也没有仿真网络回包。
