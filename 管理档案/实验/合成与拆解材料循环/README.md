# 合成与拆解材料循环：有限步整数状态搜索

[返回正文](../../../GameLibrary/游戏设计/系统设计/成长与经济/合成与拆解为什么能反复产出材料.md)。

[脚本](fixture.py)只用 Python 3.12 标准库。为保留脚本断言，请勿使用优化模式。执行并核对[原始输出](fixture-observed.txt)：

```sh
python3 fixture.py > /tmp/craft-observed.txt
cmp /tmp/craft-observed.txt fixture-observed.txt
```

状态顺序是废料、零件、残渣、机器剩余电量。合成与拆解分别检查输入、先扣再加，最后检查三类库存的总件数。电量不是背包物品；只在单独的电量对照中消耗。未建模入库、丢弃、买卖、等待、时间或补货；加进任一规则，闭合性需重查。

脚本广度优先枚举从给定初始状态八动作内可达的不同状态，并检查从所有已枚举状态出发的合法后继是否仍在集合。基线 9 状态未闭合，观测到 4 个以零件为唯一增长项且其余项恢复到种子的状态。无种子、返两件、一格电量、容量三件、容量四件分别有 1、3、4、2、4 个已闭合状态；容量四件虽有 1 个增长状态，但第二轮拆解溢出。零件没有上限、无电量消耗的基线可任意重复，是正文的独立推导，不是深度八的搜索结论。
