# 静态补给必经：复现材料

原创教学模型，使用 Python 标准库，无游戏引擎依赖。

```sh
python3 check.py
```

本次环境见 [runtime.txt](runtime.txt)，输入与预设断言写在 [check.py](check.py)，实际标准输出见 [observed.json](observed.json)。2026-11-18 UTC 执行，退出码 0。五个图分别区分必经、绕行、原图不可达、方向错误和可达死路；程序还校验所有输出路径的首尾、相邻边及绕行不含 R。

`wrong_room` 是独立字符串用途断言，不是素材检查器。此试件未运行关卡生成器、房间装配、碰撞或玩家移动，未证明实际补给领取，也未验证多出口/多补给扩展或状态图。没有性能测量。本文复杂度来自邻接表 BFS 分析，不来自这组运行耗时。
