# 粒子传送与历史重置

这是一个一维策略模型，不调用 Godot 或 Unity 的粒子模块，也不采集画面。运行 `node model.js | cmp - observed.json`；使用 Node.js 24.22.3。代码内断言覆盖各项重置和传送后普通移动的发射节奏。

| 条件 | 旧世界粒子 | 旧局部粒子的世界读数 | 插值中点 | 沿途发射 | 拖尾边数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 三项均未处理 | 1 | 101 | 50 | 200 | 1 |
| 只重置距离采样起点 | 1 | 101 | 50 | 0 | 1 |
| 另重置变换插值 | 1 | 101 | 100 | 0 | 1 |
| 再分隔新旧拖尾段 | 1 | 101 | 100 | 0 | 0 |

跳变 0→100；间隔 0.5、无沿途发射限额、跳变前无余量。正常移动的 100.25 与 100.5 检查另从 0.25 或 0 的发射余量开始。SVG 是依据模型绘制的示意图，不是引擎画面。
