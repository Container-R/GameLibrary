# 粒子距离发射与路径采样：几何图复现

使用 Python 3 和 Pillow 13.0.0。在本目录执行 `python3 produce.py`，就地得到 `comparison.png`，将终端输出与 [geometry-observed.txt](geometry-observed.txt) 对照。所有点由代码计算。图上四个面板共用距离比例；深色实线是已知输入路线，蓝色虚线是仅从端点构造的弦，橙点是出生位置。

- A/B 使用同一直线和 8 个出生事件。A 的点都放到段末，B 沿段每 0.5 米发一次。改变直线采样点但保留发射余量，结果不变。
- C/D 比较同一 2 米加 2 米的拐角。保留拐角点得到 8 枚，省略它只按首尾弦计算得到 5 枚。
- 限额对照：第一段前进 2.25 米，理论应发 4、实际发 2、丢 2、余 0.25 米；下段前进 0.25 米只在 2.5 米处发一枚，没有补偿丢掉的两枚。脚本为此对照在第一段保留最早两点；它验证相位，不用于证明某种上限抽样画面更平滑。

试件不运行 Unity 或 UE，也不模拟出生年龄、粒子力、碰撞、局部坐标变换或实际烟尘外观。
