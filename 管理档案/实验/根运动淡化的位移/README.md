# 动画交叉淡化的两种位移

[返回正文](../../../GameLibrary/角色动画/角色移动/根运动与动作对齐/动画交叉淡化时，为什么混合根位置做差会让角色猛冲.md)。

用 Godot 4.6.3 稳定版，在此目录运行 `bash run.sh | cmp - observed.json`。[固定设置](project.godot)和[测试脚本](probe.gd)不需要编辑器、图形窗口或联网。Shell 为临时运行设置可写的 XDG 目录；命令保留 JSON，脚本有验证失败退出码。不同系统的浮点最后几位不保证逐字相同。

[实际输出](observed.json)保留三种相同空间的单轴非循环轨道对照，在每步同时读位置混合值及运动增量。同步 Blend2 让两输入共享推进的步长，本试件未放入实际角色控制器、碰撞体、脚锁、旋转与循环位置。数值不是设备或多人同步结论。
