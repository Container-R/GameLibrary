# 任务目标的既有事实：单人任务合成对照

[返回正文](../../../GameLibrary/叙事设计/运行时叙事/任务进度/先拿到任务道具，后来才接任务，进度该不该算.md)。

运行 `node objective.js`；[脚本](objective.js)、[Node v24.22.3 输出](observed.json)。输入是同一虚构存档的一条连续领域记录，顺序号单调，没有让不同时间线共用顺序号。对照目标对象 R、同类型但非目标对象的拾取和交付、同一步开通/拾取换序、先拾后耗用、历史不完整旧档、从记录补算以及一次交付后的读档重放。快照用 JSON 往返模拟，不读任何实际游戏存档。演出只是计数，不模拟跨进程投递、实际持久化事务、掉电或实际渲染。覆盖水位仅用于严格有序且同一时间线的输入。

输出中的 `have`、`found`、`after` 分别表示当前持有、曾取得、开通后取得；`found:null` 表示过去证据不足。归档的 `receipt` 与即时持有资格是不同数据，不会因为交付后消费道具而撤回成功。
