# 地形分块边界：原创二维剖面对照

运行：`MPLCONFIGDIR=/tmp/terrain-mpl XDG_CACHE_HOME=/tmp/terrain-cache python3 probe.py`。
依赖 Python 3 与 matplotlib。脚本在自身目录写 comparisons.png 与 observed.json；可复制脚本到临时目录运行以保留归档。

三列分别为峰顶横移、双块公共端点错位、渲染不变而规则脊线横移；两行为40/10像素每米的正交投影。左右块以x=0分界。无缝案例以同一点接合，断缝案例使用两段独立折线，未连接端点。没有三维面、法线、真正LOD选择或深度测试；不得把剖面错误写成完整地形实验。

数值从候选峰点及公共端点计算并断言预期40/8/40与10/2/10像素。规则线移位与高度阈值是人为反例，只有一条射击线和一个高度样本。屏幕坐标是绘图数据坐标；排版图像尺寸不等于真实游戏视口，不能在网页缩放图上量像素。

作者实际查看生成PNG：六面板可读，近景峰位与端点差可见，远景显示差异缩小；规则列渲染重合而规则线分离。脚本数值而非显示图片量尺作为记录。首次运行有Matplotlib/Fontconfig缓存只读警告，退出0；随后用上述可写缓存路径重跑，退出0。没有引擎、原游戏、性能、人眼阈值或普遍无缝保证。
