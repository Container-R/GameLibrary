# 观战比分与画面同步：合成试件

[返回正文](../../../GameLibrary/网络与在线服务/实时同步/观战与回放/延迟观战的比分与画面同步.md)。

在 Node.js 中运行，固定输出来自 Node v24.22.3：

```sh
node prefix.js
node cursor.js
```

- [prefix.js](prefix.js) 与 [输出](prefix.observed.json)：迟到分段触发完整覆盖恢复，对比严格比分与可修正比分；静默区间需显式空覆盖，不能由没有数据推断。
- [cursor.js](cursor.js) 与 [输出](cursor.observed.json)：模拟回放适配器的帧位置和跳转完成代号，比较连续播放、暂停、主动回看、计分迟到和旧请求返回。检查点在 tick 100、事件序号 0；同 tick 但序号 1 的事件仍应用。

两组都是控制输入的合成算例。源事件预先定义；不连接比赛、媒体、浏览器或 Unreal，不校验真实编码、时钟映射、授权、修订协议或丢包补传。覆盖例只接受预定义的不相交完整分段；游标例刚好检查应用层请求的异序，不模拟 Web API 或引擎实际回调契约。正文的规则取舍不代表所有播放器采用同一设计。

两脚本分开运行：覆盖脚本只比较比分，不运行提示调度；游标脚本检查提示窗口，不模拟覆盖缺口。正文中的缺口抑制、追溯改版和跳转超时是设计规则，不是这组观察的测量结果。
