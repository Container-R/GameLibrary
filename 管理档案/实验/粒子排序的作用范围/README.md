# 粒子排序的作用范围

[正文](../../../GameLibrary/视觉特效/特效制作/粒子渲染/粒子开了深度排序，为什么两团半透明还是会遮反.md)

- [EGL / OpenGL 读回脚本](egl_sort.py) · [实际输出](egl-output.txt)。运行 `python3 egl_sort.py`。需要 Python 3 与提供 OpenGL 4.5 的 Mesa EGL 软件实现；试件强制使用软件路径。目标 32×8、RGBA16F，关闭色彩转换、MSAA 和抖动，在两侧各读一像素。深度随距离增大，普通深度测试 LESS，固定透明度 0.5。脚本逐个四边形提交，GPU 合批不是主张。
- [精确分数模型](sort_scope.py) · [实际输出](sort-output.txt)。运行 `python3 sort_scope.py`。此模型只计算常深度四短片在两个采样点的颜色和分组反例，不包含相交构形或深度写入。
- 实验覆盖四片按组与交错、相交卡片的两种整卡次序、四片开启深度写入。对照结果可以精确表示为半精度二进制数，本机逐项断言。其他系统的真实烟雾、排序、视图及性能需要另测。
