# 短对白响度的测量对照

复现使用 FFmpeg 7.1.5-0+deb13u1、Python 3，无需下载素材：

```sh
python3 fixture.py | diff -u observed.json -
```

脚本把 48 kHz 单声道 float PCM 送到 `ffmpeg -af ebur128=peak=sample+true`。输入为合成 1 kHz 正弦，首尾时长不改变被比较的声音内容；信号用于测量，不能代替对白或试听。

- 不足 400 ms 的 200/350 ms 测试没有形成一个完整测量块；程序摘要的 −70.0 是该实现的初始显示值，不能当作有声片段的有效测量。两段各补零至 400 ms 后，首个完整块分别约 −26.0 和 −23.6 LUFS；补零只定义了一种测量窗口，不是“恢复了真实的单句响度”。两段峰值仍为 −20.0。
- 1 秒测试音本身约 −23.0 LUFS；加同样长的头静音或尾静音约 −23.7 LUFS，峰值仍为 −20.0。门控按窗口处理，纯静音块与边界处声音、静音混合的窗口不同；试件不代表任意留白量都会造成同样差值。
- 第二个长测试音幅度降低约 12 dB，实测约 −35.0 LUFS、−32.0 dBTP；给它施加 +12 dB 安全标量增益，其测值回到约 −23.1 LUFS、−20.0 dBTP。它只展示统一目标会消除预设强度差，不评价角色表演、可懂度或增益是否适合实际游戏。末位可能受实现、直方图精度、打印舍入等因素影响。

[ITU-R BS.1770-5 Annex 1](https://www.itu.int/dms_pubrec/itu-r/rec/bs/R-REC-BS.1770-5-202311-I%21%21PDF-E.pdf) 定义 400 ms、75% 重叠和双门槛；[FFmpeg 7.1 扫描器源码](https://ffmpeg.org/doxygen/7.1/f__ebur128_8c_source.html) 定义初始 `ABS_THRES`、400 ms 积分器、每 100 ms 更新及峰值测量。两类峰值的显示在本试件恰好相同，不表示所有素材的采样峰值都等于真峰值。
