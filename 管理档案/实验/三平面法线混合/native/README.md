# 平法线三平面对照：实际软件 OpenGL

```sh
python3 -B probe.py /tmp/triplanar-contact.png > /tmp/triplanar-observed.json
cmp /tmp/triplanar-observed.json observed.json
cmp /tmp/triplanar-contact.png contact.png
```

Python 3.12.14，系统 EGL / Mesa llvmpipe，图片可选依赖 Pillow。脚本使用无窗口 EGL，强制软件 GL，并禁用 shader disk cache；无安装步骤。两次实际运行的 JSON 和 PNG 均逐字节一致。不同 Mesa 版本的最后几位浮点数未保证一致。

同一个平面 z=-tan(25°)x，以两个三角形实际栅格化到 96×96 RGBA32F。基准法线为 (sin25°,0,cos25°)。投影、几何体、固定光向、漫反射与 Blinn 型高光算式不变，仅切换法线计算。1×1 RGBA32F 纹理存放已经解码的 (0,0,1)，实际通过 texelFetch 读取，避免 8 位量化及导入差异。

三个模式：基准法线；按投影轴重定向后用归一化 abs(n)^p 权重混合；将 -xy/z 斜率按 X(U=y,V=z)、Y(U=x,V=z)、Z(U=x,V=y) 的单位尺度共同空间梯度加权，投到表面切平面，再重建 normalize(n-gradient)。本例纹理为平图，所以三轴梯度均为零。它并不验证这些投影基底在所有符号象限或非平法线上的一般正确性。

p=4 时轴混合得到约 2.707008° 的法线倾角，相对原来 25° 偏差 22.292992°。基准线性光照读回约 0.753225，轴混合约 0.432438，梯度重建约 0.753225。梯度与基准的全图 RGBA 最大绝对差约 7.15e-7（额外归一化及浮点运算），不是位级完全相等。p=1 作控制，直接轴混合也还原基准，避免把所有轴混合都说成平图必错。

contact.png 从真实帧缓冲读回生成，三列为基准、轴混合、梯度；上排将有符号法线映射 RGB，下排为线性光照直接映射灰度，无色调映射。作者实际查看过图片：中列明显改变颜色与亮度，两侧视觉一致。恒定平面没有空间变化的高光形状，图不是球面接缝展示。

证据边界：只检验平图恒等性与同光照下的差异；不是 Unity 或其他引擎的 Triplanar 实现，也不是硬件 GPU 测试。没有非平纹理、真实 UV 采样变化、负象限/镜像、导入通道、mip、接缝、曲面、TBN 畸变、几何位移、性能或感知验证。不应从这个零梯度例子推断非零细节路径已全部正确。
