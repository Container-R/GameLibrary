# 太空场景固定镜头的透视对照

- [原创投影脚本](project_scale.py)；[断言执行结果](projection-output.txt)。
- [返回正文](../../../GameLibrary/美术设计/环境设计/概念设计/太空场景概念图的尺度参照与透视检查.md)。

运行 `python3 project_scale.py`，标准输出给出每一栏两物体的水平投影宽度，当前目录会写出 `projection-comparison.svg`。向量图比对的是定义轮廓在参考画布的坐标，不把网页缩放后的像素当实测数据。相机与蓝色轮廓固定；黄色轮廓中心沿原视线移动，两个平面轮廓均面向镜头。断言检查 A 为 120/12 px、B 为 120/120 px。无游戏或实时引擎依赖，不验证读者感知。
