# 五房间地图的可达性复算

Python 3.12.14，运行 `python3 reachability.py`，断言并输出可与 `observed.json` 比较。固定一张有向地图，只有大厅到下层的边需要钥匙；取得后不消耗。比较两个移钥匙的版本，分别以纯拓扑、查锁但只按房间去重、查锁且按完整房间与钥匙状态去重执行。为便于演示，代码直接保存走过的状态序列；大规模可用前驱记录重建。输出里的探索中阻挡记录与最终是否成功分开，有成功路径也可能先遇到阻挡。

真实生成器、Spelunky、几何跳跃、危险、玩法时序、资源消耗和完整的玩家可解性都不在实验范围。此处实际执行的是条件图搜索，没有搜索多个随机种子。
