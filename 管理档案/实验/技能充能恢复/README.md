# 固定时长下的技能充能恢复

正文：[两格技能充能：第二格为什么在第 20 秒才恢复](../../../GameLibrary/玩法程序/玩法系统/战斗状态/两格技能充能：第二格为什么在第%2020%20秒才恢复.md)。

在本目录以 Python 3.10 或更高版本运行 `python3 model.py`，不要加 `-O`，因为预期结果用断言核验。无需装库或访问网络。[实测输出](observed.txt)中的三元组为（当前可用格数，距下一格，距补满），后两项单位为秒；`None` 表示已满，无下一格时间。

- 两格，耗时 10 秒：0、2 秒各成功消耗一格，3 秒拒绝第三次，之后不再消耗。分别检查 3、10、12、20 秒。
- 新建同样状态，在第 10 秒恰好到期时再次消费，检查先恢复再消费；随后直接推进到 30 秒，检查一次结清。
- 新建状态，有格但施放资格不满足时不扣格；空闲到 60 秒再用，验证满格不会积攒额外恢复时间。

这是固定时长、单调模拟时钟上的自建模型，不运行 SimulationCraft 或商业游戏，也不验证动态改速、回滚、输入重传或联网。
