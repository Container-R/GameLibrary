# 虚构关卡的 NPC 听觉：图搜索与事件快照试件

[正文](../../../GameLibrary/游戏人工智能/行为决策/感知与搜索/同样近的两个%20NPC，为什么只有一个听见.md)

```sh
node hearing.js > hearing.observed.json
python3 -B plot.py
```

- [hearing.js](hearing.js) 使用 Node 24.22.3，从固定拓扑选择最小非负代价的路径，分别观测距离、长度、损耗、预算、接收与推定区域。是合成的游戏参数，不是物理声强。起点固定为图中的 S，坐标字段只用于直线距离；额外断言真正断开时不会听见，以及修改源对象坐标或门配置后，之前已经生成的记录不变。没有模拟移动声源再发声或引擎时间线。
- [运行输出](hearing.observed.json) 包含四组情形对照。A 和 B 直线均为 4；B 在四组中的最低代价与判定是 20/没有、4/收到、20/收到、15/收到。观察仅保留事件标识、时间、类别与估计区域，不交给角色活的源变换。
- [plot.py](plot.py) 用 Pillow 和 Noto Sans CJK SC 绘制 [rooms.png](rooms.png)。图中连接不按比例，通风口为听觉图连接，不是 NPC能走的路线。不模拟延迟传播、音频波形、游戏引擎、调试、反应动画或正常视角读者验收。
