# 镜像落脚事件的足别：复现

[正文](../../../GameLibrary/角色动画/角色移动/步态同步/动作镜像后右脚落地，脚步事件为什么还是左脚.md) · [来源核对](../../来源笔记/mirrored-foot-events-20261125.md)

```sh
godot --headless --path native --script probe.gd
```

[存档输出](native/observed.txt)来自 Godot 4.7.2.stable.official.ed1daf0bf。为隔离通知侧，脚的位置轨道从 0 秒起保持定值，且在方法键之前先完成第一次求值；程序推进到 0.30 秒，跨过 0.25 秒处的一次方法键。不开启自动时间推进、过渡、IK、物理接触或实际音效，左右区域是简单的横向位置判定。双换组在生成素材参数时主动应用两次对侧变换；这是重复映射错误的对照，不表示 Godot 自动执行两次。四组中每组只记录一个通知，故问题与数量无关。

试件作用是验证造出的轨道数据到实际方法参数这条链，不验证曲线、骨骼名等特定引擎的镜像实现，也不测混合或异步派发。
