# 正文链接检查的范围

维护文章时，最容易漏掉的是相对路径少退或多退一级。`check_reader_links.py` 针对显式图书目录中的正文做离线检查；它不取代实际沿书架打开文章，也不访问外部来源。

从仓库根目录运行：

```sh
python3 管理档案/工具/library/check_reader_links.py --root . --manifest 管理档案/图书目录.json --expected-count 66
python3 -B -m unittest discover -s 管理档案/工具/library
python3 -B -O -m unittest discover -s 管理档案/工具/library
```

清单必须存在、数量与显式预期相同、正文路径唯一且位于仓库内。空正文不是成功扫描。数量是防止输入丢失的约束，不是文章质量指标。

## 怎样读结果

- `pass`：本次输入中识别到的受支持链接没有发现问题。不是所有 Markdown 写法都已覆盖。
- `fail`：发现可判定的目标或标题片段错误。修正路径或目标后再运行。
- `incomplete`：存在工具不能可靠解释的写法，需要另行检查，不能当作通过。
- `configuration_error`：输入无效或缺失，不继续给出通过结论。

后三种情况都返回非零退出码。结果分开列出目标错误、标题片段错误和不支持项；HTTP(S) 只计为未检查的外部链接。代码块中的示例不会当作正文链接。普通单行行内链接、中文及百分号编码路径、简单 ATX 标题及重复标题是主要支持范围。格式化标题、Setext 标题、参考式或跨行链接、复杂 HTML、含实体的目标等可能返回不支持；它不是 GitHub Markdown 渲染器。

2026-11-01、提交 `ccfaed7ab4a23221253e48dd985eb8ed8306b69e` 对应的 58 篇正文扫描识别 133 个本地链接和 22 次片段检查；没有可判定的目标或片段错误，但有 31 项不支持，整体结果为 **incomplete**。这些数字只记录当时输入，不能作为未来发布的豁免。不要为了获得绿色结果删除文章中的正常语法或把不支持项隐藏。

## 已知边界与反例

开发中的早期版本漏掉过空正文、缩进中的链接、跨行标签、无效围栏及跨行 HTML。普通单元测试通过并没有阻止这些假通过，随后独立反例促使实现改成明确拒绝。当前测试也只是有限回归集，不是解析完备性的证明。

如果将来要扩大 Markdown 范围，先保留失败输入，再确定应识别还是明确拒绝；不要在未知语法上默认成功。发布时仍须对变更正文实际打开关键路径，并确认检查的是待发布树，而不是混合了未提交文件的工作目录。

## 对已报告未支持项的人工复核

[固定59篇基线的31项复核](../../审查/正文出链未支持项复核.md)没有发现这些项中的实际坏目标或片段；其中包含不是链接的数学区间/页码引用，以及被工具保守跳过的历史支持标题。该有限静态复核不把工具状态改成通过，不证明完整Markdown识别、全部外链可用或浏览器逐项点击体验。

## 潜在 HTML 目标的保守拒绝

目标中可能有原始 HTML 块时，仅按行寻找 `#` 会误认标题。已保留的反例是目标依次包含 `<div>`、`# Hidden`、`</div>`，旧工具对 `#hidden` 给出 pass；这并不是 Markdown 标题的有效证明。

修正后的有限规则是：在工具已识别的有效围栏之外，目标任意行含字面 `<`，整份目标的片段检查返回 unsupported。不尝试解析 HTML 或恢复其后的上下文；普通不等式、行内代码及自动链接也可能因此被保守拒绝。它们不是被判定为坏链接。路径检查、其他不支持项及既有标题规则不因本次修正得到普遍正确性认证。

对本次63篇候选的实际扫描，155个本地链接、22次片段检查没有可判定的目标或片段错误，但未支持项从31增加到32，仍是 incomplete。新增玩法岗位到固定步输入段的链接，因目标行内代码含 `0≤A<h` 被整目标拒绝；独立定向静态核查未发现该路径或标题失配，未执行浏览器渲染。旧59篇/31项审查仍只属于其历史快照，不能据此自动扩充覆盖。

本轮35个既有链接测试和6个新增方法保持区分。独立18情形的检查入口为：

```sh
python3 -B 管理档案/工具/library/adversarial_reader_html.py 管理档案/工具/library/check_reader_links.py
python3 -B -O 管理档案/工具/library/adversarial_reader_html.py 管理档案/工具/library/check_reader_links.py
```

普通和优化模式重复同一组输入，不增加情形种类。参见[有限反例与独立复核](../../审查/正文片段检查HTML上下文修正.md)。
